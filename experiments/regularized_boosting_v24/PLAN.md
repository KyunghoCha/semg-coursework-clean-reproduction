## 근거와 우선순위

기존 v21 내부 14,592관측에서 오답은 1,332개다. 그중 946개는 정답이 상위 두 클래스에 있고, 각도만 틀린 경우 319개·동작만 749개·둘 다 264개다. 가장 큰 방향성 혼동도 72개로 오답의 5.4%이며 여러 클래스쌍에 분산돼 있다. 따라서 특정 쌍 보정부터 추가하지 않는다. RMS 분위별 정확도도 단조롭지 않아 낮은 진폭만을 원인으로 단정하지 않는다. 이 진단은 내부 예측만 읽었으며 새 바깥 예측은 보지 않았다.

기존 fit_gap_probe는 현재 계열의 좁은 410특징 XGB에서 학습 19,456창을 모두 맞혔지만 평가 정확도는 90.05%였다. 이 관찰은 추정 분산이나 복잡도를 줄이는 대조의 근거이며, 과적합의 원인을 확정한 것은 아니다. 이전 v4/v7의 트리 수 증가는 다른 특징 또는 직접 8목표를 포함하며, 이번 410특징·64목표·v21 결합에서 아래 두 설정을 비교한 기록은 없다.

## 고정 조건

- 현재 200ms·5채널·410특징만 사용한다. stride100ms와 시행당19창, 전체 개발1,536시행, 기존 v10 내부/바깥 시행 분할을 그대로 유지한다. 원본1,920시행 캐시는 유지하되 과거 노출된384시험을 새 평가에 쓰지 않는다.
- 과거·미래창, 시행 투표, 경계 힌트, 위치, 사람/기록 ID를 추론 입력에 넣지 않는다. 훈련64목표는 기존 사람×8클래스이며 추론64확률을 사람 축으로 합쳐8클래스로 만든다. 64목표와64기록의 일대일 관계는 해결되지 않는다.
- 기존 v21의 XGB/LDA/SVM 비중64/16/20을 그대로 쓴다. LDA·SVM은 저장된 같은 fold 모델/확률을 재사용한다. 새 XGB가 해당 부분만 대체하며 결합 비중은 재선택하지 않는다. 단독 XGB 점수도 보조로 남긴다.
- 두 후보 모두 learning_rate=.05, subsample=.9, colsample_bytree=.8, reg_alpha=0, gamma=0, hist, CUDA, seed42, n_jobs6이다. reg400은 depth6·400회·min_child_weight5·lambda5, shallow800은 depth4·800회·min_child_weight1·lambda1이다. 전자는 규제 묶음, 후자는 깊이와 라운드가 함께 바뀌는 대조이므로 개별 파라미터 하나의 인과 효과로 쓰지 않는다.
- 모든 학습 창으로 StandardScaler를 fit한다. 데이터 표본을 영구 축소하지 않는다. subsample=.9는 기존과 같은 트리별 무작위 사용률이다. 조기 종료나 평가 레이블 기반 학습 중단을 사용하지 않는다.

## 내부 선택과 바깥 평가

내부 768학습시행·256평가시행에서 기존 결합과 두 후보의 결합을 비교한다. 후보의 XGB 저장 크기가 같은 fold 기존 XGB의 두 배를 넘으면 비용 제한으로 선택에서 제외하되 결과는 보존한다. 선택 기준은 정답 창 수 최대, 동률은 기존 모델 우선, 새 후보 간 동률은 작은 저장 크기·사전 순서 reg400/shallow800이다. 내부 총합의 선택은 참고용이고 바깥에는 각 내부 fold의 선택만 쓴다.

내부6fit를 모두 마친 뒤 선택 파일·해시를 고정한다. 각 바깥 학습1,024시행에서 선택된 새 후보만 학습하며 기존 선택이면 새 fit0회다. 최대 새9fit다. 바깥512시행×19창은 각 fold에서 한 번 평가하고 전체 개발시행이 정확히 한 번 나타나야 한다. 기존 v21을 보존하며 바깥 결과로 규제·라운드·비중·표본을 조정하지 않는다. 바깥 점수가 나빠도 남긴다. 기존 개발 자료와 반복 선택이므로 외부 독립 시험이라고 부르지 않는다.

## 검증과 비용

분할 재생성·클래스 지원·학습 전용 scaler·입력 해시·실제 CUDA·라운드/트리 수·선택 규칙·확률 열·합산·저장 모델 CPU 복원·수동 지표를 검증한다. 원본 모델과 예측 해시는 보존한다. 학습 정확도는 재대입 진단으로만 기록한다. 실패하거나 불완전한 체크포인트는 덮어쓰지 않고 상태를 확인한다.

학습 시간은 scaler와 모델 fit를 구분한다. 모델 저장 크기를 모든 fit에서 남긴다. 학습 종료 뒤 CPU6라이브러리스레드에서 기존과 새 XGB 단독, 전체 결합의 특징+모델 확률 지연을 측정한다. 대표는 첫 새 후보 선택 바깥 fold이고, 모두 기존이면 내부 fold0의 두 후보를 측정한다. 대표 평가의 첫20시행×19창=380창을 각 조건에서 모두 시간 측정하고19창 예열을 사용한다. CSV읽기·모델 로딩·신호 취득은 제외한다. 각 창의 추론에는 상태를 두지 않는다. 기존 v22 라벨 생략을 새 모델에 자동 적용하지 않고 전체 확률 비용으로 비교한다.
