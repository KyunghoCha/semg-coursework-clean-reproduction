# 단독 분류기 비교와 XGBoost 용량 대조

2026-10-22 UTC. 사용자가 서로 다른 모델의 결합을 원하지 않는다고 명시했다. RF·XGBoost·SVM은 각각 하나의 fitted estimator로 평가한다. 91.9819% 앙상블과 v23 과거 창 결과는 과거 별도 조건이며 새 목표나 성공 기준이 아니다. 기존 파일은 보존한다.

## 먼저 확인한 같은 내부 분할의 단독 결과

현재 410개 특징, 내부 학습 768시행/평가 256시행, 같은 3개 분할·전체 19창이다. XGB 800회/깊이 4는4352/4442/4384개 정답(평균90.3098%), XGB 400회/깊이 6은4319/4416/4348개(89.6587%)다. 기존 SVM확률 보정 결과 대신 저장된 최종 단일 SVC의 predict→64목표mod8 결과만 읽으면4199/4202/4192개(86.3007%)다. C100·RBF·gamma=scale이며 보정기·다른 base 모델의 출력을 쓰지 않는다. RF200 직접 8목표는82.2026%로 낮다. v32 마지막64목표 모델까지 완성한 후 같은 단독 지표를 확정한다. 이미 학습된 모델·저장 예측을 재사용하므로 비교표를 위해 중복 학습하지 않는다.

XGB800은 기존에 결합 지표로 선택된 이력이 있으나, 이번에 단독 내부 정답을 다시 비교해도 세 분할 모두 XGB400보다 높다. 그 사실과 과거 후보 생성·반복 개발 노출을 함께 기록한다. 기존 단독 바깥90.9608%는 참고값이며 새 미관측 평가로 부르지 않는다. RF/SVC의 내부점수를 XGB의 바깥점수와 같은 평가로 직접 순위화하지 않는다.

## 한 가지 새 가설과 비용

400개보다800개의 얕은 트리에서 단독 정확도가 일관되게 높았다. 더 얕은 분할을 더 많은 단계에 나누면 현재창 특징의 복잡한 결합에 덜 의존하면서 경계를 표현할 수 있다는 가설을 검증한다. 후보는 **깊이3·1600회** 한 개다. 깊이와rounds를 함께 바꾸므로 각각의 독립 인과효과로 해석하지 않는다. 과거 1600회 실험은 다른특징·직접 8목표였으며 현재 410개 특징·64목표에서 이 설정은 미실행이다.

현재 200ms×5채널·100ms 이동·전 19창·전체 개발 1,536시행/64기록·v10의 동일 분할을 유지한다. 시험 384시행은 제외한다. 과거/미래 창·시행 투표·기록 ID 입력 없음. 사람×8조건의 64목표는 한 XGB에서 학습하고, 단일 모델의 64확률을 조건별로 합산해8클래스로 해독한다. 서로 다른 학습 모델의 출력 결합은 없다. 이 학습 목표와 64기록의 일대일 한계는 유지된다.

새 XGBClassifier는 n_estimators1600,max_depth3,learning_rate.05,min_child_weight1,reg_lambda1,reg_alpha0,gamma0,subsample.9,colsample_bytree.8,objective multi:softprob,tree_method hist,device cuda,n_jobs6,random_state42,early_stopping_rounds=None. 모든 학습 창을 제공하고 학습 전용 StandardScaler를 적용한다. 평가 집합을 학습 중단에 쓰지 않는다. 실제 CUDA/라운드/102,400트리를 확인한다. CPU보다 GPU가 적합하므로 연결된 TITAN Xp에서 실행한다.

예산은 새 내부 3fit와 선택된 바깥 최대 3fit다. 1,600단계의 깊이 3 최대 잎 수 합은 800단계 깊이 4와 같다. 하지만 직렬 학습 단계는 두 배이므로 실제 시간을 반드시 기록한다. 예상 전체 10–25분이며 나쁜 후보의 추가 추론 벤치마크를 하지 않는다. 각 fold의 후보 파일이 기존 XGB 800회의 2배 이내이고 내부 정답이 10개 이상 늘면 새 후보를 선택한다. 아니면 기존 단독 XGB 800회을 유지한다. 다른 fold의 점수 합이나 바깥 점수로 선택하지 않는다. 내부 3fit 후 선택을 파일·해시로 고정하고 바깥에 적용한다.

모든 새 모델의 클래스 지원·학습 범위·scaler·입력 해시·GPU 설정·라운드·저장 모델 CPU 복원·수동 8클래스 지표를 확인한다. 전체 바깥 1,536시행이 정확히 한 번 나와야 한다. 기존 모델과 예측 해시를 보존한다. 개선 후보만 대표 fold의 같은 380창으로 단독 추론 시간을 측정하며, 실패도 보존한다. 19창을 독립 표본으로 간주한 신뢰구간은 만들지 않는다.

현재 자료에는 이미 바깥 평가 노출이 있고, 공통 기록이 학습·평가에 포함된다. 기록 일반화나 논문 정확재현을 보장하지 않는다. 논문의 평가 단위 미확인은 별도 비교표에 유지한다. 외부 게시·업로드·새 공개 묶음 생성은 계속하지 않는다.
