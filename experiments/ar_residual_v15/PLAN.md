# AR 계수와 잔차 고정 대조 (v15)

2026-10-21 UTC, 학습 전 등록. 이전 clean 프로젝트 결과를 유지하며 새 특징만 추가한다.

## 근거와 후보 판단

Pan et al., EMBC 2015, DOI [10.1109/EMBC.2015.7320070](https://doi.org/10.1109/EMBC.2015.7320070), [PubMed 26737970](https://pubmed.ncbi.nlm.nih.gov/26737970/)의 공식 초록을 Europe PMC API로 읽었다. 6차 AR에 잔차를 더한 효과가 대상 집단에 따라 달랐다. 전문은 구독 대상이고 추정식·잔차 요약식·분할은 미확보다. 아래 최소제곱과 잔차 RMS는 이 프로젝트의 사전 정의이며 원연구의 정확 재현이 아니다.

기존905특징은 AR 계수·잔차를 포함하지 않는다. 50ms×4 log-RMS 변화는 기존40ms×5 subRMS와 겹치며, 기존 time 추가는 내부58.36%로 기본58.44%보다 높지 않았다. 이번에는 생략한다. v10 내부 검증에서 최대 오류쌍은 fold마다 달랐고 전체 오류의 약9–14%로 분산되어 쌍별 LDA/SVM 보정도 생략한다. 기존 확률 혼합은 이미 검증했으므로 반복하지 않는다.

## 변환 고정

현재200표본×5채널만 사용한다. 각 채널에서 해당 창 평균을 빼고 z를 만든다. 상수 채널은 z=0으로 명시한다. t=6,…,199에서 D[t,k]=z[t-k], k=1,…,6이며 b=pinv(D,rcond=1e-12)z[6:]이다. float64 SVD 상대 절단값만 사용하며 ridge, 절대 epsilon, clipping, 정규화는 없다. 잔차는 e=z[6:]-Db, RMS=sqrt(mean(e²))이다. 계수는 무차원, 잔차 RMS는 입력 CSV와 같은 단위다. 계수 부호는 예측식 z[t]=sum b[k]z[t-k]+e[t]를 따른다. 출력은 채널 순서별6계수30개, 마지막에 채널별잔차5개다. TD25는 원래 창과 원래 ZC .01·SSC 수식을 그대로 사용한다. 채널별 DC 제거는 AR 부분에만 적용한다.

## 주평가와 선택

입력1,920시행 모두 특징을 계산한다. 이전384시험은 새 학습·선택·평가에서 제외한다. 개발1,536시행의200ms·100ms hop·19창, 창 정확도를 유지한다. 표본·채널·시행 축소, early stopping, 하이퍼파라미터 검색은 없다.

1. 기존v10의 정확한3개 outer/inner 분할을 사용한다. 각 inner는768학습/256검증이며 전체 inner OOF는 아니다. 기존 narrow410에 계수30개를 더한440D와 계수+잔차35개를 더한445D를 각3회 학습한다. XGB400, 64목표와 기존depth6/lr.05/subsample.9/colsample.8/lambda1/seed42/GPU/6threads를 유지한다. 64목표는64기록과 일대일이며 최종8클래스 확률로 합친다.
2. 각 fold의 inner correct 수 최대인 base410/AR440/AR445를 선택한다. 동률이면 작은 특징수다. 바깥 결과를 읽기 전에3선택을 파일로 고정한다. 선택 모델만 outer1,024학습/512평가한다(최대3새fit). base 선택 시 기존 동일 모델을 재사용한다. 기존410 outer와 창별로 비교한다. 선택 이점이 없으면 그대로 보고한다.
3. 선택 고정 후 별도 직접8클래스 대조를 실행한다. TD25+계수=55D, TD25+계수+잔차=60D 각각 기존 active_record_baseline의4fold 기록 공유와4fold 기록 분리에서 학습한다(16fit). 기존25D 8fit는 재사용한다. XGB400 고정이며64목표 실험과 학습 목표를 혼동하지 않는다. 이 결과로 앞선 후보 선택을 바꾸지 않는다.

신규 학습은6+0~3+16=22~25회다. 결과를 보고 가지를 늘리지 않는다. 기존 CV 탐색 이력과 이미 노출된 시험 때문에 새 외부 시험 또는 편향 없는 최종 성능으로 부르지 않는다. 19창을 독립 관측으로 놓고 신뢰구간을 계산하지 않는다. 기록 분리 결과는 새 사람 분리와 다르다.

## 검증과 비용

독립 np.linalg.lstsq 수식 대조, 채널 순서, 상수/영 입력, 양의 배율, 배치와 단일창 동등성, 창 밖 정보 비참조를 검사한다. 원본 캐시 SHA256 보존, 모든1920×19 특징 유한성, 학습만 scaler fit, 모든8/64클래스 지원, 확률 열, 모델 CPU 복원, 수동 metric, 모든 개발시행 분할별1회 평가를 확인한다.

모든fit의실제시간/직렬화크기를 기록한다. 학습 종료 후 기존256개 고정 개발 창을 재사용해 대표모델의CPU6thread 특징+scaler+추론 batch1을20warmup/200회 측정한다. 신호200ms 취득·모델 로딩은 제외한다. 원신호·모델·개별예측은 private, 공개는 코드와 집계만이다. 기존 파일을 덮어쓰지 않는다.
