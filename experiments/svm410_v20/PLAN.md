# 410특징 RBF SVM 고정 대조 v20

2026-10-21 UTC, 학습 전에 고정한다. 현재 90.5942% 후보의 추가 개선 가능성을 내부 자료에서만 검토한다. 외부 push·업로드는 중단 상태를 유지하며 이번 작업은 로컬에만 기록한다.

## 기존 실행과 남은 오류

전체 src/experiments의 SVC·SVM 사용과 실제 학습 코드를 검색했다. v4의 SVM은 240특징·직접8목표·C100이며, 표준화 72.83%와 분위수 변환 73.56%였다. 현재 410특징 또는 410특징·64목표의 SVM은 실행하지 않았다. 기존 결과를 410특징 SVM의 검증으로 간주하지 않는다.

v19의 고정 결합 내부 관측 14,592개 중 오류는 1,430개다. 동작만 틀린 오류 803개, 각도만 335개, 둘 다 292개다. 최대 방향성 클래스쌍도 77개로 오류의 5.38%이므로 특정 쌍에만 보정기를 붙이지 않는다. 첫 창은 83.46%, 뒤쪽 창은 약93–95%지만 주평가의19창을 줄이거나 위치를 입력에 추가하지 않는다. 학습 RMS 사분위로 나누면 가장 낮은 구간이94.22%여서 낮은 활성도만으로 실패를 설명할 수 없다. 자료와 예측은 내부 분할에만 대응하며, 바깥 예측을 새 후보 선택에 읽지 않았다.

LDA가 일부 XGB 오류를 보완했던 사실과 남은 동작 오류를 근거로, 축별 분할과 다른 거리 기반 곡선 경계 한 가지를 검사한다. SVM이 유리하다는 결론을 전제로 하지 않는다.

## 고정 모델과 확률 보정

410특징, 200ms·100ms이동·19창·5채널, 기존 v10의 내부3분할과 바깥3분할을 유지한다. 각 내부 학습768시행의 모든14,592창을 사용한다. 원래1,920시행 캐시는 유지하며 개발1,536시행만 학습·선택·바깥 평가에 사용한다. 역사적384시험은 제외한다. 학습 목표는 기존과 같은64개이며 확률을 사람 축으로 합해8개 출력으로 만든다. 기록 ID는 입력에 없지만64목표가64기록과 일대일이라는 한계는 같다.

후보는 StandardScaler+RBF SVC(C=100,gamma='scale',tol=.001,max_iter=-1,cache_size=1024MB,probability=False,decision_function_shape='ovr',random_state=42) 한 개다. C·gamma·입력 변환의 탐색은 하지 않는다. CPU libsvm을 사용하며 GPU 사용이나 학습 반복 상한을 강제하지 않는다.

[scikit-learn1.7.2 SVC](https://scikit-learn.org/1.7/modules/generated/sklearn.svm.SVC.html)와 [확률 보정 설명](https://scikit-learn.org/1.7/modules/svm.html), [CalibratedClassifierCV](https://scikit-learn.org/1.7/modules/generated/sklearn.calibration.CalibratedClassifierCV.html)을 읽고 설치된 fit 소스를 확인했다. 64확률의 합산을 위해 sigmoid 보정을 사용한다. 겹치는 창을 별도로 나누는 기본 보정 CV 대신, 학습768시행 안의64목표 층화3fold(seed20261123+바깥fold)를 창 인덱스로 확장해 같은 시행의19창이 함께 이동하도록 한다.

`CalibratedClassifierCV(estimator=pipeline,method='sigmoid',cv=고정시행분할,n_jobs=1,ensemble=False)`를 사용한다. 보정 내부의3개 SVM과 scaler는 각 보정 학습 부분에서만 맞춘다. 보정용 OOF 점수를 모은 뒤 전체768시행에서 최종 SVM과 scaler를 다시 학습한다. 검증256시행은 이 모든 과정에서 제외한다. 최종 활성 모델은 SVM1개와 보정기이며, 모델마다 base SVC fit는4회다. sigmoid 파라미터는 학습 OOF에서만 추정한다. 보정 전 predict와 확률 argmax가 다를 수 있으므로 주지표는 보정된64→8확률 argmax로 고정한다.

## 내부 선택과 바깥 평가

내부3개 후보를 모두 마친 뒤 각fold에서 현재 v19의 고정 XGB80%+LDA20% 정답 수와 비교한다. SVM의 정답 수가 더 클 때만 해당 바깥 학습1,024시행에서 동일 절차로 SVM을 학습해512시행을 평가한다. 동률이나 하락이면 기존 v19를 유지한다. 바깥 보정 CV seed는20261133+fold다. 바깥점수로 C·gamma·보정방식·가중치를 바꾸지 않는다. 이번에는 SVM을 기존 모델과 다시 결합하지 않는다.

내부 확률모델3개는 base SVC12fit가 필요하고, 바깥선택에 따라 최대3개 확률모델·12base fit가 추가된다. wrapper fit수와 base fit수, sigmoid 보정을 구분한다. 예상 내부 시간은 기존240특징 SVM 기록을 참고한 약2–8분이나, 클래스 수·확률 보정이 달라 실제 시간은 불확실하다. 최대 메모리는1GB커널캐시와특징·모델이며, 감사용 base모델 저장까지 수백MB가 추가될 수 있다. 예상 시간을 맞추려고 자료·모델을 줄이지 않는다.

## 검증과 비용

각 base fit의 scaler·학습 입력 해시·클래스 지원·수렴 상태·support vector·반복 수와 모델을 private에 보존한다. 실제학습3CV+전체재학습4회를 확인하고 모든 보정 학습·평가 시행의 교집합0,전체 OOF창 포함을 검사한다. 최종보정확률·열순서·64→8합산·지표를 복원하고 내부선택을 다시 계산한다. 공개 가능한 결과는 전체집계뿐이며 외부 게시하지 않는다.

학습 종료 후 내부fold0의 현재 XGB/LDA와 SVM 두 조건을 동일256개 개발창·CPU환경·20예열·200회batch1로 측정한다. SVM은 libsvm의 CPU 단일 스레드 경로임을 명시한다. 특징+scaler+실제보정확률+8합산을 포함하고 취득200ms·모델로딩은 제외한다. 선택된바깥SVM이있으면첫해당fold도비교한다.크기·실제학습시간·추론중앙값/p95를 함께 보고한다.

반복 내부 선택, 과거 바깥 평가와 특징 설계의 노출은 남는다. 19겹친창을 독립 표본으로 삼지 않고 새 일반화·논문 정확재현으로 표현하지 않는다. 410특징 SVM 한 설정의 대조이지 SVM 전체에 대한 판정이 아니다.
