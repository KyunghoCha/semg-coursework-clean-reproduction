# 원인 분리와 창 길이 대조

이 단계는 새 모델 점수 전에 고정한 여섯 조건을 개발 자료에서 검증한다. 진행 중인 2차 중첩 평가의 선택 규칙과 결과를 변경하지 않는다. 2차 첫 내부 비교에서 ZC 교체와 시간 특징 추가는 약 58%로 기준과 비슷했고, 채널 관계는 약 65%, 대역 특징은 약 74%로 상승했다. 독립 감사의 과거 문맥 집계도 별도 코드로 재현했다. 이제 관찰된 효과를 더 좁혀 확인한다.

## 공통 조건

원래 개발 1,536시행의 층화 5-fold(seed 42)를 그대로 사용해 기존 clean 실험과 짝을 맞춘다. 고정 시험 384시행은 제외한다. 기존 개발 자료와 분할을 반복 사용하는 원인 분석이며, 독립 시험이나 선택 편향이 보정된 최종 성능으로 부르지 않는다. 기존 200ms 19창과 300ms 18창 기준은 이미 검증된 clean 프로젝트의 결과를 대조값으로 사용한다. 이전 실패 프로젝트의 결과는 사용하지 않는다.

모든 새 모델은 강의 XGB400 설정(깊이 6, lr .05, subsample .9, colsample .8, lambda 1, hist, CUDA, seed 42)과 학습 창에만 fit한 StandardScaler를 사용한다. 같은 피험자·채널·조건·분할 시행을 모두 유지한다. 같은 출력 파일을 덮어쓰지 않는다.

## 고정 대조

1. `ZC_added_200_19`: 원래 25개 특징에 무임계값 ZC 5개만 추가한다. 기존 임계값 ZC를 보존한 보완 효과를 확인한다. 낮은 진폭에서도 교차가 존재한다는 사실과 분류에 유용하다는 주장은 구분한다.
2. `base_200_18`: 학습과 평가 모두 첫 18개 시작 위치 1.5–3.2초만 사용한다. 기존 `XGB_win300`도 이 18위치이므로 창 길이 이외의 학습 위치를 통제한다. 원래 19창 주평가와는 별도 조건이다.
3. `spectrum_200_18`: 위 200ms 18창에 2차 계획의 95개 주파수 특징을 추가한다.
4. `spectrum_300_18`: 동일한 18시작 위치에서 300ms의 25개 시간 특징과 95개 주파수 특징을 사용한다. 200ms와 300ms 모두 FFT의 실제 주파수 간격으로 전력을 적분한다. 창 길이와 주파수 특징의 효과를 나눠 비교한다.
5. `spectrum_200_19`: 원래 19창에 주파수 특징을 추가한 대조군이다.
6. `spectrum_no60_200_19`: 각각의 200ms 원창에서 60Hz 사인·코사인의 최소제곱 투영 성분만 빼고 25+95개 특징을 다시 계산한다. 창 밖 신호나 미래 창을 사용하지 않는다. 이는 기존 필터를 재현한다는 뜻이 아니라 60Hz 성분에 대한 민감도 실험이다. 해당 주파수의 생리 신호도 제거될 수 있으므로 성능 하락을 곧바로 잡음 의존으로 단정하지 않는다. 원래 단독 창과 비교할 수 있는 동일한 200표본 입력이다.

주파수 대역은 0–20, 20–50, 50–100, 100–150, 150–250, 250–350, 350–450, 450–500Hz다. 오른쪽 끝 제외, 마지막 대역은 Nyquist 포함. Hann, detrend constant, PSD 합 × 실제 주파수 간격을 절대 전력으로 사용한다. 상대 전력, MNF, MDF, 정규화 엔트로피 정의는 2차 계획과 같다. eps=1e-12다.

## 판단 규칙

각 대조는 5개 fold의 창 정확도 차이와 각도·동작 오류, 시작 위치별 차이를 함께 보고한다. ZC 추가의 이득이 작거나 방향이 일관되지 않으면 ZC 임계값을 주요 병목으로 삼지 않는다. 학습 위치를 맞춘 후에도 300ms 이득이 남는지, 주파수 특징의 추가 이득이 두 길이에서 남는지 확인한다. 60Hz 제거의 변화는 성분 민감도로 해석하며 전처리 구현 오류나 생리적 원인을 단정하지 않는다.

여섯 조건의 최고 수치만 채택하지 않는다. 다음 모델 선택을 진행할 경우 이 결과를 근거로 범위와 규칙을 다시 고정하며, 이번 반복 개발의 이력을 계속 명시한다. 과거 문맥 결과는 각 단독 창 결과와 따로 보고한다. 논문 전문이 없는 상태에서 정확 재현을 선언하지 않는다.
