# 활동 구간 기록 대조 완료

고정 직접8클래스 XGB400·19창으로905특징8fit와기본25특징8fit를 완료했다. 기본25대조는905의 기록 분리 실패를 본 뒤 등록한 사후 진단이다. 개발1,536시행만 사용하고 기존384시험은 제외했다.

기본25는기록공유18,116/29,184=62.0751%,기록분리2,585/29,184=8.8576%다.905는25,435/29,184=87.1539%,1,973/29,184=6.7606%다. 클래스당3,648평가창,학습·평가8클래스 모두 존재한다.16개 모델 CPU복원,확률열,scaler,분할독립재구성,정수지표 검증을 통과했다.

기록전이는 주파수 확장 이전부터 낮았다. 사람×조건별기록 하나이므로 기록특성·개인별조건반응·획득조건을 분리할 수 없다. 이 직접8목표3200트리 점수를64목표25600트리 모델의 정확한 기록분리 성능으로 대체하지 않는다.
