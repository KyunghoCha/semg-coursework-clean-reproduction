# 활동 구간 기록 대조에 기본25특징을 복원

905특징의 고정 활동 대조가 시행 분리87.1539%,기록 분리6.7606%임을 확인한 뒤 설계한 사후 진단이다. 이 결과를 처음부터 정한 독립 확증 실험으로 표시하지 않는다. 특징 확장의 이득이 기록을 공유하는 조건에서만 나타나는지 확인한다.

기존 활동 대조의 분할8개,모든 개발1,536시행,mark+1.5–3.5초,200ms·19창·5채널,직접8클래스 XGB400 설정을 그대로 유지한다. 입력만 최초 기준 캐시의25특징(RMS/MAV/WL/ZC/SSC)으로 복원한다. ZC 임계값0.01·SSC 무임계값도 강의 기준 그대로다. 총8fit이며 다른 특징·모델·하이퍼파라미터를 탐색하지 않는다. 원래384시험은 제외한다. 출력은 별도 private/results의active_record_baseline에만 저장한다.

기존 CPU 비용 측정이 끝난 뒤 순차 실행한다. 각 분할의 학습 부분만으로 scaler를 fit하고8개 확률 열,정수 지표,클래스·사람 지원 수,학습·평가 기록 교집합,저장 모델 복원을 검사한다. 두 표현의 같은 분할 결과를 모두 보고하며 이 진단으로 주평가 후보를 다시 고르지 않는다.8개 목표400회 모델의 진단을64개 목표 개선 모델의 정확한 기록 일반화 점수로 대체하지 않는다.
