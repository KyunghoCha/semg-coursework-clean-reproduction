# 활동 구간의 기록 의존성 고정 대조

초기창의 기록 분리2.60%만으로 활동 구간19창의 일반화를 결론 낼 수 없다. 기존 개발 자료의 활동 구간에서 기록을 공유했을 때와 제외했을 때 같은 분류기가 어떻게 달라지는지 확인한다. v10의 마지막 내부 direct8 학습 중에 이 계획을 고정했으며, 활동 구간의 기록 분리 결과는 아직 없다. v10–v13의 후보 선택과 결과는 변경하지 않는다.

조건은 두 프로토콜뿐이다. 초기창 진단과 같은 시행 분리4-fold와 클래스별 기록6개 학습·2개 평가의 기록 분리4-fold(seed20261116)를 재사용한다. 총8회 새 학습이다. 개발1,536시행을 프로토콜마다 정확히 한 번 평가하고 기존384시험은 제외한다. 전체1,920시행에서 이미 준비한 특징을 그대로 읽고 새로운 표본 제거·특징 선택·정렬·필터·정규화 정의 변경을 하지 않는다.

입력은 mark+1.5–3.5초의19개200ms창,100ms이동,5채널,905특징이다. 직접8클래스 XGB400,깊이6,lr.05,subsample.9,colsample.8,lambda1,seed42,CUDA6스레드와 학습 부분만의 StandardScaler를 쓴다. 원래 강의와 초기창 대조의400회를 유지한다. 각 모델은3,200트리다. 이 모델은64개 목표25,600트리 개선 모델과 다르므로 이 진단을 그 모델의 기록 일반화 점수로 표시하지 않는다. 기록을 제외하면 사람×조건 조합의 학습 목표64개 일부도 사라지므로64개 모델을 분할만 바꿔 동등하게 적용했다고 주장하지 않는다.

주지표는 모든 활동창의8클래스 정확도다. 시행별 다수결·선택창 점수로 대체하지 않는다. 각 클래스의 학습·평가 지원 수, 기록·시행 교집합, 확률 열, 학습 scaler, 저장 모델 복원, 정수 혼동행렬을 검증한다. 창이 같은 시행 안에서 겹치므로 창을 독립 표본으로 보는 유의성 검정은 하지 않는다. 학습 시간·실제 저장 크기도 남긴다.

기록 분리에서도 활동창 점수가 유지된다면 초기창 결과만으로 활동구간 전체가 기록 특성에 의존한다는 가설은 약해진다. 크게 하락하면 이 고정 분류기의 기록 간 전이 제한을 확인한 것이다. 신호 기원·생리적 휴식·필터 인과성·새 사람 일반화를 입증하는 실험은 아니다. 결과가 낮아도 분할·조건·학습량을 바꾸지 않는다. 이전 외부 시험처럼 부르지 않으며 새 정확도 선택에는 사용하지 않는다.
