# 개발 특징의 집단 간 거리 진단

개발 1,536시행만 사용해 특징별 진단용 표준화 후 시행 평균을 계산했다. 사람과 8클래스 조합별 중심 사이의 평균 제곱 거리를 비교했다. 이 표준화와 중심은 예측 모델의 특징이나 전처리로 사용하지 않는다. 개인별 중심은 비공개 로컬에만 저장한다.

같은 클래스의 사람 간 거리는 한 사람 안의 서로 다른 클래스 거리보다 전체 특징에서 1.67배, 채널 관계에서 2.06배, 주파수 특징에서 2.14배였다. 따라서 같은 클래스도 여러 집단으로 분산되어 있을 가능성이 있다. 각 사람·조건이 한 기록에 대응하므로 생리적 개인차와 기록 차이를 분리한 증거는 아니다.

공간 공분산으로 집단 간 차이를 다룬 [Gowda와 Miller의 논문](https://arxiv.org/html/2311.08548v2)에서 표현의 아이디어를 참고했다. 그 연구는 전체 제스처 길이와 다른 데이터·채널 수를 사용하므로 보고 정확도를 여기로 옮기지 않는다. 여기서는 현재 개발 자료의 거리 진단을 근거로 학습 목표를 더 세분하는 별도 대조를 설계한다.
