# 대역별 채널 관계와 학습 목표의 용량 대조

주파수 특징과 전체 채널 관계는 개발 자료에서 각각 이득이 있었다. 그러나 기존 240특징에는 특정 대역의 두 채널이 같은 위상으로 변하는지 표현하는 항목이 없다. 앞선 하위 클래스 실험의 첫 두 분할에서 약 5%p 상승했으나 학습 클래스 수와 트리 수도 동시에 늘었다. 이번에는 빠진 채널·주파수 상호작용과 학습 목표의 용량 차이를 분리한다. 아래 조건은 이번 분할의 학습·평가 전에 고정한다.

모든 입력은 고정 1.5–3.5초, 200ms 창, 100ms 이동, 19창, 5채널이다. 창을 제외하거나 이전·미래 신호를 단독 창 입력에 추가하지 않는다. 기존 240특징은 그대로 보존한다.

## 추가 특징 160개

각 채널의 현재 200표본에서 평균을 빼고 periodic Hann을 곱해 rFFT한다. DC와 Nyquist를 제외한 한쪽 주파수 계수에 sqrt(2)를 곱한다. 기존과 같은 8대역(0–20, 20–50, 50–100, 100–150, 150–250, 250–350, 350–450, 450–501Hz)의 채널 쌍 10개에 대해 다음을 계산한다.

`C_ab(B) = sum(conj(Z_a) * Z_b) / sqrt(sum(abs(Z_a)^2) * sum(abs(Z_b)^2))`

합은 해당 대역 안의 FFT bin에 대해 계산한다. 실수부 80개와 허수부 80개를 연결한다. 분모가 1e-20 이하이거나 두 채널 중 하나의 대역 파워가 해당 채널 전체 파워의 1e-12 이하이면 0으로 놓는다. 이는 원 FFT 제곱 단위의 나눗셈과 수치 누설을 보호하는 기준이며 생리적 잡음 임계값으로 해석하지 않는다. 절댓값은 Cauchy–Schwarz 부등식에 따라 1 이하이며 반올림 허용오차를 검사한다. 특징 순서는 대역, 채널 쌍 순서이고 실수 블록 다음 허수 블록이다.

학습 전 합성 검증에서 대역 밖에 파워가 없는 순수 사인파의 부동소수점 잔차를 정규화하면 진폭 배율 불변성이 깨지는 문제를 발견했다. 분모 절대값만 보호하던 구현에 위의 채널별 상대 파워 기준을 추가했다. 실제 자료의 결과를 보고 정한 기준이 아니다.

이 값은 대역 안에서 합산한 복소 교차 스펙트럼의 정규화값이다. Welch coherence나 여러 독립 구간으로 평균한 추정량이라고 부르지 않는다. 복소 공액 방향은 [SciPy CSD 설명](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.csd.html)의 conj(X)Y와 같다. SciPy의 한 구간 CSD/PSD를 이용한 별도 계산, 동일·직교 위상 합성파, 무신호, 양의 진폭배율, 창 경계 검사를 한다.

## 세 고정 조건

1. `global8_3200`: 기존 240특징, 직접 8클래스 목표, 3,200 boosting rounds = 25,600트리.
2. `subclass64_400`: 기존 240특징, 학습 사람×8클래스 목표, 400 rounds = 25,600트리. 평가 때 신호만으로 얻은 64개 확률을 원래 클래스별로 합산한다.
3. `subclass64_cross400`: 기존 240+교차 특징160=400특징, 두 번째와 같은 목표와 모델.

모두 XGB 깊이6, lr .05, subsample .9, colsample .8, lambda1, hist CUDA, seed42, n_jobs6이다. StandardScaler는 해당 학습 창에서만 fit한다. 트리 수 대조는 전체 트리 개수를 맞추며, 각 클래스에 투입된 boosting 단계와 손실 구조·실제 파일 크기까지 같게 만들지는 않는다. 특징 추가 대조에서는 전체 특징 중 80%를 쓰는 동일 비율을 유지하므로 후보 특징 개수도 늘어난다.

기존 개발 1,536시행만 사용해 층화 3-fold seed20261031을 고정한다. 세 조건을 같은 학습 1,024시행, 평가 512시행에서 비교해 총 9회 학습한다. 기존 고정 시험 384시행은 제외한다. 내부 튜닝은 없으며 세 조건 모두 끝낸다. 주지표는 8클래스 독립 창 정확도다. 과거 5창 결과는 별도 문맥 조건으로 기록하며 모델 선택이나 목표 달성 선언에 사용하지 않는다.

이 자료는 반복 개발에 사용됐고 같은 사람·기록의 시행이 양쪽에 존재한다. 새 seed도 독립 외부 검증을 만들지 않는다. 교차 성분이 유용하더라도 근육 간 생리적 결합이나 새로운 기록 일반화로 단정하지 않는다. 특히 공통 전원 성분·전극·기록 차이와 분리되지 않는다. 특징 추가가 세 fold에서 일관되게 작거나 음수이면 해당 가설을 약화시키고 단순히 특징 수를 더 늘리지 않는다. 학습 목표 효과는 첫째와 둘째 조건, 추가 특징 효과는 둘째와 셋째 조건에서 판단한다.
