# 같은 트리 수와 대역별 관계 결과

3개 분할 9회 모두 완료했다. 동일 25,600개 트리에서 직접 8클래스 목표는 83.82±0.87%,64개 학습 목표를 원래 8클래스로 합산한 모델은 85.58±0.52%였다. 같은 트리 수에서도 평균 1.76%p의 차이가 남았으나 클래스별 boosting 단계, 손실 구조, 실제 노드 수까지 같지는 않다.

추가 160개의 대역별 복소 채널 관계를 넣으면 88.39±0.24%였다. 세 분할은 88.11/88.69/88.37%로 모두 상승했다. 같은 29,184개 창에서 24,977→25,796개 창을 맞혀 819개가 늘었다. macro F1은 0.8839, 각도 94.34%, 동작 91.14%였다. 원래 8클래스 조합의 정확도 88.39%가 주지표다. 과거 5개 창 문맥을 쓴 94.84%는 최대 600ms 이력을 추가한 별도 조건이다.

첫 분할의 모델 크기는 직접 8클래스 53.68MB, 하위 목표 41.72MB, 교차 특징 38.71MB였다. 트리 수가 같아도 실제 분할 노드와 말단 수가 달라 크기가 달랐다. 전체 9개 모델 복원 확률, scaler, 정수 혼동행렬 지표, 원래 8클래스 확률 합산과 시험 제외 검사가 일치했다.

첫 모델의 학습 gain이 250–350Hz의 정규화된 관계에 많이 배분됐지만 그 대역의 평균 상대 파워는약 0.4–0.7%였다. 유용한 예측 정보의 물리적 기원은 미확인이다. 근육 간 생리적 결합으로 단정하지 않는다. 전체 분할의 학습 gain과 개발 파워는 `training_gain_by_fold.csv`, `high_band_power.csv`에 집계했다. `2c48944`에서 400/800회와 해당 관계 20개 제외의 재학습 비교를 사전 등록했다. 고정 시험 384시행은 추가 평가하지 않았다.
