# 복구한 특징에서 남은 모델 병목 확인

2차의 첫 두 중첩 평가에서 단독 200ms 창 정확도는 약 82%로 올랐다. 과거 문맥을 쓰면 90%대였지만 입력 이력이 늘어난 결과다. 단독 창의 성능을 더 높일 근거를 확인하기 위해 아래 다섯 후보만 추가한다. 이 계획은 해당 후보의 새 점수를 보기 전에 고정한다. 3차의 원인 분리 실험과 구분한다.

## 근거와 후보

주파수와 채널 관계를 추가했을 때 내부 성능이 크게 올랐고, 결합 특징에서 400→800회의 이득도 첫 두 내부 묶음에서 약 2%p였다. 따라서 단순히 처음부터 트리 수를 늘리는 대신, 정보 복구 이후의 학습 용량을 한 단계만 더 확인한다. 기본 25특징의 SVM 결과만으로 풍부한 특징 공간에서도 SVM이 낮다고 결론 내릴 수 없으므로 곡선형 결정 경계를 함께 비교한다. 시간 특징 85개의 단독 추가 효과가 작았기에 결합 안에서의 기여도 한 번 분리한다.

1. `XGB_rich800`: 2차의 240특징, 800회 대조군.
2. `XGB_rich1600`: 240특징, 1600회. 회수만 변경한다.
3. `XGB_noTime800`: 기본25+채널관계35+주파수95=155특징, 800회. 2차의 추가 시간 특징85개만 제외한다. 원래 25특징과 모든 채널은 유지한다.
4. `SVM_rich_standard`: 240특징, StandardScaler, RBF C=100, gamma=scale, cache_size=1024MB, probability=False.
5. `SVM_rich_quantile`: 위와 같은 SVM에서 변환만 QuantileTransformer(n_quantiles=min(1000,학습창수), output_distribution=normal, subsample=None, random_state=42)로 바꾼다.

모든 XGB의 나머지 설정은 깊이6, lr .05, subsample .9, colsample .8, lambda1, hist, CUDA, seed42, n_jobs6이다. XGB도 학습 창으로만 StandardScaler를 fit한다. 모든 후보가 원래 mark+1.5–3.5초, 200ms/100ms, 19창, 5채널을 사용한다. 시행 ID나 시간 위치, 정답, 파일명은 특징으로 넣지 않는다. SVM은 설치된 scikit-learn의 CPU 구현, XGB는 TITAN Xp CUDA를 쓴다. 공식 API 근거: [SVC 1.7.2](https://scikit-learn.org/1.7/modules/generated/sklearn.svm.SVC.html), [XGBoost 3.0.5 설정](https://xgboost.readthedocs.io/en/release_3.0.0/parameter.html).

## 평가와 선택

기존 개발 1,536시행 안에 새 outer 3-fold(seed20261024), inner 3-fold(seed20261025+outer 번호)를 만든다. 이전 바깥 fold를 새 후보 선택에 다시 쓰지 않는다. 이 자료 자체는 이전 분석과 평가에 이미 사용됐으며, 새 seed가 독립 데이터를 만드는 것은 아니다. 반복 개발의 선택 편향은 여전히 남는다.

각 outer의 학습 부분에서만 다섯 후보의 inner 평균 단독 창 정확도를 비교한다. 최대값을 선택하고 동률은 위 순서를 따른다. 해당 outer 평가에는 선택 모델과 `XGB_rich800` 대조군만 사용한다. 후보별 학습 정확도도 저장해 용량 확대가 단순 학습 암기에 그치는지 확인한다. 기존 고정 시험 384시행은 전부 제외한다. 첫 두 outer 결과가 좋거나 나쁘다는 이유로 마지막 fold를 생략하거나 후보를 바꾸지 않는다.

고정 과거 5창 집계는 보조 문맥 조건으로만 함께 계산한다. 모델 선택은 단독 창 정확도로 한다. 단독 창 평균, macro F1, 각도·동작 정확도, 문맥을 쓴 결과와 첫 창 손실을 따로 보고한다. 모델과 scaler는 outer마다 비공개 로컬 저장하고 복원 예측을 대조한다.

## 이후 판단

1600회의 이득이 작으면 같은 특징으로 트리를 계속 늘리지 않는다. SVM이 유리하면 변환의 효과와 단독 창의 시간대별 잔여 오류를 확인한다. 시간 특징을 뺀 조건이 떨어지면 단독 추가 효과가 작다는 이유로 결합에서 무익하다고 결론 내리지 않는다. 여전히 단독 창 정보가 부족하고 채널·주파수 기여가 남으면 대역별 채널 관계처럼 빠진 상호작용을 다음 별도 가설로 검토한다. 이번 등록 후보의 개수를 채웠다는 이유로 종료하지 않는다.
