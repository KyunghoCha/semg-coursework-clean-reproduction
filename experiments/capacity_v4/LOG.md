# 용량·시간 특징·SVM 비교 결과

사전 등록한 다섯 후보의 45개 내부 평가와 6개 바깥 평가를 모두 마쳤다. 세 outer 모두 1,600회 XGB를 선택했다. 내부 평균은 rich800 79.79%, rich1600 80.45%, 추가 시간 85개를 뺀 155개 특징 79.73%, 표준화 SVM C100 72.83%, 분위수 SVM C100 73.56%였다. 모든 후보의 학습 정확도는 100%였으므로 학습 정확도만으로 일반화 차이를 판단할 수 없었다.

같은 바깥 평가 29,184개 창에서 800회는 23,936개 정답(82.02%),1,600회는 24,211개 정답(82.96%)이었다. 세 분할에서 모두 상승했지만 평균 이득은 0.94%p였다. 800→1,600회로 모델 크기는 대표 fold에서 21.65→35.88MB, 총 트리는 6,400→12,800으로 늘었다. 초기 특징 복구에서 얻은 큰 상승과 달리 비용 대비 추가 이득이 작았다. 같은 표현의 8클래스 모델을 계속 배수로 키우는 접근을 주된 개선으로 삼지 않는다.

155개 특징 후보는 내부 평균이 240개 특징보다 0.06%p 낮아 거의 같았다. 불필요한 추가 시간 특징 계산을 생략한 비용 대안으로 살펴본다. SVM의 두 변환은 이번 고정 설정에서 충분한 성능을 내지 못했다. 이 결과로 모든 SVM 설정이 불가능하다고 결론 내리지는 않는다.

51회 지표와 scaler를 재계산했고,6개 바깥 모델을 복원해 예측과 학습 정확도가 일치함을 확인했다. 세 선택 규칙과 시행 분리, 기존 시험 384시행 제외도 일치했다. 중간 프로세스 중단 후 미완료 행만 재개했으며 기존 산출물 해시가 유지됐다. 새로운 외부 시험이 아니라 반복 개발 자료의 중첩 평가다.
