# 두 정현파 성분을 신호에서 제거하는 대조

v8 초기 기준창 진단은 mark+0.0–0.2초에서도 90.43%를 보였다. 300Hz·420Hz의 로그 파워는 초기와 후기 모두 큰 기록 간 차이를 보였다. v9의 특징 열 제거는 인접 bin·기존 대역·교차 특징의 관련 정보를 남기므로, 다음에는 신호 자체의 두 정현파 성분을 제거해 의존 범위를 검사한다. 원신호가 잡음이라는 결론을 전제로 하지 않는다.

각 원래 200ms 창을 독립 처리한다. fs1000, n=0..199에서 300Hz와 420Hz의 sin/cos 네 열을 만들고 QR로 정규직교화한 Q를 쓴다. 각 채널 x에서 Q(Qᵀx)를 뺀다. 네 성분의 최소제곱 투영이며 학습할 파라미터·정답·다른 창을 쓰지 않는다. 원래 현재 창의 끝보다 뒤를 보지 않는다. 인접 주파수와 다른 60Hz 배수는 제거하지 않으므로 전원 성분 전체가 사라졌다고 주장하지 않는다. 같은 주파수의 생리 신호도 함께 제거될 수 있다.

합성 300/420Hz 혼합 제거, 직교하는 75Hz 보존, 잔차 직교성, 영신호, 창별 독립성을 먼저 검사한다. 변환한 창에서 v8의 905특징 전체를 같은 공식으로 다시 계산한다. 기존 특징 캐시는 덮어쓰지 않는다. 원래 1.5–3.5초, 200ms·100ms 이동·19창, 모든 5채널과 1,920시행을 변환하고 학습·평가에는 기존 개발 1,536시행만 사용한다.

v7/v8의 동일 3개 시행 분할을 쓴다. scaler는 각 학습 창에만 맞추고 XGB 64개 목표·400회·깊이6·lr .05·subsample .9·colsample .8·lambda1·seed42·CUDA·6스레드, 25,600트리를 유지한다. 후보는 투영 제거 하나로 3회 학습하며 v8의 고정 대조 3회를 재사용한다. 원래 384시행 시험은 평가하지 않는다. 모든 창을 주평가하고 문맥 점수는 별도로 기록한다.

이것은 정확도를 높이기 위한 숨은 구간 선택이 아니라 성분 의존을 확인하는 실패 가능 대조다. 점수가 낮아져도 모두 보고한다. 제거 여부에 따른 차이만으로 성분의 생리적 기원이나 데이터 불량을 확정하지 않는다. 이 결과는 사전에 고정한 v10 후보 선택 절차에 섞지 않는다. v9와 v10의 실행·검증을 마친 뒤 별도로 진행한다. 관측 학습 시간과 저장 크기도 남긴다.
