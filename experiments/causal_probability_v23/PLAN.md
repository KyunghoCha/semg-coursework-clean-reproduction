# v23: 현재 v21 확률의 인과적 시간 평균

2026-10-21 UTC, 결과 계산 전에 고정한다. 목표는 같은 시행의 일시적인 창 오류를 과거 증거로 줄일 수 있는지 확인하는 것이다. 새 모델 학습은 없다. 초기 개발뿐 아니라 v5–v11에도 과거5창 하드 라벨 다수결이 이미 있었음을 코드에서 확인했다. 현재 v21의 확률 평균과 k=1/3/5 내부 선택은 미실행이며, 기존 다수결을 다시 실행하는 대조는 하지 않는다.

## 고정 입력과 수식

이미 검증된 v21의 XGB/LDA/SVM 비중64/16/20을 그대로 사용한다. 내부 확률은 기존 v19 확률과 v20 SVM 확률을 고정 비중으로 합하고, 바깥은 private/svm_blend_v21/outer_selected_{fold}.npz의 원래8확률을 사용한다. 시행별19행의 순서는 생산 코드의 reshape와 저장 split에 맞춰 확인한다. 정답으로 정렬하거나 경계를 추론하지 않는다. 원래384시험은 제외한다.

후보는 k=1,3,5뿐이다. 시행 t의 창 j에서 qbar[t,j]는 q[t,max(0,j-k+1):j+1]의 산술평균이다. 사용 가능한 과거가 k보다 적으면 실제 보유 개수로 나눈다. 첫 창은 현재 확률만 쓰며 모든19창을 평가한다. 각 시행 시작에서 상태를 반드시 초기화한다. 미래 창, 전체 시행 평균, 정답 레이블은 업데이트에 사용하지 않는다. 확률 argmax의 동률은 가장 작은 클래스 번호로 처리한다.

각 현재 창은200ms, stride는100ms다. j번째 출력의 실제 신호 범위는200+100*min(j,k-1)ms이며 최대200/400/600ms다. mark+1.5초에서 시작하는 첫 창의 신호 종료는+1.7초다. k3의 완성된 과거는+1.9초, k5는+2.1초부터 사용하지만 첫 창부터 출력하므로 이때까지 기다리지 않는다. 미래 대기시간은 추가하지 않는다. 과거 정보를 쓰면서 발생할 수 있는 동작 전환 응답 지연은 정적 시행 자료로 측정하지 못한다. 알려진 시행 경계가 필요한 평가이며 실제 경계 자동 검출이나 무구간 연속 동작 실험이 아니다.

## 선택과 평가

기존 v10 내부3분할의 각256평가시행에서 정답 창 수가 가장 큰 k를 고르고 동률은 작은 k를 선택한다. 모든3후보의 결과를 남긴다. 내부 합산 점수의 공통 선택도 기술 통계로만 남기며, 바깥에는 각 내부 분할에서 선택한 k를 그대로 쓴다. 선택 파일을 먼저 저장하고 해시를 고정한 뒤 바깥3분할을 계산한다. 바깥 결과로 k나 확률 평균 방식을 바꾸지 않는다.

바깥에서는 k1과 선택 k만 비교한다. 전체1,536개발시행·29,184창을 유지한다. 원래 단일200ms의91.3857%는 변경하지 않고, 이 실험의400/600ms 범위는 별도 조건으로 보고한다. 내부 관측14,592개는 전체 OOF가 아니며 같은 시행이 중복 관측될 수 있다. 과거 특징 설계·반복 CV·이전 바깥 결과 노출과64목표/64기록 일대일의 한계도 남는다.

전후 창 정확도·macro F1·각도/동작 정확도, 수정/손실, 창 위치별 오류,8클래스 혼동행렬, 시행 안의 연속 오류 길이 분포를 보존한다. 첫 창 변화는0이어야 한다.19겹친 창을 독립 표본으로 유의성 검정하지 않는다.

## 검증·비용·상태

고정 크기 NumPy 링 버퍼에 최근 k개의8확률을 저장한다. float64 확률 payload는64*k바이트이고 cursor/count 및 Python객체 비용은 별도로 기록한다. 평균 업데이트는 미래를 보지 않는다. 독립적인 슬라이스/스칼라 합과 모든 내부·바깥 확률/라벨을 대조하고, 미래 구간을 바꿔도 이전 출력이 같음과 시행 간 reset을 검사한다. k1은 v21 지표와 정확히 일치해야 한다. 원본 모델·확률 파일은 해시로 보존을 확인한다.

확률 평균은 매창의 전체 v21 확률을 요구하므로 v22 라벨 전용 호출 생략을 사용하지 않는다. 첫 번째 k>1 선택 바깥fold(없으면fold0)를 대표로 고른다. 해당 평가의 첫20시행×19창=380창을 순서대로 모두 사용해 k1과 선택k의 실제 특징+세모델 확률+평균+라벨 지연을 CPU에서 비교한다. 한 시행19창으로 예열하고 시행 경계를 그대로 초기화한다. 선택k=1이면 중복 측정하지 않는다. 모델 로딩·CSV읽기·취득200ms는 제외하고 중앙값·평균·p95를 기록한다. 평균 업데이트만의 시간은 대표fold의 모든512시행×19창을1회씩 실행해 별도 측정한다. 이 분포는 독립 반복실험의CI가 아니다.

예상 새 fit는0, 저장 확률 집계·검증은수초, CPU 전체 경로380창×최대2조건은약30–60초다. 실제시간과부가메모리를기록한다. 미래대기0과동작전환응답지연미측정을구분한다. 원신호·모델·개별예측은private에두고공개push/upload는계속금지한다. 승인대기v19ZIP도바꾸지않는다.
