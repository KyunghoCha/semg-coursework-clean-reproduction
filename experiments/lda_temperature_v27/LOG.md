# LDA 확률 완화 대조 완료 기록

명세·구현을 28e474e에 고정한 뒤 실행했다. 기존 v25 모델과 beta .4/.2/.3을 유지하고 LDA의 8확률에만 T1/1.5/2를 적용했다. 새 학습0이다. 내부 정답 최대·동률시 작은T 규칙으로 1.5/1/2를 선택했고 선택 해시를 먼저 고정했다.

내부 정답 13,330→13,334개였지만 바깥 정답은 26,844→26,838개로 6개 줄었다. 정확도 91.9613±0.5138%, 오답 수정 24·정답 손실 30다. 전체 개발 1,536시행·19창을 유지했다. 바깥 결과를 보고 T나 beta를 다시 고르지 않았다. 현재 유지할 결과는 기존 v25이며 이 실패도 보존한다.

독립 거듭제곱 공식과 직접 클래스 인덱스 합산으로 검증했다. 최초 NLL 검사 1e−12에서 최대 5.5523e−10 차이가 발생했다. float32 합산 순서 차이를 확인하고 NLL 허용오차만 1e−8로 변경했다. 라벨 일치·지표·선택·분할 검사는 그대로 유지하고 모두 통과했다. 원래 실패 로그 verify_first.log와 최종 verify.log는 비공개 경로에 남겼으며 생산된 결과 파일은 수정하지 않았다.

대표 fold0 모델 합은 138.5073 MB, 원래 학습 합331.3527초로 같다. 전체 확률 380창에서 T1 중앙값 43.2841 ms, 선택T 중앙값 44.4713 ms·평균 48.4003 ms·p95 79.1368 ms다. CPU6라이브러리스레드·SVM 단일, 현재 특징과 모델·변환 포함, 로딩/CSV/신호 취득 제외다. 라벨 전용 생략은 측정하지 않았다. 원시 통계·대표 CPU 확률·소스 모델 해시를 확인했다.

v26 결과와 결합하지 않았고 원래384시험은 평가하지 않았다. 64기록 공유·반복 내부 선택·독립 시험 부재를 유지한다. 원논문의 NLL 기반 신경망 온도 최적화와 동일하다고 주장하지 않는다. 외부 게시/업로드는 하지 않았다.
