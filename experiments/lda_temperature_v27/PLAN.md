# 현재 창의 LDA 확률 완화 대조

2026-10-22 UTC, 후보 계산 전 고정한다. 기준은 v25의 저장된 XGB800/LDA/SVM과 내부 선택 beta .4/.2/.3이다. 진행 중인 v26 PCA 결과와 조합하거나 그 바깥 오류로 후보를 고르지 않는다. 새 학습은 없다.

## 내부 근거

v25 내부 예측에서 LDA의 정확도는 79.11–80.12%인데 평균 최고 확률은 92.56–92.80%다. 오답에서도 평균 최고 확률이 80.60–81.70%다. 반면 XGB800은 정확도 89.47–91.32%, 최고 확률 평균 89.21–90.21%이고 SVM은 86.12–86.35%, 66.61–68.25%다. 이 기술 통계는 LDA 확률이 지나치게 강할 가능성을 보여 주며, 완전한 보정 진단이나 원인 증명은 아니다. 최신 결합 오류 1,262개 중 682개에서는 구성 모델 중 하나가 맞혔다. 클래스 쌍은 넓게 분산돼 있으며 새 분류기보다 작은 확률 변환을 먼저 검증할 근거가 있다.

기존 실험은 SVM sigmoid 보정과 선형 확률 비중 선택을 했지만 LDA의 온도 변환은 하지 않았다. [Guo 등, ICML 2017 원문 6쪽 식 (9)](https://proceedings.mlr.press/v70/guo17a/guo17a.pdf)는 온도로 softmax 출력을 완화하고 단독 argmax를 보존하는 원리를 설명한다. 해당 연구는 신경망의 logit과 검증 NLL 최적화를 다룬다. 이번에는 전통 ML의 64→8 합산 확률을 변환하고 결합 창 정확도로 고르는 별도 대조이므로 그 논문의 학습 절차나 성능을 재현한다고 쓰지 않는다.

## 고정 수식과 범위

현재 200 ms×5채널·100 ms 이동·19창, 기존 개발 1,536시행과 모든 64기록, 원래 내부/바깥 시행 분할을 유지한다. 기록 ID·시행 경계·창 위치·과거·미래 입력은 없다. 과거 노출된 384시험은 다시 평가하지 않는다. v23 최대 600 ms와 v26 PCA는 따로 보존한다.

64확률을 기존 사람 축으로 합쳐 8확률 p를 만든 뒤 **LDA에만** `s_c=max(p_c,1e-15)^(1/T) / sum_j max(p_j,1e-15)^(1/T)`를 적용한다. 구현은 log와 안정화 exp를 사용한다. T=1은 원래 p를 그대로 반환해 기준 수치를 정확히 보존한다. 후보는 **T=1, 1.5, 2**뿐이며 XGB/SVM 확률과 beta는 고정한다. 각 현재 창에서만 계산한다. LDA 단독의 argmax는 유지하지만 세 모델의 결합 argmax는 달라질 수 있다.

내부 세 분할 각각에서 결합 정답 창 수가 가장 큰 T를 고른다. 동률이면 T=1, 이후 작은 T다. 선택 파일을 저장·해시 고정한 뒤 바깥 전 29,184창에 적용한다. 내부 9개 후보 계산·새 모델 fit0이며 예상 계산은 수초다. 바깥 결과로 온도 범위·비중·선택 규칙을 바꾸지 않는다. 모든 T의 결합 정답·macro F1·NLL과 LDA NLL을 함께 남기며, 정확도로 선택했으므로 최적 확률 보정이라고 주장하지 않는다.

## 검증과 비용

수식의 별도 직접 거듭제곱 계산, T1 기준 완전 일치, LDA argmax 보존, 유한 확률·합1, 배치·행 순서·미래 행 불변성, 원래 분할·전 19창·기존 시험 교집합0, 원본 모델/예측 해시와 수동 지표를 확인한다. 구성 모델은 기존 v24·v21 복원 검증에 대응하며 대표 CPU 실행도 다시 대조한다.

모델 파일은 그대로이고 분할별 온도 상수만 추가된다. 추가 학습0, 기존 구성 모델의 관측 학습 시간은 그대로다. 첫 T변경 바깥 fold(없으면0)의 같은 첫20평가시행×19창=380창에서 T1과 선택 T의 전체 확률 CPU 특징+모델+온도 변환 지연을 측정한다. 예열19창, 라이브러리6스레드·SVM 단일 스레드, CSV·모델 로딩·신호 취득 제외다. 이 경로는 v22 라벨 생략을 사용하지 않는다. 후속 라벨 비용이 새로 검증되지 않았다면 v25의 6.60 ms를 이 결과의 비용으로 옮겨 쓰지 않는다.

반복 개발 노출, XGB→비중→온도에 같은 내부 자료 재사용, 기록 공유와 64목표의 기록 일대일 관계를 유지한다. 추가 온도 탐색이나 새로운 외부 시험 주장은 하지 않는다. 불리한 결과도 보존하며 외부 게시·업로드는 계속 금지한다.
