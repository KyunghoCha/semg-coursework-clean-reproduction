# 같은 410특징·64목표의 제한된 ExtraTrees 대조

2026-10-22 UTC, 학습 전 고정. 현재 기준은 v25의 91.9819%이며 v26·v27의 실패까지 로컬 1172a88에 보존했다. 새 후보를 v26 PCA 또는 v27 온도와 합치지 않는다.

## 중복 확인과 근거

기존 forest_transfer_v13/run.py는 905특징으로 y(직접8목표)를 학습했다. 따라서 이를 410특징·64목표 ExtraTrees의 검증으로 취급할 수 없다. v25 내부의 남은 1,262오류 중 682개에서 구성 모델 하나는 맞혔고 오류는 여러 클래스 쌍에 분산돼 있다. 단독 분류기가 낮더라도 상보적 오류가 도움이 됐던 v21의 근거를 바탕으로, 부스팅과 다른 무작위 분할/평균 구조를 같은 64목표에서 한 번만 비교한다. 이 진단은 실제 상보성을 미리 보장하지 않는다.

PCA 추가는 세 내부 분할 모두 악화됐고 LDA 온도는 내부+4·바깥−6이었다. 그 후보를 더 확대하지 않는다. 다음 대조는 새 신호 표현·과거 창·클래스 쌍 보정 대신 기존 410특징을 그대로 쓰는 다른 학습 구조 하나다.

## 예산과 고정 모델

[scikit-learn 1.7.2 공식 문서](https://scikit-learn.org/1.7/modules/generated/sklearn.ensemble.ExtraTreesClassifier.html)의 bootstrap=False 전체 학습 자료 사용, 잎 수 제한, 최소 잎 표본과 병렬 실행을 확인했다. 모델은 ExtraTreesClassifier(n_estimators=128,criterion='gini',max_depth=None,min_samples_split=2,min_samples_leaf=4,max_features=.5,max_leaf_nodes=384,bootstrap=False,class_weight=None,ccp_alpha=0,random_state=42,n_jobs=6,warm_start=False) 한 설정이다. 나머지 전체 get_params도 저장한다. CPU 구현이므로 GPU를 억지로 사용하지 않는다.

128트리·최대384잎은 실행 시간을 맞추기 위한 사후 축소가 아니라 저장 비용을 먼저 제한한 신규 후보다. 설치된 sklearn의 노드 메타데이터64바이트와 64클래스×8바이트 값을 기준으로 최대 tree 배열은 `128×(2×384−1)×(64+64×8)=56,549,376바이트`다. 이는 Python/직렬화 메타데이터를 제외한 상한이며 실제 파일 크기를 따로 검사한다. 기존 내부 전체 결합 약116 MB의 50% 추가 예산 안에서 검증할 수 있도록 정했다. 트리 수나 잎 수를 결과 뒤에 늘리거나 줄이지 않는다. 이 설정 하나의 실패를 무제한 크기 숲 전체의 실패로 확대하지 않는다.

현재200 ms×5채널·100 ms 이동·전19창·전체개발1,536시행·64기록과 기존 v10 분할을 유지한다. 내부768/256시행, 바깥1024/512시행이다. 모든 학습 창을 사용하며 bootstrap=False다. 학습 전용 StandardScaler를 fit하고 기존 사람×8클래스의64목표로 학습한다. 추론 확률을 사람 축으로 합쳐8클래스를 만든다. 기록 ID·창 위치·시행 경계·과거/미래창은 추론 입력이 아니다. 64목표와64기록의 일대일 한계는 그대로다.

새 숲의 비중은 **10%로 고정**하고 `q_new=.9*q_v25+.1*q_forest`만 비교한다. 기존 v25의 분할별 beta .4/.2/.3과 세 모델은 바꾸지 않는다. 내부에서 정답 수가 엄격하게 늘고, 새 숲을 더한 파일 합이 기존 전체 결합의 1.5배 이하일 때만 해당 fold를 선택한다. 동률·비용 초과는 기존 유지다. 내부3fit를 모두 마친 뒤 선택을 저장·해시 고정하고 선택된 fold만 바깥에서 새로 학습한다. 새3–6fit, 예상 CPU수분이며 실제값을 기록한다. 기존384시험은 평가하지 않고 바깥 점수로 규칙을 조정하지 않는다.

## 검증과 비용

128개 트리·잎 상한·최소 잎 표본·64클래스·실제CPU학습·전체창·원래분할·학습전용scaler·원본해시·64→8확률·수동지표·저장모델복원·행순서불변성을 검증한다. 숲 단독 정확도와 학습 재대입은 보조 결과다. 기존 모델을 덮어쓰지 않는다.

첫 선택 바깥 fold(모두 탈락이면 내부fold0)의 같은20평가시행×19창=380창에서 기존3모델과 새4모델 전체확률 경로를 측정한다. 예열19창, CPU라이브러리6스레드·SVM단일·숲추론단일스레드로 고정한다. 숲 학습은6작업이고 추론 단일스레드의 확률 동등성을 확인한다. 특징·scaler·모델·결합 포함, CSV·로딩·신호취득 제외다. 라벨 호출 생략은 이번 후보에서 사용하지 않는다. 학습시간·모델크기·중앙값·평균·p95를 기록한다.

기존 내부 선택의 재사용과 개발 노출을 없애는 실험은 아니다. 기록 공유 조건의 개선과 새 기록 동작 일반화를 구분하며, 논문 전문 부재를 성공 주장으로 대체하지 않는다. 원래모델·v23별도조건·실패결과를 보존한다. 외부push/upload/공개묶음갱신은 계속 금지한다.
