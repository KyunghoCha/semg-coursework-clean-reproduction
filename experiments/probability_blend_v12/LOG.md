# 현재 창 확률 결합 결과

2026-10-21 UTC. v10의 두 표현 모델이 모든 바깥 fold에 있어 추가 학습0회로 기존 모델을 재사용했다.3개 내부 선택 부분에서5개 가중치,총15개 조합을 평가했다. 세 fold와 최종 개발 가중치 모두 좁은 표현의 비중 a=.75를 선택했다. 바깥 점수는 가중치 선택에 쓰지 않았다.

| 같은 바깥3-fold | 정답 / 29,184창 | 평균±SD | 평균 저장 크기 |
|---|---:|---:|---:|
| 전체 표현 하나 | 26,273 | 90.0254±0.4323% | 36.19MB |
| 좁은 표현 하나 | 26,270 | 90.0151±0.4240% | 36.83MB |
| 사전 고정50:50 | 26,364 | 90.3372±0.3820% | 73.02MB |
| 내부 선택25:75 | 26,313 | 90.1624±0.4303% | 73.02MB |

내부 선택 결합은 전체 표현보다40창(+0.1370%p) 높았다. 고정50:50 대조가 바깥 점수는 더 높았으나 이 결과로 a를 바꾸거나50:50을 내부 선택 결과처럼 보고하지 않았다. 선택 결합의 log loss는.29674, Brier sum은.14507로 전체 표현의.30594/.14907보다 낮았다. 개선 폭에 비해 저장 용량이 약 두 배가 되므로 CPU 지연을 함께 판단한다. 두 모델 모두 같은 현재 창만 사용한다.

6개 모델 복원,18개 원본 산출물 해시,확률 합산·가중치 선택의 별도 계산,학습 scaler,모든 개발 시행의1회 평가를 검증했다. 기존384시험의 새 평가0회다. 이는 이미 특징 설계에 사용한 개발 자료이며 새 외부 시험이 아니다.
