# 410특징의 축소 QDA 고정 대조 v17

2026-10-21 UTC, 학습 전 등록. 같은 입력의 특징 간 상관을 클래스별 타원형 경계로 표현하면 XGB의 축별 분할과 다른 오류를 줄일 수 있는지 확인한다. 확장 전 SVM만 확인한 것은 아니다. v4의240특징 RBF C100은 표준화72.8259%,분위수73.5592%로 내부 XGB80.45%보다 낮았다. 현재410특징/AR60의 SVM·QDA는 미수행이며 이번에는410특징의 축소 QDA 한 가지만 추가한다. SVM·여러 축소 강도·여러 입력을 동시에 탐색하지 않는다.

## 출처와 고정 추정법

[scikit-learn1.7.2 QDA 수식](https://scikit-learn.org/1.7/modules/lda_qda.html)의 클래스별 정규분포와 [LedoitWolf](https://scikit-learn.org/1.7/modules/generated/sklearn.covariance.LedoitWolf.html)의 공분산 축소 정의를 읽었다. 실제 설치1.7.2를 유지한다. QDA의 클래스별 공분산을 LedoitWolf로 추정하는 별도 구현이며, sklearn QuadraticDiscriminantAnalysis의 reg_param과 동일하다고 주장하지 않는다.

StandardScaler를 각 학습 창에만 fit한 뒤 클래스별 LedoitWolf(store_precision=False,assume_centered=False)를 fit한다. 공분산은 (1−α)S+α tr(S)/d I이고 α는 해당 클래스 학습자료의 해석적 추정값이다. 검증 점수로 α를 선택하지 않는다. 클래스 평균과 경험적 사전확률 n_k/n도 학습에서만 구한다. 점수는 −0.5 log|Σ_k|−0.5(x−μ_k)'Σ_k⁻¹(x−μ_k)+log prior_k이며 Cholesky 삼각해법과 logsumexp로 계산한다. 작은 고유값에 임의 epsilon을 더하지 않는다. 비유한값이나 Cholesky 실패가 있으면 멈추고 보고하며 결과를 보고 수식을 바꾸지 않는다.

클래스별 표본 수보다410특징이 많을 수 있어 원래 표본공분산의 역행렬을 그대로 쓰지 않는다. 겹치는 창은 독립 표본이 아니므로 LedoitWolf 추정의 이론적 최적성이나 정규성 성립을 보증하지 않는다. 이번 자료에서의 고정 알고리즘 대조다.

## 입력·분할·선택

narrow64의410특징·200ms·100ms 이동·19창·5채널을 그대로 사용한다. 전체1,920시행의 캐시를 유지하고 개발1,536시행에 기존 v10 바깥3분할과 각 내부768학습/256선택 분할을 재사용한다. 기존384시험은 전부 제외한다. 내부3분할은 전체 OOF가 아니다. 시행·창을 subsampling하지 않으며 특징·원시시계열·정규화를 추가 변경하지 않는다.

64목표는 subject_index×8+원래8class다. 기존 XGB와 입력·목표·분할을 맞춘다. 기록 ID를 입력에 추가하지 않지만64목표가64개 기록과 일대일이라는 한계는 유지한다.64개 확률을 사람 축으로 합해8개 확률을 만든다. 기록 분리·미학습 사람에 대한 새로운 성과로 해석하지 않는다.

새 QDA 내부3fit를 모두 끝낸 뒤, 각 fold에서 기존 narrow64와 정확히 같은 내부 창의 정답 수를 비교한다. 더 높을 때만 QDA를 해당 바깥1,024시행에서 다시 학습하고512시행을 평가한다. 동률은 XGB를 유지한다. 바깥 결과로 선택 규칙을 바꾸거나 다른 모델을 추가하지 않는다. QDA가 내부에서 선택되지 않은 fold의 기존 XGB 바깥 결과는 재사용한다. 새fit는3~6회이며, 결과가 약하면 후속 외부 학습을 늘리지 않는다. 모든 개발 시행은 선택 절차의 바깥 평가에 한 번 포함된다.

기존 v10/v15와 같은 내부 자료를 다시 쓰므로 적응적 선택 편향은 남는다. 새 바깥 절차도 미관측 외부 시험이 아니다. 비용에 새 임의 상한을 넣어 선택하지 않으며 성능과 함께 보고한다.

## 검증과 비용

합성 자료에서 SciPy 정규밀도와 확률, 클래스 순서, 고차원·저랭크의 축소 양의정부호,64→8 합산을 검사한다. 실제 저장모델·scaler·분할·학습 목표 지원·확률과 지표를 재계산한다. 학습 자료에서 공분산을 다시 구해 저장 Cholesky와 일치함을 확인한다. 모델과 캐시를 보존하며 클래스/개인별 결과는 private에 둔다.

주지표는 기존 창8class 정확도, 보조로 macro F1 및 동작/각도 정확도다. 같은 내부 평가에서 XGB와 오류가 겹치는 비율도 집계하되 그 결과로 사후 결합은 하지 않는다. 내부와 바깥 정확도를 섞지 않는다.19창을 독립 표본으로 간주한 신뢰구간을 만들지 않는다.

학습은 CPU6스레드이며 GPU는 사용하지 않는다. 신규 모델 크기·실제 fit 시간을 기록한다. 학습 종료 후 내부fold0의 QDA/XGB 두 조건과, 선택된 QDA 바깥fold가 있으면 첫 해당fold의두 조건을 같은256개 고정 개발창으로 측정한다.20회 예열·200회 batch1이며 특징+scaler+확률 추론·64→8 합산을 포함하고200ms신호취득·모델로딩은 제외한다. 이득이 있어도 추가 메모리와 CPU 지연을 함께 판단한다.
