# 초기 기준 구간에 남은 분류 정보

원본 64개 CSV의 SHA-256, 마커와 시행 매핑을 다시 확인했다. 개발 1,536시행의 mark+0.0–0.2초만 새로 추출했다. 고정 시험 384시행에는 예측하지 않았다. v8에서 각 시행을 평가했던 OOF 모델과 scaler를 그대로 사용하고 새 학습은 하지 않았다. 같은 계산으로 원래 마지막 창을 예측했을 때 저장된 결과와 모두 일치했다.

초기 기준창 1,389/1,536개, 90.4297±0.6379%를 맞혔다. 원래 마지막 창 mark+3.3–3.5초는 1,436/1,536개, 93.4896±0.4872%였다. 창 한 개씩의 다른 입력 시점을 비교한 진단이며, 원래 19개 창의 89.7786%를 대체하지 않는다. 초기 구간이 생리적으로 완전한 휴식이라는 증거도 없다.

초기 기준창의 로그 파워 전체 분산 중 기록 사이 평균 차이가 차지하는 비율은 채널 평균으로 300Hz 78.43%, 420Hz 62.75%였다. 원래 마지막 창에서도 각각 78.14%, 60.85%였다. 같은 피험자×조건에 기록이 하나이므로 사람·자세·동작·전극·기록 조건을 분리한 추정은 아니다. 기록별 값이나 개인별 점은 공개하지 않는다.

이는 높은 개발 정확도를 활동 구간의 근육 반응을 인식한 성능으로만 설명하기 어렵다는 증거다. 60Hz 배수의 전원 성분이라는 결론이나 원신호 불량이라는 결론은 아직 내리지 않는다. 실제 신호 성분의 기원을 확인하려면 획득·필터 상세나 독립 기록이 필요하다. 현재 동일 기록 안 시행 분류 목표와, 새 기록에 대한 일반화 질문을 구분해 후속 결과를 해석한다.
