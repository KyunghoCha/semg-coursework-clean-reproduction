# 초기 기준 구간의 주파수 정보 진단

v8의 300Hz·420Hz 파워 의존과 v9 첫 분할의 추가/제거 대조가 확인됐다. 이 두 주파수가 동작 활성과 함께 변하는지, 기록별 차이가 초기 구간에도 남는지 확인한다. 생리 신호·전원·전극·기록의 기원을 미리 결론짓지 않는다.

기존 개발 1,536시행만 분석한다. 원본 CSV를 다시 읽어 해시·마커·시행 매핑을 확인하고 mark+0.0–0.2초의 200ms를 추출한다. 이는 초기 기준 구간이며 생리적으로 완전한 휴식이라고 검증된 구간은 아니다. 원래 crop의 마지막 창 mark+3.3–3.5초와 같은 길이·채널·특징 계산으로 비교한다. 원래 384시험의 신호는 CSV 확인 과정에서 읽힐 수 있으나 진단 통계·예측에는 포함하지 않는다.

1. 채널별 RMS와 300Hz·420Hz 절대/상대 파워의 전체 집계를 비교한다.
2. 동일 피험자×조건의 한 기록 안 분산과 기록 사이 분산을 로그 파워에서 분해한다. 전체 집계만 공개하며 기록별 값은 내보내지 않는다. 이 분해는 사람·동작·각도·기록 효과를 서로 분리하지 못한다.
3. 저장된 v8 바깥 분할 모델을 그대로 복원해 각 개발 시행의 초기 기준창 하나를 해당 OOF 모델로 예측한다. 새 학습·scaler fit·튜닝은 없다. 원래 crop 마지막 창의 예측은 저장 결과와 대조한다. 초기 구간 점수는 입력 시점이 다른 진단으로, 원래 19창 주평가 점수를 대체하지 않는다.

CPU 스레드 상한은 1로 두고 GPU 학습과 별도로 실행한다. 추론 속도를 측정하지 않으므로 이 진단 시간을 성능 벤치마크에 포함하지 않는다. 결과가 높거나 낮아도 원신호 불량이나 레이블 오류로 단정하지 않는다. 이후의 기록 일반화는 별도 질문이며 기존 목표를 대체하지 않는다.
