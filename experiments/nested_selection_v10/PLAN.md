# 후보 선택을 분리한 후속 검증

## 목적과 자료의 사용 이력

v7–v9는 같은 개발 분할에서 원인을 비교했다. v8은 89.7786%였고, 이 계획을 쓰는 시점에는 v9 첫 narrow64 분할의 90.0493%만 확인했다. 나머지 v9 결과와 무관하게 다음 후보 4개를 유지한다. 후보를 고르는 자료와 최종 점수를 계산하는 자료를 분리한 절차가 얼마나 안정적인지 확인한다.

새 분할은 기존 개발 1,536시행 안에서만 만든다. 이 자료는 앞선 특징 설계와 반복 CV에 사용됐으므로, 새 seed와 중첩 구조로 과거의 노출을 없앴다고 주장하지 않는다. 아래 바깥 평가는 이번 선택 절차 안에서 분리한 평가이며 완전 미관측 외부 데이터가 아니다. 원래 384시행 시험은 이 단계 전체에서 사용하지 않는다.

## 고정 후보와 분할

후보는 fine64(905특징·64개 목표·400회), narrow64(410특징·64개 목표·400회), drop_two64(895특징·64개 목표·400회), direct8(905특징·8개 목표·3,200회)다. 모두 총 25,600트리이며 v8/v9의 열 선택, 깊이6, lr .05, subsample .9, colsample .8, lambda1, seed42, CUDA, 6스레드 조건을 그대로 쓴다. 새 특징이나 하이퍼파라미터는 추가하지 않는다. 200ms·100ms 이동·19창·5채널과 모든 개발 시행을 유지한다.

바깥은 8클래스 층화 3-fold, shuffle=True, random_state=20261109다. 각 바깥 학습 1,024시행 안에서 StratifiedShuffleSplit(test_size=.25, random_state=20261110+fold) 1회를 사용한다. 내부 학습 768시행, 내부 선택 256시행이다. 3×4=12회 내부 학습을 모두 수행한다. 사람·파일 ID는 예측 입력에 넣지 않는다. 64개 목표의 학습 부분에는 모든 목표가 있어야 하며, 없으면 절차를 임의 변경하지 않고 검사 오류로 보고한다.

scaler는 각 내부 학습 768시행의 창에서만 맞춘다. 내부 선택 지표는 현재 창의 8클래스 정확도다. 내부 정답 창 수가 가장 많은 후보를 고른다. 정확히 동점이면 특징 수가 적은 후보, 그다음 부스팅 횟수가 적은 후보, 그다음 사전 나열 순서를 쓴다. 비용에 임의의 상한을 두지 않는다. 문맥 점수나 바깥 결과로 선택하지 않는다.

## 바깥 평가와 검증

선택 후보를 해당 바깥 학습 1,024시행에서 새 scaler와 함께 다시 학습하고 남은 512시행의 모든 창을 평가한다. 같은 바깥 분할에서 고정 fine64도 대조로 평가한다. 선택 후보가 fine64이면 같은 학습을 중복하지 않고 한 결과를 두 역할에 사용한다. 따라서 바깥 학습은 3~6회이며 총 15~18회다. 중복 제거는 정확히 동일한 모델·학습·평가가 될 때만 적용한다.

세 바깥 분할을 모두 끝낸 뒤 29,184개 창의 정확도·macro F1·각도/동작 오류, 분할별 결과와 평균±SD를 보고한다. 내부 점수와 바깥 점수는 별도 표로 둔다. 창을 제외하지 않고 과거 5창 문맥은 별도 보조 지표로만 기록한다. split manifest에는 내부 학습/선택/바깥 평가/기존 시험의 교집합을 검사한다. 저장된 확률·예측·scaler·모델을 복원하고 지표를 독립 계산한다.

## 이후 판단

최종 후보의 개발 선택은 후보별 내부 3개 분할의 총 정답 창 수로 정한다. 동점 규칙은 위와 같다. 바깥 평가의 최고 수치로 다시 후보를 바꾸지 않는다. 이 결과 이후 원래 시험을 평가하려면 후보·모델 설정·단 한 번의 평가 범위를 별도 계획에 고정한 뒤 실행한다. 이전 전체 CV에 노출된 시험이라는 사실을 반드시 유지한다. 이번 계획은 새 시험 평가를 포함하지 않는다.

학습 시간과 실제 저장 크기는 모두 기록한다. 현재 비용 측정은 반복하지 않으며 선택된 후보에 새 비용 측정이 필요한지는 기존 대표와의 차이로 판단한다. 다른 학습과 추론 벤치마크를 동시에 실행하지 않는다. 예상 시간은 내부 및 바깥 합계 약 40~60분이며 실제 fit 로그로 갱신한다.
