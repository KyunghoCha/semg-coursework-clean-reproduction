# v31: 상관을 고려한 410차원 RBF 거리 한 설정

2026-10-22 UTC. v29의 바깥 점수와 v30의 내부 실패를 확인한 뒤, v31의 학습 전에 등록한다. 현재 410특징 SVM은 열별 표준화 뒤 유클리드 거리를 사용한다. 기존 내부 진단에는 절대 상관 0.9 초과 특징 쌍이 fold별 367/393/387개이고, 상위 64주성분이 약 65.7% 분산을 차지한다. 이런 상관이 RBF 거리에서 중복 강조되어 오류를 만들 수 있다는 가설을 검증한다. 이는 아직 입증된 원인이 아니다.

v26은 XGB에 PCA64열을 추가했고 whiten=False였다. v17은 클래스별 QDA, v18은 LDA였다. 410차원을 모두 유지하면서 SVM의 거리만 수축 공분산으로 바꾸는 실험은 검색한 현재 코드·결과에서 확인되지 않았다. 과거 240특징 SVM의 quantile 변환도 이 비교를 대신하지 않는다. 새 모델 종류를 나열하거나 C/gamma 탐색을 더 넓히지 않고 한 설정만 비교한다.

## 입력·분할과 정확한 변환

현재 200 ms×5채널·100 ms 이동·전 19창·410특징·64학습 목표·8출력 클래스를 유지한다. 기존 v10의 개발 1,536시행·64기록과 내부 768/256시행, 바깥 1,024/512시행 분할 ID를 그대로 쓴다. 과거·미래 창·시행 경계·기록 ID 추론 입력은 없다. 원래 시험 384시행은 새 학습·평가·선택에서 제외한다. 공유 캐시의 물리적 읽기 범위는 EVALUATION_SCOPE에 명시한 그대로다.

각 실제 base SVM 학습 부분에서만 StandardScaler를 fit하고, 그 출력 Z에 LedoitWolf(store_precision=False, assume_centered=False, block_size=1000)를 fit한다. 수축 행렬은 S=(1−a)Cov(Z)+a·trace(Cov(Z))/410·I이며 a는 해당 학습 자료에서 추정한다. S=V diag(e) Vᵀ의 고유값에 tau=max(1e−12, 1e−12·max(e_max,0))를 적용해 e'=max(e,tau), W=V diag(1/sqrt(e')) Vᵀ를 만든다. 새 입력은 (Z−학습 location)W다. 410차원을 모두 남기며 차원 축소·창 제거는 없다. transform에서 평균·분산·공분산을 다시 맞추지 않는다.

그 뒤 SVC(C=100,gamma=scale,kernel=rbf,probability=False,max_iter=-1,tol=.001,cache_size=1024,decision_function_shape=ovr,random_state=42)를 학습한다. gamma=scale은 변환된 학습 행렬의 실제 분산으로 계산하며, 원래 1/410과 같다고 가정하지 않는다. 원래 시행 단위 3-fold sigmoid 보정·ensemble=False를 유지한다. scaler와 공분산 변환은 보정의 각 base fit 안에서도 그 학습 시행만 사용한다. 보정 검증 시행을 포함한 공분산을 미리 만드는 방식을 쓰지 않는다. 최종 SVC도 전체 해당 학습 부분에서 새 변환을 학습한다.

공식 [LedoitWolf 설명](https://scikit-learn.org/1.7/modules/generated/sklearn.covariance.LedoitWolf.html)과 [수축 공분산 수식](https://scikit-learn.org/1.7/modules/covariance.html#shrunk-covariance)을 읽었다. 서로 겹친 19창은 i.i.d.가 아니므로 이 자료에서 수축량의 통계적 최적성을 보장한다고 주장하지 않는다. 여기서는 학습 전용의 수치적으로 안정된 거리 변환 후보로 평가한다.

## 선택·비용과 검증

비교 기준은 계속 v25다. XGB/LDA 4:1과 fold별 SVM 비중 40/20/30%를 고정하며 v29 넓은 커널이나 C1을 섞지 않는다. 내부 새 확률모델 3개(64분류 base SVC 12fit)를 학습하고, 정답 창 수가 엄격히 늘며 SVM+변환 파일이 기존 SVM의 1.25배 이하면 선택한다. 동률은 기존 유지다. 선택 파일·해시 고정 뒤 개선된 fold만 바깥 학습에 적용한다. 최대 3개의 새 바깥 확률모델·12base fit다. 바깥 파일 크기가 제한을 넘으면 점수는 보존하고 기존 모델로 되돌린다. 바깥 점수를 보고 변환·수축량·C·gamma·비중을 고치지 않는다.

CPU libsvm과 CPU 행렬 연산을 사용한다. 추가로 저장하는 두 410×410 float64 행렬은 약 2.69 MB이며 최종 실제 파일 크기로 비용 제한을 판정한다. 특징 계산은 같고 추론에 410차원 행렬 곱 하나가 더해진다. 내부 학습·예측 약 6–10분, 선택 시 바깥 최대 약 10분을 예상하되 실제 비용을 기록하고 표본을 줄이지 않는다. 대표 분할·380창·19예열·모델 크기·관측 학습시간·전체 확률 CPU 중앙값/평균/p95는 v29와 같은 기준이다. 모든 학습·복원 검증 종료 뒤 단독 측정하며 라벨 호출 생략 시간과 혼합하지 않는다.

각 base fit에서 전체 학습 행 해시, scaler, LedoitWolf의 location·수축량·공분산, 고유값·floor·변환행렬, 실제 SVC gamma, 64클래스·수렴, 보정 OOF와 sigmoid, 저장·복원 확률을 검사한다. 변환의 Mahalanobis 거리 등가성과 미래 평가 행·행 순서 무관성을 합성 자료 테스트로 확인한다. 전체 개발 1,536시행·19창과 기존 시험 교집합 0, 선택·비용 상한·CPU 라벨·원본 모델 해시도 검증한다.

반복 내부 선택과 이전 바깥 점수 노출은 그대로다. 64목표와 64기록의 일대일 구조, 기록 공유와 기록 일반화의 차이, 논문 전문·원필터·독립 세션 미확보를 유지한다. 성공하더라도 새 외부 시험이나 논문 정확재현으로 부르지 않는다. 기존 v23·v25와 실패 결과를 보존하고 외부 push·업로드·공개 ZIP 갱신은 하지 않는다.
