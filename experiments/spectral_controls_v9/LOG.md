# 세부 파워·학습 목표 대조 결과

v8의 학습 gain이 300Hz·420Hz에 집중된 이유를 확인하려고, 기존 400특징에 이 두 주파수의 5채널 파워 10개만 추가한 조건과 905특징에서 그 10개만 제외한 조건을 등록했다. 직접 8클래스 조건도 같은 905특징과 총 25,600트리로 비교했다. 계획 10598a0을 결과 전에 고정했고 같은 3개 시행 분할, 200ms·19창·전체 개발 1,536시행을 유지했다.

| 조건 | 정답 / 29,184창 | 평균±fold SD | 평균 모델·scaler 크기 | 평균 관측 학습 시간 |
|---|---:|---:|---:|---:|
| v8 전체 905특징, 64개 목표 | 26,201 | 89.7786±0.3530% | 36.1747 MB | 234.51초 |
| 기존 400특징+두 주파수, 64개 목표 | 26,257 | 89.9705±0.2374% | 36.8280 MB | 122.29초 |
| 두 주파수 열 제외, 64개 목표 | 25,650 | 87.8906±0.3053% | 37.6589 MB | 247.32초 |
| 전체 905특징, 직접 8클래스 | 25,632 | 87.8289±0.1532% | 46.1937 MB | 290.38초 |

좁은 표현의 v8 대비 차이는 각 fold +0.2981, −0.0103, +0.2878%p이며 전체 +0.1919%p, 정답 56창 증가다. 작은 차이이고 세 분할 모두 개선된 것은 아니다. 학습 시간은 약 48% 줄었지만 모델 크기는 약 0.65MB 늘었다. 새 추론 지연은 아직 측정하지 않았다. 이전 v8의 측정값을 이 후보의 값으로 옮기지 않는다.

두 열을 제외하면 세 분할 모두 낮아져 평균 1.8880%p 하락했다. 이 대조는 특징 열만 제외하며 원신호·인접 bin·기존 대역과 교차 특징은 남는다. 해당 정보에 대한 의존은 확인했지만 성분의 기원이 전원 잡음인지 생리 신호인지는 확정하지 못했다. 별도 v11은 현재 창에서 두 정현파 성분을 제거하고 모든 특징을 다시 계산한다.

직접 8클래스는 세 분할 모두 v8보다 낮아 평균 1.9497%p 차이가 났다. 같은 총 트리 수에서 64개 보조 목표의 이득은 남지만, class별 트리 배분·boosting 단계·목적함수도 달라진다. 동일 기록의 다른 시행이 학습·평가에 공유된 조건이라는 제한을 유지한다.

9개 저장 모델과 확률·scaler를 복원했고 수동 지표, 원래 fold와의 동일성, 기존 시험 교집합 0을 확인했다. 중단 전에 완료한 4회 산출물의 해시도 보존됐다. 마지막 비용 목록 갱신 명령 오류와 복구는 RECOVERY.md에 기록했다. 비용 목록 갱신으로 저장 모델 56개·관측 학습 시간 276회가 확인됐다. 이 중 4회는 기존 모델 비용 복원을 위한 재학습이다.

다음 v10은 미리 등록한 내부 자료의 점수만으로 후보를 선택하고 바깥 분할에서 고정 v8 표현과 비교한다. 위 평균만 보고 최종 후보를 확정하지 않는다. ±는 fold 표준편차(ddof=0)이며 신뢰구간이 아니다. 이 자료를 반복 개발에 사용했고 기존 시험도 전체 CV에 노출됐다. 새로운 독립 외부 시험이나 논문 동등 결과로 표현하지 않는다.
