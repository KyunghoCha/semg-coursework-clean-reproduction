# 세부 파워 의존과 보조 목표의 분리

v8의 개발 3분할 정확도는 89.7786%였다. 추가 세부 파워의 학습 gain 중 큰 몫이 300Hz·420Hz에 집중됐다. 이 성분이 60Hz의 배수라는 사실은 기원 판정이 아니다. v9는 이 의존과 분류 목표의 효과를 분리한다. 아래 조건을 결과를 보기 전에 고정한다.

## 동일 조건과 세 후보

v7/v8의 같은 개발 1,536시행·3분할을 재사용한다. 각 분할 학습 1,024·평가 512시행, mark+1.5–3.5초, 200ms 창, 100ms 이동, 19개 창, 모든 5채널을 유지한다. 원래 시험 384시행은 제외한다. 반복 개발 평가이며 새 외부 시험이 아니다. v8 fine400의 3개 결과를 그대로 대조로 쓰고 다음 3후보만 9회 새로 학습한다.

1. narrow64: 기존 400개에 300Hz·420Hz의 5채널 로그 파워 10개만 추가한다. 총 410개, 64개 학습 목표, 400회, 25,600트리다. 세부 파워 효과가 좁은 성분으로 압축되는지 검사한다.
2. drop_two64: 기존 905개에서 위 10개만 제외한다. 총 895개, 64개 목표, 400회, 25,600트리다. 다른 bin과 원래 400특징은 보존한다. 필터링 실험이 아니며 인접 Hann bin·대역 파워·교차 특징에도 같은 성분이 남을 수 있다. 따라서 전원 영향 전체를 제거했다고 주장하지 않는다.
3. direct8: 동일 905개로 원래 8클래스를 직접 학습한다. 3,200회·25,600트리로 보조 목표 대조와 총 트리 수를 맞춘다. v6의 동일 트리 대조는 240개 특징이었으므로 현재 표현에서도 그 결과가 유지되는지 새로 확인한다. 부스팅 단계 수와 클래스별 상호작용까지 같은 것은 아니다.

모두 깊이6, lr .05, subsample .9, colsample .8, lambda1, hist CUDA, seed42, 스레드6을 유지한다. scaler는 학습 창에서만 fit한다. 64개 목표는 학습 자료의 사람×8클래스이며 예측 입력에 사람·기록 ID를 주지 않는다. 출력은 사람 축 확률 합으로 8클래스를 얻는다. 8개 목표의 출력은 직접 argmax다.

## 검증과 판단

주지표는 현재 200ms만 쓰는 모든 창의 정확도·macro F1이다. 과거 창 문맥은 별도로 기록한다. 각 후보 3분할을 모두 실행하며 성능이 낮다고 나머지를 생략하지 않는다. 원래 대조와 교집합·scaler·특징 열 대응·저장 모델 복원·수동 지표 계산을 검사한다. 단일 fold의 90% 통과를 목표 완료로 삼지 않는다.

학습 시간, 저장 바이트, 실제 트리·노드 수를 함께 기록한다. 원래32개 비용 결과를 다시 재지 않는다. 기존 fine400보다 평균이 높거나 크기가 작으면서 정확도 차이가 작으면 정확도·용량의 절충 후보로 보고한다. 수치 경계로 후보를 몰래 버리거나 최고 fold만 선택하지 않는다. 이후 별도 내부 선택과 바깥 평가를 수행할 때 후보 범위·규칙을 다시 실행 전에 고정한다. 이미 개발에 쓰인 자료라는 한계는 해당 평가에도 유지한다.

## 예상 비용과 실행 순서

짧은 inplace 호출 대조와 기존 특징 계산 최적화 확인을 끝낸 뒤 학습한다. 예상 학습 시간은 세 후보 전체 약 30–45분이며 실제 진행 로그로 갱신한다. 학습 중 별도 추론 벤치마크를 돌리지 않는다. 학습 모델과 개별 예측은 비공개 로컬에만 저장한다.
