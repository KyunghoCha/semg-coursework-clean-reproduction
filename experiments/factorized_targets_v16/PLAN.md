# 동작·각도 분리 고정 대조 v16

2026-10-21 UTC, 학습 전 등록. 사용자 목표는 전통 ML의 분류 성능과 비용을 개선하면서 기록 공유와 기록 전이를 구분하는 것이다. v15까지의 코드·결과를 검색했으나 동작4종/각도2종의 독립 또는 조건부 분류는 수행하지 않았다.

## 가설과 비교 대상

v15의 직접8클래스60특징 혼동행렬에서 같은 동작의 각도만 틀린 오류는 공유2,100/8,048(26.09%), 분리8,801/26,658(33.01%)다. 하나의8분류 대신 두 축을 분리해 학습하면 일부 경계를 더 잘 표현하거나 비용을 줄일 가능성이 있다. 나머지 동작 오류와 두 축 동시 오류도 커서 각도 분리만으로 일반화가 해결된다고 가정하지 않는다.

[scikit-learn MultiOutputClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.multioutput.MultiOutputClassifier.html)의 출력별 독립 분류 정의와 [XGBoost objective 문서](https://xgboost.readthedocs.io/en/stable/parameter.html)의 binary:logistic/multi:softprob 확률 출력을 읽었다. 실제 실행은 기존 설치 XGBoost3.0.5를 유지한다. 아래 조건부 확률 곱은 이 프로젝트에서 고정한 구현이며 논문 재현이나 알려진 우월성으로 포장하지 않는다.

## 고정 입력과 레이블

기존1,920시행×19창의60특징(TD25+AR30+잔차 RMS5)을 그대로 재사용한다. 각200ms,100ms hop,5채널 모두 유지한다. 새 필터·정규화·특징 선택·데이터 축소는 없다. 384개 역사적 시험은 새 학습·평가에서 제외하며 개발1,536시행을 기존4fold 기록 공유와4fold 기록 분리에서 각각한 번씩 평가한다. 기록 분리는 새 사람 분리와 다르다. 60특징 선택에는 이전 개발 평가 이력이 있으므로 독립 외부 시험으로 부르지 않는다.

기존8클래스 y=4a+g, a=y//4 (0=30°,1=60°), g=y%4 (extor,fist,open,pro)다. 입력과 학습 목표에 피험자/기록 ID를 추가하지 않는다. 채널 역할별 분리는 하지 않으므로 강의의 기존5채널 대응을 바꾸지 않는다.

## 두 고정 방법

1. 독립: 전체 학습 시행으로 G(x)=P(g|x), A(x)=P(a|x)를 각각 학습한다. 최종 q[a,g]=A[a]G[g]를 angle-major 순서로 펴서8클래스 argmax를 사용한다.
2. 조건부: 같은 G 모델을 재사용한다. 학습 자료의 실제 동작g별로 A_g(x)=P(a|g,x) 네 개를 학습한다. 평가에서는 실제 동작 레이블을 사용하지 않고 모든 A_g와 G를 계산한다. 최종 q[a,g]=G[g]A_g[a]의 argmax를 사용한다. hard gate와 soft 결합을 결과를 보고 선택하지 않으며 soft joint 결합 하나만 고정한다.

각 구성 모델은 XGB400,depth6,lr.05,subsample.9,colsample.8,lambda1,seed42,cuda,6threads다. G는4class multi:softprob로1600트리, A와각 A_g는 binary:logistic으로400트리다. 독립 방법은2모델/2000트리, 조건부 방법은5모델/3200트리이며 직접8기준은1모델/3200트리다.400라운드를 유지하되 클래스 분해로 총트리가 달라진다는 점을 비용과 함께 명시한다.

각 scaler는 해당 모델이 학습하는 시행의 창에만 fit한다. 조건부모델 네 개의 학습 시행은 동작에 따라 서로 겹치지 않고 합집합이 전체 학습 시행이다. 이는 정의에 따른 분할이며 임의 subsampling이 아니다. G는 두방법에서 실제같은저장모델을 재사용한다. 새fit는6구성모델×8fold=48회이며 기존직접8모델8개는 재사용한다.

하이퍼파라미터·특징·방법 선택을 수행하지 않는다. 두 고정 방법을 모두 비교하고 이 평가점수로 새 기본 모델을 고르지 않는다. 이후 후보 선택을 한다면 별도 내부 자료로 해야 한다. 기존 개발 선택 편향은 남는다.

## 지표·검증·비용

주지표는 최종8클래스 창 정확도다. 최종8예측에서 파생한 동작/각도 정확도, 각 확률 주변분포 argmax의 보조 정확도, 각도만/동작만/둘다 틀린 오류수를 모두 보고한다. 겹치는19창을 독립 표본으로 간주한 신뢰구간은 만들지 않는다.

합성 확률로 열 순서·합1·독립 결합·조건부 결합·주변화·oracle 비사용을 테스트한다. 실제 모델48개를 CPU에서 복원해 분할 재생성,학습 scaler,클래스 지원,400라운드/트리 수,확률열,수동지표를 확인한다. 모델·입력캐시 해시는 보존한다. 개인별 결과는 공개하지 않는다.

학습 종료 후 각protocol의fold0에서 직접8/독립/조건부 세 방법(총6조건)의 CPU6threads 비용을 측정한다. 동일256개 고정개발창,20회준비+200회batch1,특징+scaler+확률결합까지 포함하고200ms취득·모델로딩은 제외한다. 방법별 구성모델 직렬화크기·학습시간 합도 비교한다. 기존로그/결과를 덮어쓰지 않고 v16에만 저장한다.
