# 정확도·크기·지연 비용 측정

학습 시간은 이미 저장한 실측값을 먼저 정리한다. 최초·2차·4차 시간은 scaler 계산을 포함하고 5–7차는 model.fit 시간이다. GPU 작업이 겹친 구간의 시간은 독점 GPU 처리시간으로 비교하지 않는다. 각 모델의 실제 저장 바이트, 트리·노드·말단 수를 세고, SVM은 지지벡터와 계수 수를 별도로 센다. 모든 모델을 같은 의미의 단일 parameter 수로 환산하지 않는다.

4차 내부 비교에서 저장하지 않았던 155특징 대안과 SVM 두 변환도 비용을 확인한다. 첫 outer의 첫 inner 학습682시행에서 rich800/noTime800/SVM standard/SVM quantile 네 모델만 동일 설정으로 다시 만들고, 당시 저장한 평가 예측과 정확히 일치하는지 확인한다. 이는 후보·분할 변경이나 새로운 시험 평가가 아닌 비용 측정용 복원이다. 정확도와 크기를 짝지을 때 원래 내부 검증 그룹으로 따로 표시한다. 155특징 추출에서는 불필요한 추가 시간 특징 계산을 생략하고 원래 선택된155개 값과 일치함을 검사한다.

## 추론 측정 조건

현재 4·6·7차 학습을 끝내고 다른 계산 작업의 GPU 사용이 없는 시점에 실행한다. 다른 사용자의 작업을 종료하지 않는다. 시작 전·후 계산 프로세스와 GPU 상태를 비공개 로그로 기록한다. 그래픽 데스크톱은 남으므로 완전 전용 GPU라고 부르지 않는다. 모델별 새 Python 프로세스에서 순서대로 측정한다. 라이브러리 threadpool·OMP·MKL·OpenBLAS의 상한을 6으로 맞추고, RF n_jobs 및 XGB n_jobs/DMatrix nthread도 6으로 고정한다. SVC 자체의 단일 스레드 구현은 별도 표기한다.

입력은 개발 자료에서 seed20261105로 고정한 256개 현재 창이다. 모든 주비교는 200표본×5채널이며 샘플 선택은 지연 측정용이지 정확도 선택용이 아니다. 최초 300ms 모델을 다룰 경우 별도 입력 조건으로 분리한다. 원본 캐시에서 읽은 신호로 특징을 매번 실제 계산한다.

- warmup20회 후 단일 창 batch1을 200회 측정한다. 특징 추출, scaler, 모델 추론, 신호 배열부터 8클래스 출력까지 전체 처리를 각각 독립 측정한다. 중앙값과 p95, 반복 횟수와 총 경과시간 기반 처리량을 남긴다. 각 성분의 중앙값을 더한 값 대신 실제 전체 호출 시간도 직접 잰다.
- batch256은 warmup5회 후 30회 측정한다. 모델 전용 처리량과 특징을 포함한 전체 처리량을 구분한다. batch256 지연을 단일 창 실시간 지연으로 바꾸어 제시하지 않는다.
- GPU는 `cudaDeviceSynchronize`를 타이머 앞뒤에 호출하고 반환 코드를 검사한다. GPU 추론에는 CPU 배열의 DMatrix 변환, 전송, 확률의 CPU 반환과 8클래스 합산을 포함한다. 별도 CPU 추론 대안을 측정하면 동일한 저장 모델을 CPU 장치에서 쓰고 장치를 명시한다. CPU로 조용히 대체하지 않는다.
- 프로세스 RSS를 모델 로드 전·후와 warmup 후에 읽고, ru_maxrss를 프로세스 생애 최고치로 보고한다. 이는 모델만의 peak 메모리가 아니다. GPU는 해당 PID의 nvidia-smi 사용 메모리를 warmup 후·측정 후에 읽는다. 이 두 시점의 관측 최대값이지 학습 또는 전체 순간 peak VRAM은 아니다.

동기화 의미는 [NVIDIA 문서](https://docs.nvidia.com/cuda/cuda-driver-api/cuda_driver_api/group__CUDA__CTX.html)의 선행 context 작업 완료와 같은 목적이다. 실제 구현은 설치된 CUDA runtime의 cudaDeviceSynchronize를 사용하며 실패하면 GPU 지연 결과를 만들지 않는다.

## 신호 시간과 계산 시간의 구분

단독 창은 200ms 신호가 있어야 첫 예측을 만든다. 분석 구간이 mark+1.5초에서 시작하므로 첫 출력의 신호 종료는 mark+1.7초다. 이후 100ms마다 새 창을 얻는다. 과거5창 집계는 현재와 이전만 써서 미래 대기는 0ms이고 첫 창부터 출력한다. 다섯 예측이 모두 쌓인 시점에는 최대600ms 신호를 사용한다. 알려진 시행 경계에서 reset한다. 실제 연속 동작 전환에 대한 반응 지연은 정적 레이블 시행 자료로 측정하지 못했다. 2초 신호를 모두 기다리는 전체 시행 다수결과 구분한다.

## 절충 판단

정확도는 같은 평가 분할을 공유한 비교 안에서만 Pareto 지배 관계를 판단한다. 서로 다른 단계의 CV 정확도를 같은 시험처럼 섞지 않는다. 더 작은 모델이 비슷한 정확도·낮은 지연을 보이는지 확인하고, 실제 추가 비용을 제시한다. 새 시간·메모리 제한을 정해 성능 목표를 낮추지 않는다. 효율 때문에 후보를 선택할 경우 그 정확도 차이를 함께 밝힌다.
