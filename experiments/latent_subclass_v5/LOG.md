# 학습 목표 세분화 결과

같은 클래스의 사람 간 특징 중심 거리가 한 사람 내 클래스 거리보다 큰 관찰에서 시작했다. 학습 사람×동작·각도를 64목표로 구분하면 하나의 8클래스 안에 섞인 신호 분포를 더 잘 표현할 수 있다는 가설을 7ff52de에서 고정했다. 평가 때 사람 정보는 입력하지 않고 64확률을 원래 8클래스별로 합산했다.

동일 개발 3-fold, 동일 240특징·200ms·19창에서 직접 8클래스 목표의 정확도는 80.84/80.13/80.32%, 하위 목표는 85.86/85.34/84.91%였다. 합계 29,184창 중 23,473→24,914창을 맞혔으며 평균 80.43→85.37%, +4.94%p였다. 세 fold 모두 개선됐다. 하위 목표의 macro F1은 0.8537, 각도 정확도는 92.57%, 동작 정확도는 88.86%였다.

고정 과거 5창 문맥 조건은 27,227/29,184=93.29%였다. 이는 최대 600ms 신호 이력과 알려진 시행 경계를 사용하는 별도 조건이며 독립 200ms 창 점수는 85.37%다. 새로운 사람·기록의 일반화나 원논문 정확재현으로 해석하지 않는다.

6회 실행의 혼동행렬 지표, 확률 열의 독립 합산, 학습 부분 scaler, 시행 분리, CUDA 설정과 6개 저장 모델 복원 확률이 모두 일치했다. 기존 시험 384시행과 교집합은 0이다. 마지막 실행은 프로세스 중단 뒤 재개했다. 앞서 완료된 예측·설정·모델·분할의 SHA-256은 그대로 유지됐다.

학습 목표와 전체 트리 수가 함께 바뀌었다(3,200→25,600트리). 따라서 이득 전부를 사람별 분포의 표현만으로 설명하지 않는다. a351b21에서 전체 트리 수를 맞춘 직접 8클래스 모델 대조와 대역별 채널 관계 추가를 별도 고정했다. 단독 창 90%에는 여전히 미달하므로 이 두 원인을 계속 검증한다.
