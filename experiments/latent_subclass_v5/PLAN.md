# 학습 목표의 세분화 대조

개발 자료의 특징 중심을 비교하면 같은 클래스라도 사람 간 거리가 한 사람 안의 클래스 간 거리보다 컸다(전체 1.67배, 채널 관계 2.06배, 주파수 2.14배). 단일 클래스가 여러 신호 분포를 포함할 가능성을 확인하기 위해 아래 두 모델만 고정한다. 이는 사람·기록 효과를 분리한 생리적 결론이 아니다. 별도 거리 진단의 중심과 scaler를 예측에 사용하지 않는다.

## 두 고정 모델

- `global8`: 8개 동작·각도 조합을 직접 학습한다.
- `subclass64`: 학습에서만 제공된 사람 코드와 8클래스의 조합을 64개 목표로 구분한다. 목표 번호는 사람 인덱스×8+원래 클래스다. 예측 때는 신호 특징만으로 얻은 64개 확률을 사람 축으로 합산해 원래 8클래스 확률을 만든다. 최대 확률의 8클래스를 출력한다. 평가 사람 코드를 입력하거나 모델을 골라 주지 않는다.

둘 다 240개 결합 특징, 현재 200ms 창, 100ms 이동, 19창, 5채널, 고정 1.5–3.5초다. XGB 400회, 깊이6, lr .05, subsample .9, colsample .8, lambda1, hist, CUDA, seed42, n_jobs6을 사용한다. 학습 창으로만 StandardScaler를 fit한다. 64클래스는 400×64=25,600트리, 8클래스는 3,200트리이므로 같은 모델 크기 대조가 아니다. 모델 용량과 학습 목표 구성이 함께 달라지며 비용을 기록한다. 800/1600회 확장과는 별도 실험이다.

## 평가

기존 개발 1,536시행의 새 층화 3-fold(seed20261028)를 결과 전에 고정한다. 두 모델을 매 fold의 같은 학습 1,024시행·평가 512시행에서 비교한다. 정해진 두 가설의 대조이며 내부 최적화나 추가 후보 선택은 없다. 각 학습 집합에 64개 조합이 전부 존재하는지 검사한다. 기존 시험 384시행은 모두 제외한다. 개인별 평가 표나 모델은 공개하지 않는다.

주평가 단위와 출력은 원래 8클래스 창 분류다. 새로운 64클래스 학습 목표를 사용했다는 사실을 결과와 함께 명시한다. 모든 평가 창을 유지한다. 고정 과거 5창 결과는 별도 조건으로만 계산한다. 각 모델·scaler·64개 확률을 비공개 로컬에 보존하고, 확률 합산·분할·지표·복원 예측을 검증한다.

자료는 이미 여러 개발 분석에 사용됐다. 새 분할도 독립 외부 시험이 아니며, 같은 사람과 같은 기록의 다른 시행에 대한 평가다. 세 분할에서 이득이 일관되지 않거나 작으면 목표 세분화를 채택할 근거를 낮춘다. 큰 이득이 있어도 새 사람이나 새 기록에 대한 일반화로 해석하지 않는다. 결과를 본 뒤 같은 fold에 맞춰 구조나 목표를 바꾸지 않는다.
