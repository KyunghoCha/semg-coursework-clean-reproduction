# v30: 실제 제약이 작동하는 C=1 후속 대조

2026-10-22 UTC. v29의 내부 학습 중, 새 바깥 평가 전에 등록한다. 기존 C100의 내부 최종 SVM에서 최대 절대 dual 계수는 4.7729/5.2766/4.7785다. 모두 10보다 작고, 완료된 v29 C10 내부 세 모델의 지원벡터·정답 수도 기존과 같다. 따라서 C100→10은 현재 해를 실제로 제한하지 않을 수 있다. 이것을 규제 효과를 충분히 검사한 결과로 해석하지 않고, 더 작은 C=1 하나만 추가한다. 전체 base 배열 동등성은 v29 독립 검증 뒤 확정한다.

새 후보는 C=1, gamma=scale, 나머지는 v29의 고정 SVC와 동일하다. 비교 기준은 계속 v25이며 v29의 넓은 커널 선택을 섞지 않는다. C0.1, 추가 gamma, 새 seed, 가중치 재탐색, 새 특징은 이번 등록에 없다. 기존 200 ms·5채널·410특징·64목표, 100 ms 이동, 전 19창, 개발 1,536시행·64기록과 기존 v10 분할을 유지한다. 과거·미래 창·시행 경계·기록 ID 추론 입력은 없다.

내부 768/256시행의 세 분할에서 새 확률모델 3개(64분류 base SVC 12fit)를 학습한다. v25의 XGB/LDA 4:1 및 fold별 SVM 비중 0.4/0.2/0.3을 고정한다. 같은 시행 단위 sigmoid 보정 3-fold·ensemble=False·학습 전용 scaler·같은 seed·max_iter=-1을 유지한다. 정답 창 수가 엄격히 늘고 SVM 파일 크기가 기존의 1.25배 이하면 선택한다. 동률은 기존을 유지한다. 선택 파일을 고정한 뒤 필요한 fold에서만 바깥 1,024시행으로 학습하고 512시행을 평가한다. 최대 새 바깥 3모델·12base fit이며 바깥 파일 크기 제한을 넘으면 점수를 보존하되 기존 모델로 되돌린다. 바깥 정확도로 설정이나 비중을 바꾸지 않는다.

v29가 실행 중인 과정에서 등록한 별도의 후속 비교이며 원래 v29의 3후보를 사후 변경하지 않는다. 공통 실행·검증·비용 코드는 experiments/svm_tuning_v29에 두고, 환경변수 SEMG_SVM_COMPARISON=svm_regularization_v30으로 전용 private/results 경로와 이 명세를 선택한다. 기본값 v29의 설정·선택 의미는 유지한다. 실행 순서는 v29 학습 종료 후 v30 학습이며, 추론 비용은 모든 학습과 복원 검증이 끝난 뒤 각각 분리 측정한다.

CPU libsvm을 사용한다. 내부 fit 약 5분 및 선택 시 바깥 최대 약 8분은 기존 관측에 따른 예상이며 예측·복원·비용 시간은 별도다. 모든 창을 유지하고 시간에 맞춰 표본·학습을 줄이지 않는다. 비용의 대표 분할·380창·19예열·전체 확률·모델 파일 크기·wrapper fit와 base fit 별도 집계는 v29와 같다. 바깥 선택이 없으면 내부 fold0에서 기준과 C1을 측정한다. 라벨 호출 생략 시간과 혼합하지 않는다.

모든 새 4base 체크포인트·클래스·수렴·scaler·보정 OOF·sigmoid·최종 확률·metric·선택·전체 바깥 창의 CPU 라벨을 검증한다. C1이 실제로 dual 계수를 제한했는지도 저장 모델에서 확인한다. 반복 개발 선택과 이미 알려진 바깥 결과의 한계, 64목표와 64기록의 일대일 구조를 유지한다. 새로운 외부 시험·새 기록 일반화·논문 정확재현이라고 부르지 않는다. 기존 시험 384시행의 새 학습·평가·선택은 없다. 공유 캐시의 파일 읽기 범위는 docs/EVALUATION_SCOPE.md와 같다. 외부 게시·업로드는 계속 금지하며 기존 v23·v25 및 공개 ZIP은 보존한다.

근거: [공식 SVC의 C 정의](https://scikit-learn.org/1.7/modules/generated/sklearn.svm.SVC.html). C는 오류 페널티의 상한이며 큰 C 두 값이 동일한 해를 만들었다는 사실만으로 작은 C의 효과까지 기각할 수 없다.
