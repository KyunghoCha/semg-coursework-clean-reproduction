# 남은 오류와 학습 맞춤 정도의 진단

v8 전체 표현과 v9 좁은 표현의 같은 첫 fold 저장 모델에서, 학습 1,024시행의 현재 19창을 다시 예측한다. 이는 학습 자료 재평가이며 일반화 점수로 사용하지 않는다. 이미 저장된 해당 fold의 평가 512시행 예측과 비교해, 남은 약 10% 오류가 학습 자료에도 많이 남는지 확인한다. 학습 점수만으로 과적합의 원인을 확정하지 않는다.

원래 특징·scaler·모델을 그대로 불러오며 새 학습·튜닝·시험 384시행 평가는 없다. 두 모델의 64확률을 기존 방식으로 8클래스에 합친다. 8클래스 학습/평가 정확도와 log loss, 학습 부분의 64목표 정확도, 8클래스 학습−평가 차이를 전체 집계로 기록한다. 평가 정답을 이용한 새로운 후보 선택은 하지 않는다.

모델 파일은 변경하지 않고 메모리 안에서만 CPU 예측으로 설정한다. CPU 1스레드로 실행해 진행 중인 GPU 학습에 대한 자원 경합을 줄인다. 이 시간은 추론 벤치마크로 보고하지 않는다. 앞서 v8 전체 개발 예측의 CPU/GPU 클래스 일치를 확인했다. 실행 후 원래 모델 바이트 해시가 같음을 검사한다.

학습 8클래스 점수도 낮으면 표현·용량 부족을 함께 검토한다. 학습 점수는 매우 높은데 평가만 낮으면 더 많은 트리만 우선하지 않고 이미 계획한 확률 결합, 추정 분산과 정규화의 영향을 검토한다. 어느 경우에도 기록 조건 의존 가능성과 반복 개발 편향이 해결됐다고 주장하지 않는다.
