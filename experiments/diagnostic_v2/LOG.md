# 2차 개선 기록

## 진단과 사전 고정

1차 기준 18회, 개발 40회, 선택 모델 1회의 원결과를 보존했다. 300ms 모델의 68.20%=4714/6912창은 전체 CV에 이미 노출된 고정 시험에서 얻은 값이다. 200ms의 동일 18시작 위치 63.05%는 평가 위치만 맞춘 사후 집계이며 학습 창 수까지 통제한 비교가 아니다.

이번 진단은 기존 개발 1536시행만 사용했다. 기본 ZC의 0.01 임계값, 창 내부 시간 변화, 주파수 분포, 채널 관계, SVM 거리 배치를 각각 검토하기로 했다. 단순 저진폭보다 반응이 감소하는 2.3–2.5초에서 오류가 커지는 양상을 확인했으나, 생리적 원인을 확정하지 않았다. 마커·클래스 매핑과 RMS 재계산은 일치했다. 사람별 편차는 로컬 비공개 결과에 보존한다.

`b3f7ac7`에서 계획과 후보 코드, 진단 집계를 새 모델 학습 전에 고정했다. 전체 1920시행의 stateless 특징을 만들었지만 새 모델 학습·진단·선택·평가는 개발1536시행 안에서만 한다. 나머지384시행은 모두 제외한다. 합성 검사는 기존12개와 추가3개, 총15개를 통과했다. 기존25특징과 새 계산의 최대 차이는4.3×10⁻¹⁴였고, 이는 배열 연산의 반올림 차이다. 대조 입력에는 기존 배열 값을 그대로 넣어 정확한 동등성을 보장했다.

## 실행 중

개발 자료 안의 outer3-fold 각각에서 inner3-fold로 후보10개를 비교한다. XGBoost는 TITAN Xp CUDA, ExtraTrees와 SVM은 같은 PC의 CPU에서 실행한다. 시행별19창을 유지하고, StandardScaler 또는 QuantileTransformer는 각 학습 창에만 fit한다. 평균 창 정확도로 선택하고 동률은 등록 순서를 따른다. 기록·채널·어려운 창을 제거하지 않는다.

실행 원수치: `results/diagnostic_v2/inner.csv`, `outer.csv`. 비공개 시행 ID 분할과 예측, scaler 상태: `private/diagnostic_v2/`. 과거 실험과 진단에 이미 사용된 개발 자료의 재평가이며, 외부 일반화 증거로 표현하지 않는다. 등록한 후보 비교가 끝나면 상승·실패 원인에 따라 다음 가설을 별도로 고정한다.

## 첫 내부 비교와 원인 해석

첫 outer 학습 집합 안의 inner 3-fold 평균은 기준 58.01%, ZC 교체 58.07%, 시간 특징 추가 57.97%, 채널 관계 65.35%, 대역 특징 73.76%, 결합 특징 400회 77.23%, 결합 특징 800회 79.16%였다. ExtraTrees 400회는 77.44%, SVM C10은 표준화 51.20%, 분위수 변환 52.17%였다. 이 값은 학습 시행이 fold당 682 또는 683개인 내부 비교이므로 기존 개발 5-fold 평균과 직접 비교하지 않는다.

주파수·채널 관계 정보의 보완이 ZC 교체나 단순 시간 특징 확장보다 효과가 컸다. 800회의 추가 이득도 약 1.93%p로 관측됐다. 따라서 임계값만 고치면 해결된다는 설명과 scaler가 절대 진폭을 지웠다는 설명을 주원인으로 삼지 않는다. 원래 ZC를 유지하는 추가 대조는 `mechanisms_v3/PLAN.md`에 따로 고정했다.

개발 PSD에서 60Hz 한 주파수점의 평균 상대 전력은 채널별 약 11–18%였다. 이는 특정 성분에 대한 민감도 확인이 필요하다는 근거이며 잡음의 물리적 원인을 확정한 결과는 아니다. 추가 필터를 기본값으로 바꾸지 않고, 200ms 창 내부의 60Hz 투영 성분만 제거하는 별도 대조를 등록했다.

## 첫 바깥 평가와 고정 과거 문맥

첫 outer 평가 512시행·9,728창에서 기준 XGB는 61.18%, 내부 선택된 결합 특징 XGB 800회는 81.88%였다. 이 결과를 보고 최초 후보나 선택 규칙을 바꾸지 않았다.

`1ab81ef`에서 첫 바깥 결과 전에 현재+직전 4창 집계 규칙을 고정했다. 단독 창 성능으로 모델을 선택하는 규칙은 그대로 유지했다. 독립 구현의 기존 개발 결과는 감사와 일치했다(XGB 73.87%, RF 75.72%, 300ms XGB 77.55%). 첫 바깥 평가의 결합 특징 모델은 문맥 집계 후 90.09%였다. 956창을 정정하고 157창을 악화시켰다. 첫 창과 평가 분모는 그대로다. 이는 최대 600ms 신호 이력과 알려진 시행 경계를 사용한 값으로, 200ms 단독 성능이나 논문 재현 수치가 아니다. 남은 바깥 평가를 완료한 전체 결과로 다시 요약한다.

## 전체 중첩 평가와 검증 완료

모든 90개 내부 학습과 6개 바깥 학습을 완료했다. 세 outer 모두 결합 특징 XGB 800회를 선택했다. 바깥 창 정확도는 기준 61.18/62.28/61.37%, 개선 81.88/82.95/82.52%였다. 같은 29,184창에서 17,981→24,062창을 맞혔고, 평균은 61.61→82.45%다. 개선 모델의 macro F1은 0.8245, 각도 정확도 90.98%, 동작 정확도 87.19%였다.

고정 과거 문맥은 26,409/29,184=90.49%였다. 2,837창을 정정하고 490창을 악화시켰다. 단독 창과 입력 이력이 다르며 모델 선택에는 문맥 점수를 쓰지 않았다. 96개 실행 모두 지표를 별도 정수 혼동행렬 계산으로 재검증했고, scaler의 평균·분산 또는 분위수 지점을 학습 부분에서 다시 구해 정확히 일치함을 확인했다. 모든 중첩 학습/평가 교집합은 0, 기존 시험과의 교집합도 0이었다.

현재 결과는 실패 원인이 단순히 데이터나 ZC 구현 오류라는 설명을 지지하지 않는다. 같은 200ms 안에서도 충분히 활용하지 않은 주파수·채널 정보가 있었다. 다만 단독 창 90%에는 미달하며, 원래 특징에 대한 SVM의 낮은 성능만으로 새 특징의 결정 경계까지 결론 내릴 수 없다. `92e2632`의 창 길이·ZC·60Hz 대조와 `f4f82f6`의 모델 용량·SVM 비교를 결과 전에 고정했고 계속 실행한다.
