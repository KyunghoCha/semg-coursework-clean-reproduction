# 별도 라벨 전용 경로의 동등성과 비용

2026-10-22 UTC. v25 내부 비중 선택과 결과 계산 전에 추가 등록한다. 원래 PLAN의 전체 확률 비용 측정은 그대로 수행한다. 아래는 별도 라벨 전용 실행이며 정확도 후보·비중·분할을 바꾸지 않는다.

기존 검증된 v22 `gate_rule.labels`를 그대로 재사용한다. q0=0.8*qXGB+0.2*qLDA의 상위 두 확률 차이가 beta/(1-beta)+1e-8보다 크면 SVM을 실행해도 전체 결합의 argmax가 바뀔 수 없으므로 생략한다. beta0은 SVM을 항상 생략하고, 경계·동률은 계산한다. v25 내부에서 선택한 각 fold의 beta만 쓰며 임계값을 튜닝하지 않는다. 확률값까지 같다는 주장은 하지 않는다.

모든 바깥29,184창에서 저장 확률의 라벨 일치와 실제 CPU 모델의 조건부 실행 라벨 일치를 확인한다. 시행 경계·위치·과거/미래창·ID는 분기 입력이 아니다. 원래384시험은 평가하지 않는다. 소스 모델·확률 해시를 보존한다.

시간 측정의 대표는 v25와 같은 첫 beta변경 fold(없으면0)다. 그 fold의 전체512평가시행×19창=9,728창을 각각 한 번 실행한다. 첫19창 예열, CPU6라이브러리스레드·SVM단일스레드, 현재200ms 특징·모델·실제 분기·라벨을 포함한다. 로딩·CSV·신호 취득은 제외한다. 중앙값·평균·p95와 호출/생략 각각의 분포, 실제 호출률을 보고한다. 기존380창 전체 확률 측정과 표본 범위가 다르므로 이를 같은 표본의 속도 비율로 계산하지 않는다. 시간 분포는 반복 측정 신뢰구간이나 최악 지연 보증이 아니다.

새 fit0, 추가 저장 모델0이다. beta0이 아니면 전체 세 모델을 유지하므로 파일 크기·학습 비용은 줄지 않는다. 예상 비용은 검증과 전9,728창 측정을 포함해 수분이며, 모델 정확도 개선과 분리해 보고한다. 외부 게시·업로드는 계속 금지한다.
