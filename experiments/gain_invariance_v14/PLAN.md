# 현재 창의 공통 진폭 정규화 대조

활동 구간의 고정 직접8클래스 대조에서 기본25특징은 기록 공유62.0751%·기록 분리8.8576%,905특징은87.1539%·6.7606%였다. 같은 클래스의8개 기록 사이에서 기록별 전체 RMS 중앙값의 최대/최소 비는 약2.00–7.53배였다. 이 차이는 측정 이득,사람,동작 강도를 구분하지 못하지만 절대 진폭 의존을 분리해 볼 근거다. 이전 결과를 본 뒤 등록하는 사후 고정 진단이며 독립 확증 실험이 아니다.

가설은 현재 창의 공통 진폭을 제거하면 기록 간 전이가 개선되는가이다. 입력200ms×5채널에서 g=sqrt(mean(x²))를 계산하고 x/g에 기존25특징 함수를 그대로 적용한다. g=0이면 영신호를 반환한다. 전체 시행·다른 창·파일 통계를 사용하지 않고 학습할 정규화 파라미터도 없다.5채널을 같은g로 나누므로 채널 간 상대 진폭은 보존된다. 채널별 정규화나 주파수 제거는 하지 않는다. 고정 ZC 임계값0.01은 이 조건에서 정규화된 무차원 파형에 적용되므로 원래 전압 단위의0.01과 의미가 다르다. 강의 기준과 혼동하지 않는다.

원본1,920시행의19창을 모두 변환한다. 기존 기록 공유/기록 분리4-fold를 그대로 재사용하고 개발1,536시행만 학습·평가한다. 직접8클래스 XGB400·3,200트리·깊이6·lr.05·subsample.9·colsample.8·lambda1·seed42·CUDA6스레드를 유지한다. 총8회 학습이다. 원래384시험은 제외하고 기존모델·결과를 덮어쓰지 않는다. 기준은 바로 앞에서 완수한25특징 원파형의 동일 분할8회다.

단위 검사는 공통 양의 배율 불변성,영신호,현재 창 밖 변형 불변성이다. 실제 입력에서도 baseline RMS로 계산한g와 직접g를 비교하고 변환 후 양의 창의 전채널 RMS가1인지 확인한다. 모델·확률·클래스 지원·분할·scaler는 기존 독립 검증 절차로 확인한다. 두 프로토콜의 모든창 정확도,학습시간,모델크기,대표 CPU 특징+추론 중앙값/p95를 함께 보고한다.

기록 분리에서 개선되지 않으면 이 공통 진폭 정규화가 전이 실패를 해결한다는 가설은 지지되지 않는다. 기록 공유 점수가 내려가더라도 숨기지 않는다. 결과를 보고 정규화 방식·임계값·모델을 추가 탐색하지 않는다. 이 대조는64개 기록 목표 모델의 일반화 확증이나 원필터의 검증이 아니며 논문 전문 부재도 해소하지 못한다.
