# v29: 410특징 RBF SVM의 제한된 내부 비교

2026-10-22 UTC. 기존 HEAD 7690b21을 보존하며 새 학습 전에 고정한다. v20과 v21은 현재 410특징·64목표에서 C=100, gamma=scale 하나만 학습했다. 이전 240특징·직접 8분류 SVM은 이 비교를 대신하지 않는다. v25는 이 SVM의 보완 오류를 이용하지만 지원벡터가 내부 학습 창의 96.64/97.31/97.03%이며 대표 바깥 SVM만 약 79.96 MB다. 기본 gamma는 학습 전용 표준화 뒤 1/410과 수치상 같다. 커널 폭과 규제를 바꾸면 같은 입력의 오류·비용 균형이 개선되는지 검사한다. 바깥 오류로 설정을 정하지 않는다.

## 고정 조건과 후보

현재 200 ms·100 ms 이동·시행당 19창·5채널·410특징·64학습 목표·8출력 클래스를 유지한다. 기존 v10 분할 ID 및 개발 1,536시행·64기록을 그대로 사용한다. 내부 학습 768/평가 256시행, 바깥 학습 1,024/평가 512시행이다. 원래 시험 384시행은 새 평가·선택에 사용하지 않는다. 과거·미래 창, 시행 투표·경계 힌트, 기록 ID 추론 입력은 없다.

기존 C100/gamma=scale은 재사용한다. 새 후보는 정확히 세 가지다.

| 후보 | C | gamma | 변경 이유 |
|---|---:|---:|---|
| regularized | 10 | scale | 오분류 비용을 낮춰 더 강한 규제 |
| broad | 100 | 1/820 | 거리의 영향 감소, 더 넓은 RBF |
| narrow | 100 | 2/410 | 거리의 영향 증가, 더 좁은 RBF |

표의 gamma 변화는 RBF 거리 제곱 계수의 1/2배·2배다. 물리적 신호 입력 길이는 변하지 않는다. 나머지는 기존 SVC: probability=False, max_iter=-1, tol=.001, cache_size=1024 MB, random_state=42, ovr decision_function이다. 지원벡터 제한·표본 축소·조기 종료는 없다. CPU libsvm을 사용한다. XGB 재학습은 없다.

각 SVM은 학습 시행을 3개로 나눈 OOF 점수로 sigmoid를 보정하고 전체 학습 자료로 최종 SVC를 학습한다. ensemble=False, n_jobs=1이며 모든 base fit에 학습 전용 StandardScaler를 적용한다. 내부 보정 seed 20261123+fold, 바깥 보정 seed 20261133+fold를 유지한다. 같은 시행의 19창은 보정 fold를 넘지 않는다. 1확률모델은 4 base SVC fit와 64 sigmoid 보정이다.

## 선택과 비용 제한

v25의 XGB/LDA 확률, 4:1 비율, fold별 SVM 비중 0.4/0.2/0.3을 모두 고정한다. 세 새 SVM의 확률만 교체한다. 각 내부 평가에서 결합 정답 창 수로 선택하되 SVM 파일 크기가 기존 SVM의 1.25배 이하인 후보만 허용한다. 정답 수 동률이면 기존 모델을 우선하고, 새 후보 사이에서는 파일 크기·지원벡터 수·이름 순서로 결정한다. 비중·보정 방식·특징·seed를 동시에 탐색하지 않는다.

9개 내부 확률모델(36 base fit)을 끝낸 뒤 선택 파일과 해시를 고정한다. 해당 내부에서 엄격히 개선되고 크기 제한을 통과한 후보만 바깥 전체 학습 자료에 다시 학습한다(최대 3모델·12 base fit). 새 바깥 후보가 1.25배 크기 제한을 넘으면 점수와 비용을 남기되 해당 fold는 기존 모델로 되돌린다. 바깥 점수로 후보나 비중을 다시 고르지 않는다. 모든 실패를 보존한다.

기존 한 내부 보정 모델은 약 100초, 바깥은 약 160초의 wrapper fit이었다. 새 내부 fit 합 약 15분, 바깥 최대 약 8분을 예상하지만 후보에 따라 달라질 수 있으며 예측·독립 복원·비용 측정은 별도다. 대표 분할은 첫 새 바깥 선택 fold, 없으면 내부 fold0이다. 기존 결합과 선택 결합(바깥 선택이 없으면 세 후보)을 동일 첫 20평가 시행의 380창, 19예열에서 측정한다. 특징 계산·scaler·전체 확률을 포함한 CPU batch1 중앙값·평균·p95, 모델 크기, wrapper fit와 base fit 합을 따로 기록한다. 기존 v25 라벨 전용 호출 생략 비용과 섞지 않는다. 실측 비교 중 다른 학습·검증은 실행하지 않는다.

## 검증과 해석

모든 새 모델의 4개 base 체크포인트, 입력 해시, 클래스 지원, 수렴, 학습 전용 scaler, 보정 시행 분할과 OOF 점수, 64개 sigmoid 계수, 최종 확률·라벨·metric을 독립 복원한다. 선택과 크기 제한, 바깥 29,184창의 정확한 포함, 기존 파일 해시도 재계산한다. 각 모델과 결과를 기존과 별도 경로에 남긴다. 전체 19창을 독립 관측처럼 신뢰구간을 계산하지 않으며 fold 표준편차는 기술 통계다.

이는 반복 사용된 개발 자료의 후속 선택이다. 내부 자료도 v10 이후 반복 사용됐고 바깥 결과도 이미 알려졌다. 새 외부 시험이나 정직한 단회 nested-CV 보장으로 표현하지 않는다. 64목표는 64기록과 일대일이고 기록 공유의 성능 개선과 새 기록 일반화는 다르다. 논문 전문·원필터 설정·독립 세션은 미확보다. v23의 과거 창 조건과 원래 단일 창 결과를 보존한다. 외부 게시·업로드·공개 ZIP 갱신은 하지 않는다.
