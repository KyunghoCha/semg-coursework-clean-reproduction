# 클래스 공분산 공유 대조 v18

2026-10-21 UTC, 학습 전 고정. v17의410특징 축소 QDA는 학습99.90–100%,내부 검증49.12%로 강한 과적합과 양립했다. 클래스마다410×410 공분산을 따로 사용하는 복잡도를 줄이면 검증과 비용이 개선되는지 확인한다. 기존 전체 구현에서 LinearDiscriminantAnalysis 또는 공분산 공유 모델은 미수행이었다. 이를 근거로 축소 LDA 한 가지만 추가하며 SVM·PCA·분포 변환·축소 강도 탐색을 동시에 하지 않는다.

[scikit-learn1.7.2 LDA](https://scikit-learn.org/1.7/modules/generated/sklearn.discriminant_analysis.LinearDiscriminantAnalysis.html)와 설치된 `_solve_lstsq`, `_class_cov` 소스를 직접 읽었다. 고정 생성자는 `LinearDiscriminantAnalysis(solver='lsqr',shrinkage=None,covariance_estimator=LedoitWolf(store_precision=False,assume_centered=False))`다. 각 클래스 학습 창의 LedoitWolf 공분산을 경험적 사전확률로 가중해 하나의 공분산을 만들고 클래스별 평균은 유지한다. v17과 동일한 공분산 추정법에서 공유 여부를 바꾼다. 별도의 표준화된 shrinkage='auto'와 같은 알고리즘이라고 부르지 않는다. 회전·차원축소의 transform은 쓰지 않는다.
