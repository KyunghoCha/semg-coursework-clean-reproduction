# 초기창 정보의 시행 분리와 기록 분리 대조

초기 기준창 90.43%는 시행을 제외한 v8 OOF 예측이었다. 각 모델은 1,024시행에서 학습했고 평가 512시행과 교집합이 없었다. 그러나 세 분할 모두 기록 64개가 학습·평가에 공유됐다. 모델 재학습 없이 구한 결과이며, 특징 설계의 개발 자료 노출은 남는다.

부모 요청에 따라 기록 공유의 영향을 작은 별도 대조로 확인한다. 원래 19창·8클래스 주평가와 논문 목표를 이 문제로 대체하지 않는다. 여기서는 같은 초기 mark+0.0–0.2초 창 하나로 학습하고 같은 초기창으로 평가한다. 기존 90.43%와는 학습 구간·모델이 다르므로 아래 두 프로토콜 사이 차이만 기록 공유 대조로 해석한다.

## 고정 조건

개발 1,536시행의 초기창 905특징을 사용한다. 원래 시험 384시행은 제외한다. 직접 8클래스 XGB 400회, 깊이6, lr .05, subsample .9, colsample .8, lambda1, seed42, CUDA, 6스레드, 총 3,200트리다. 보조 64개 목표를 쓰면 기록을 빼는 순간 해당 학습 목표도 사라지는 다른 문제가 생기므로, 두 프로토콜 모두 동일한 직접 8클래스를 쓴다. scaler는 각 학습 부분에만 맞춘다. 모델 후보 선택·튜닝은 하지 않는다.

- 시행 분리: 8클래스 층화 4-fold, shuffle=True, random_state=20261116. 각 fold 1,152시행 학습·384시행 평가다.
- 기록 분리: 64개 기록을 기록의 8클래스로 층화한 4-fold, 같은 seed다. 각 fold 48기록 학습·16기록 평가이며, 각 클래스의 8기록 중 6개/2개로 나뉜다. 기록별 개발 시행 수가 달라 정확한 시행 수는 manifest에 기록한다. 모든 개발 시행이 한 번씩 평가된다.

총 8회 학습이며 200ms·5채널·특징·모델은 같다. 두 프로토콜의 학습 표본 수가 완전히 같지는 않으므로 수량 차이를 숨기지 않는다. 기록별로 한 피험자×조건만 있으므로 기록 효과와 특정 피험자·조건의 결합 효과는 분리되지 않는다. 기록 분리도 기존 데이터에 대한 진단이며 새 독립 수집 자료라고 부르지 않는다.

## 검증과 순서

시행·기록 교집합, 각 클래스의 기록 수, 전체 개발 시행의 단 한 번 평가, scaler 학습 범위, GPU 장치와 실제 트리 수를 검사한다. 저장 모델과 확률을 복원하고 지표를 별도 계산한다. 전체 정답 수와 4-fold 평균±fold 표준편차를 보고하며 신뢰구간으로 부르지 않는다. 초기창의 생리적 휴식 여부나 제공 CSV 사전 필터의 인과성은 확인되지 않았다.

v9를 끝낸 뒤 이 짧은 대조를 우선 실행하고, 사전에 고정한 v10과 v11을 이어 간다. 이 대조의 결과는 v10의 후보 풀·선택 규칙에 반영하지 않는다. 학습 예상은 수 분이며 실제 로그로 갱신한다. 개별 예측과 기록별 manifest는 로컬 비공개로만 저장한다.
