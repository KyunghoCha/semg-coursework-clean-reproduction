# 같은 200ms 창에서 세부 주파수 분포 보존

6차의 대역별 채널 관계 추가는 동일 트리 수에서 85.58→88.39%였다. 7차 첫 두 용량 비교와 첫 대역 제거 결과까지 확인했으며 전체 비교는 진행 중이다. 넓은 대역 내부의 파워 분포를 합계로 압축한 것이 남은 병목인지 별도로 검사한다. 추가 후보의 결과를 보기 전에 아래 조건을 고정한다.

## 입력과 단일 변경

같은 1.5–3.5초, 200ms 창, 100ms 이동, 19창, 5채널을 쓴다. 기존 400특징을 모두 보존하고 각 채널의 0–500Hz 한쪽 periodogram 101개 bin을 추가한다. 빈 간격은 5Hz이며 시간 신호를 늘리거나 zero padding하지 않는다. 창별 평균 제거, periodic Hann, nfft200, fs1000, density 정규화를 쓴다. 특징은 `log10(max(PSD × 5Hz, 1e-12))`이며 주파수 우선·채널 순으로 펼친 505개다. 총 905개 특징이다. DC와 Nyquist도 포함한다. 원신호 단위를 임의로 V로 바꾸지 않는다. 1e-12는 원신호 단위 제곱의 수치 바닥값이며 학습하거나 정답에 맞춘 임계값이 아니다.

[SciPy periodogram API 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)와 설치된 SciPy 1.16.3 함수 설명을 기준으로 수식·단위를 대조한다. 직접 DFT 계산, 합성 정현파, 진폭 2배의 파워 변화, 영신호, 창별 독립 계산을 검사한다. 원래 400개 특징의 값도 그대로인지 확인한다.

## 고정 대조와 평가

7차에서 이미 고정한 3개 분할을 그대로 쓴다. 개발 1,536시행의 각 분할은 학습 1,024·평가 512시행이며 기존 시험 384시행은 제외한다. 7차의 `cross400` 저장 결과가 대조다. 세부 파워 추가 후보만 3회 새로 학습한다. 대조 모델을 다시 학습하거나 이미 본 평가 자료를 새로운 외부 시험이라고 표현하지 않는다. 재사용한 개발 분할에서 가설을 비교하는 실험이므로 선택 편향이 남는다.

XGB 64개 학습 목표, 400회, 깊이6, lr .05, subsample .9, colsample .8, lambda1, hist CUDA, seed42, n_jobs6을 유지한다. 총 25,600개 트리다. 추가 특징으로 colsample의 절대 후보 수는 늘어난다. scaler는 해당 학습 창에서만 fit한다. 평가 입력은 신호 특징뿐이고 사람·파일 ID는 제공하지 않는다. 확률 64개를 사람 축으로 합해 원래 8클래스를 출력한다.

주평가는 모든 29,184개의 독립 창 정확도와 macro F1이다. 과거 5창 문맥은 별도 보조 점수로 기록한다. 새 후보는 같은 분할의 cross400보다 평균 정확도가 0.5%p 이상 높을 때만 채택 대상으로 삼는다. 7차 cross800과의 정확도·크기 차이도 같은 평가 범위에서 보고하되 비용을 숨기지 않는다. 새 시험 평가나 추가 튜닝은 이 계획에 포함하지 않는다. 개선 여부와 상관없이 모두 기록한다.

## 비용과 해석

먼저 7차와 기존 모델의 통제 비용 측정을 끝낸다. 그 뒤 새 후보 3회를 실행하고, 첫 분할 모델을 같은 입력·스레드·동기화 방식으로 CPU/GPU 각각 추가 측정한다. 추출 비용을 포함한 크기·지연 비교를 보완한다. 이는 작은 모델을 우선한다는 임의의 성능 제한이 아니다.

같은 사람·기록의 다른 시행을 분류하는 질문은 유지한다. 세부 스펙트럼이 도움을 주어도 생리 신호와 기록 특성을 분리한 증거는 아니다. 이 단계에서 창 수를 줄이거나 어려운 위치를 제외하지 않는다.
