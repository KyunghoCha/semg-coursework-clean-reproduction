# 세부 파워 추가의 결과와 다음 판단

기존 대역 합계가 놓치는 분포를 검사하기 위해 200ms·19창·64개 학습 목표·400회·25,600트리를 유지하고 5Hz 파워 505개만 추가했다. 계획은 363e6dc에서 실행 전에 고정했다. v7의 시행 분할을 그대로 재사용했으며 scaler는 각 학습 창에만 맞췄다.

세 분할은 89.7512/90.2241/89.3606%, 전체 26,201/29,184창으로 89.7786±0.3530%였다. 대조 cross400보다 +1.8640%p, cross800보다 +1.3158%p다. 모델 세 개를 복원해 원래 확률·예측과 일치하고 scaler 재계산, 64→8 확률 합, 분할과 시험 교집합 0을 검증했다.

첫 모델은 36,339,488바이트이며 CPU 전체 처리 중앙값/p95는 6.1037/7.4888ms였다. GPU DMatrix 경로는 232.9461/249.2245ms였다. 모든 기본 비용 측정 32조합을 완료하고 256개 원시 시간 묶음을 재계산했다. 총 267개 학습 시간 기록 중 4개는 기존 모델 비용 복원이다. 저장 모델은 47개, 상세 구조를 비교한 대표는 18개다.

개발 자료의 paired 분석에서 개선 시행 589, 하락 297, 동일 650개였다. 겹친 창을 개별 표본처럼 다시 뽑지 않고 시행 평균 차이를 클래스별로 bootstrap했다. 차이 구간은 +1.5042~2.2307%p지만 반복 사용한 개발 자료와 적응적으로 정한 특징에 조건부인 기술적 구간이다. 독립 일반화 증거로 해석하지 않는다.

추가 파워 특징의 학습 gain은 전체의 29.4986%였고 300Hz 17.8058%, 420Hz 2.9744%에 집중됐다. 기존 교차 특징은 21.2455%였다. 중요도는 학습 중 분할 이득이며 인과 효과가 아니다. 두 주파수가 60Hz의 5·7배라는 사실과 기원이 미확인이라는 사실을 구분한다. 다음은 이 두 특징의 추가·제거 대조와 같은 세부 표현에서 학습 목표 8/64개의 영향을 분리한다. 원래 384시행 시험은 사용하지 않는다.
