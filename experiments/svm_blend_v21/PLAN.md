# v21: 작은 SVM 확률 결합

2026-10-21 UTC, 결합 점수 계산 전에 고정한다. v20의410특징 RBF SVM 한 설정은 단독 교체에 실패했다. 그러나 현재 고정 XGB80%+LDA20%가 틀린 내부 관측655개를 맞혔고 세 분할 모두에서 보완 오류가 존재한다. SVM 확률을 작은 비중으로 넣으면 이 보완을 일부 얻을 수 있는지 검사한다. 더 큰 C/gamma 탐색이나 특징·입력 변경은 하지 않는다.

## 입력과 선택

현재200ms·100ms 이동·19창·5채널·410특징·64목표를 유지한다. 같은 v10 내부3분할/바깥3분할을 그대로 사용하고 역사적384시험을 제외한다. 현재 내부 예측을 만드는 데 사용한 전체768학습/256평가 시행을 유지한다. 내부 새 SVM fit는0회다.

고정 기준 확률은 q0=0.8*p_XGB+0.2*p_LDA이며, v19의 고정 선택을 바꾸지 않는다. 후보 q=(1-beta)*q0+beta*p_SVM에서 beta는0,0.05,0.10,0.20으로 한정한다. p_SVM은 v20의 시행 단위 sigmoid 보정 후64확률을8클래스로 합한 값이다. 각 내부 분할에서 정답 창 수가 가장 큰 beta를 고르고 동률이면 작은 beta를 고른다. 세 분할 정답 수 합으로 고른 공통 beta도 기술 통계로 기록하되 바깥에는 각 내부 분할의 선택만 적용한다.

선택 파일을 바깥 SVM fit/예측 전에 고정한다. beta=0이면 해당 바깥 모델을 추가하지 않고 v19를 유지한다. beta>0인 분할에서만 전체 바깥 학습1,024시행으로 v20과 같은 C100 RBF·시행 보정3fold·ensemble=False SVM을 학습한다. 보정 seed는20261133+fold이며 바깥 평가512시행은 모든 학습·scaler·sigmoid fit에서 제외한다. 최대3개 확률모델=base SVM12fit, 별도 sigmoid192개다. 바깥 결과를 보고 가중치·보정·평가 단위를 바꾸지 않는다.

## 비용과 해석

기존 내부fold0 기준36.53MB·CPU3.99ms에 SVM60.94MB·모델확률30.86ms가 추가된다. 특징 계산을 공유해도 전체는 약97.47MB·35ms로 예상한다. 이는 실측 결합 비용이 아니다. 바깥 SVM은 더 많은 학습 창 때문에 더 크고 느릴 수 있다. 현재 v20 내부3모델의 전체 실행은 약7분이었으며 바깥 최대3모델과 검증·측정에는 약10–20분을 예상하되 정확한 비용은 실행 후 기록한다. 자료·모델을 줄여 예상 시간에 맞추지 않는다.

추가 비용에 비해 내부 개선이 전혀 없으면 새 바깥 fit 없이 종료한다. 개선이 있어도 현재 단일 기준 XGB나 작은 XGB/LDA 결합의 우월성을 자동으로 대체하지 않는다. 동일 창 정확도, 추가 정답/손실, 크기, 실제 학습시간, CPU 추론 중앙값/p95를 함께 보고한다. 대표 바깥 선택 분할의 기존 결합과 새 결합을 같은256개 개발창·20예열·200회batch1에서 측정한다. 신호취득200ms·모델로딩은 제외하고 특징+각scaler+확률합산을 포함한다. 바깥 추가모델이 없으면 새 결합 비용 측정을 하지 않는다.

## 검증과 공개 제한

내부 원확률/ID/레이블/정답수와 선택을 독립 재계산한다. 모든 새 SVM의4base fit 입력 해시·학습 scaler·64클래스·수렴·보정 시행 분할·학습OOF·sigmoid·최종확률을 v20과 같은 방식으로 검증한다.19창을 독립 표본으로 통계검정하지 않는다. 내부 관측은 전체OOF가 아니며 반복 개발과 과거 바깥 점수 노출이 남는다.64목표가64기록과 일대일인 한계도 바뀌지 않는다. 새로운 외부시험·논문 정확재현·기록 일반화로 표현하지 않는다.

외부 push·업로드는 재시도하지 않고, 승인 대기 중인 v19의652파일 ZIP을 수정하지 않는다. 새 결과는 clean 프로젝트의 v21 전용 경로에만 쌓는다.
