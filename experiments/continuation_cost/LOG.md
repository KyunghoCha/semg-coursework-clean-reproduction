# 완료한 후속 CPU 비용 비교

모든 학습 종료 후8조건을 별도 프로세스로 측정했다.같은256개 개발창,CPU6스레드,20예열/200반복이며 특징+scaler+확률 추론을 포함한다.200ms 신호 취득과모델 로딩은 제외한다.각 저장모델의CPU예측,캐시와특징동등성,원시시간 중앙값/p95,모델해시 보존을 검증했다.

바깥fold0의전체/좁은/결합은36.07/36.75/72.82MB,전체중앙값4.60/4.69/7.78ms였다.내부fold0의RF100과ET400은68.16/365.09MB,14.54/46.11ms다.서로다른학습규모의내부/바깥모델을같은정확도점수로비교하지않는다.좁은표현은현구현에서전체주파수특징을계산한뒤10열만골라추론시간우위는확인하지못했다.

학습시간은원래fit관측값이어서자원경합을완전히통제한재측정이아니다.모델시간을다시잰것은재학습이아니다.전체목록에서저장모델수,고유실험의fit기록수,대표추론조건수를구분한다.
