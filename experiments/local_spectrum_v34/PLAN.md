# v34: 현재 200ms 내부의 시간별 주파수 분포 — 단독 XGB

2026-10-22 UTC. 기준 커밋 c1107da의 77개 검사와 v33 결과를 보존한다. 이 실험은 여러 모델의 예측 결합, 과거 창 평균, 기록 일반화 실험이 아니다. 외부 게시·업로드는 하지 않는다.

## 가설과 중복 확인

기존 410/905차원은 전체 200ms의 스펙트럼과 채널 관계, 40ms×5 광대역 RMS를 포함한다. v15의 440/445차원은 전체 200ms AR(6) 계수·잔차다. 짧은 구간의 주파수 분포가 창 내부에서 바뀌는 순서는 직접 표현하지 않는다. 내부 XGB800에서 첫 위치 83.59%와 뒤쪽 위치의 95%대 차이는 새 표현을 검토할 근거지만 그 원인이 비정상성이라는 증거는 아니다. 창 위치는 입력에 넣지 않는다.

먼저 개발 자료만 새 특징을 계산하고, 내부 학습에서 기존 905+35 AR 특징과 열별 상관을 검사한다. 내부 평가 오류와 새 특징의 시간 변화량의 관계를 기록·클래스·log RMS·40ms RMS 변동을 통제한 기술적 잔차 상관으로 본다. 19창을 독립 관측으로 놓고 유의확률을 계산하지 않는다. 이 진단은 효능을 입증하지 않는다. 기존 표현과 직접 중복되거나 모든 내부 분할에서 오류 관련성이 반대/무관하면 실행 여부를 재검토해 근거를 남긴다. 대역 경계나 표현은 진단 결과로 바꾸지 않는다.

## 정확한 특징 정의

각 입력은 현재 200샘플×5채널뿐이다. 연속한 비중첩 50샘플 네 블록으로 나눈다. 각 블록/채널의 평균을 먼저 빼고, 정확히 상수인 블록은 0으로 처리한다. 주기형 Hann `h[n]=(1-cos(2πn/50))/2`, n=0..49를 곱한다. zero padding 없이 50점 실수 FFT를 구한다. 주파수 간격은 20Hz이며 새로운 주파수 해상도를 만들어 내지 않는다.

`E[b,c] = Σ |FFT[(x−mean(x))*h](f,c)|²`, 대역은 `[20,100)`, `[100,200)`, `[200,350)`, `[350,450)` Hz다. 포함 bin은 각각 20/40/60/80, 100/120/140/160/180, 200/220/240/260/280/300/320/340, 360/380/400/420/440 Hz다. 0Hz와 Nyquist 500Hz를 제외한 모든 포함 bin의 단측 배율은 같아 상대 비율에서 상쇄된다.

출력은 `E[b,c]/max(Σ_b E[b,c], float64.tiny)`이다. 분모 하한은 약 2.2251e−308이고, 영신호는 0이 된다. log 변환·전압 단위 기반 임계값·학습된 대역 선택은 없다. 출력 순서는 시간 블록→대역→채널이며 4×4×5=80차원이다. 채널·시간 블록당 네 비율의 합이 1이라는 의도된 내부 종속성은 있다. 기존410차원 뒤에 붙여490차원으로 한 XGB에 제공한다. 원래25TD와 그 ZC 임계값은 바꾸지 않는다. 어떤 신호도 현재200ms 밖에서 읽지 않고 블록 경계는 현재창의 고정 위치일 뿐 시행 경계가 아니다.

## 고정 대조와 선택

하나의 후보만 학습한다. 기존 XGB800과 같은 깊이4·800회·learning_rate .05·min_child_weight1·lambda1·alpha0·gamma0·subsample .9·colsample_bytree .8·hist/CUDA·n_jobs6·seed42·early_stopping 없음이다. 64학습목표의 확률을 조건별8개로 해독하는 한 모델이다. 64목표가64기록과 일대일인 한계는 유지한다.

대조는 같은 v10의 내부 학습768/평가256시행, 바깥 학습1024/평가512시행, 전체1536개 개발 시행/64기록/19창/200ms/100ms stride다. 원래384시험 시행은 새 특징 계산·선택·평가에서 제외한다. StandardScaler는 각 학습 부분에서만 fit한다. 입력정보를 더하는 효과는 같은 설정의 기존410차원 XGB800과 비교한다. 80차원 추가로 무작위 특징 추출의 실현도 바뀌므로 순수 정보량만의 인과 효과로 단정하지 않는다.

현재 주결과 v33을 보존하기 위해 각 fold의 incumbent는 v33에서 이미 내부 선택된 단독 모델로 고정한다(fold0/2:410차원800회, fold1:410차원1600회). 새 후보가 해당 incumbent의 내부 정답보다 최소10개 더 맞히고, 저장 크기가 해당 fold의 기존 XGB800의1.5배 이하면 채택한다. 아니면 기존 v33 선택을 유지한다. 이 규칙·대역·모델 설정은 새 fit 전에 고정한다. 세 내부 fit 후 선택 파일/해시를 저장하고, 채택한 fold만 바깥 학습을 수행한다. 바깥 점수로 재선택하지 않는다. 기존 고정800회 대조와 v33 incumbent를 결과에서 구분한다.

예산은 내부3fit, 바깥최대3fit다. 예상10–25분이며 특징 생성/검증 시간은 별도 기록한다. 모든 신규 모델을 CPU 복원해 입력·분할·scaler·64클래스·CUDA/800회/51,200트리·확률·8클래스 라벨·수동지표와 기존파일 보존을 확인한다. 개선 시에만 대표 채택 fold의 같은380창에서 특징 계산 포함 비용을 짧게 비교한다. 불리한 후보에는 긴 추론 비용 측정을 하지 않는다. 모델 크기와 실제 학습 시간은 실패도 모두 남긴다.

이미 반복 노출된 개발 평가다. 새로운 외부 시험·논문 정확재현·기록 일반화 해결로 부르지 않는다. 전체 창 정확도를 주지표로 유지하며 높은 점수를 위해 창/시행을 제외하거나 투표하지 않는다.
