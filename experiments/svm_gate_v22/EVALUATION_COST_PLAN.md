# 바깥 평가 전체의 라벨 전용 지연 확인

2026-10-21 UTC, 추가 측정 전에 고정한다. 원래256개 개발 입력 중200개를 측정한 비교에서 SVM호출은5/200=2.5%였다. 이 입력에는 대표 모델의 학습 시행도 포함될 수 있다. 전체 바깥 평가의 호출률2,362/29,184=8.09%보다 낮으므로 해당p95를 바깥 평가 전체의 지연으로 일반화하지 않는다. 원래 비교와 원시시간은 보존한다.

현재 고정된 바깥fold0의512평가시행×19창=9,728창을 하나도 제외하지 않고 CPU에서 다시 실행한다. 같은 frozen모델·beta.2·margin기준·특징을 유지한다. 첫20창으로 예열하고 전체9,728창 각각의 특징+scaler+필요한모델+라벨결정 지연을1회씩 측정한다. 시행별 선택이나 어려운 창의 제거는 없다. 총SVM호출792개와모든라벨이기존CPU검증에일치해야한다. 신호취득·CSV읽기·모델로딩은제외하고현재창배열에서특징을만드는계산은포함한다.

중앙값·평균·p95·p99와 SVM호출/생략 경로의 집계를 보고한다. 단일호출을9,728번 실행한 분포이며 반복독립실험이나CI가아니다. 다른두바깥모델의시간을측정했다고주장하지않는다. 기존200창의전체결합/생략쌍비교와자료범위를구분한다. 예상실행은약1–2분이며실제시간을기록한다. 새학습·threshold선택·성능조건변경·외부전송은없다.
