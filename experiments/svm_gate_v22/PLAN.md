# v22: 분류 라벨을 보존하는 SVM 호출 생략

2026-10-21 UTC, 호출 비율·새 비용 측정 전에 고정한다. v21의 처음 두 바깥 중간 점수는 이미 관측했다. 새 모델·가중치·특징을 선택하는 실험이 아니라, 그 전에 고정한 결합의 분류 라벨을 보존하는 계산 경로 검증이다. v21의 원래 전체 확률 경로와 비용은 먼저 별도로 완료·보존한다.

## 근거와 식

v21의 q=(1-beta)*q0+beta*s에서 q0는 고정 XGB/LDA 8확률, s는 보정 SVM의8확률이다. q0의 최대 클래스 i와 차순위 간 차이를 delta라 하면 모든 다른 클래스 j에 대해 q_i-q_j >= (1-beta)*delta-beta다. 따라서 delta>beta/(1-beta)이면 SVM의 출력과 무관하게 최종 argmax는 i다. beta=.2이면 기준은.25다.

구현은 float64에서 delta>.25+1e-8인 창만 SVM 호출을 생략하고 q0의 argmax를 반환한다. 그 외 모든 창에서는 기존 세 모델의 결합을 그대로 계산한다. 경계와 동률은 생략하지 않는다. 이 경로는 **분류 라벨 전용**이다. 전체 결합 확률·신뢰도·log loss를 요청하면 SVM을 생략할 수 없으며 q0를 원래 결합 확률이라고 반환하지 않는다.

## 고정 검증

새 학습0회, threshold 탐색0회. 현재200ms·19창·5채널·전체 개발 분할과모델을 그대로 쓴다. v21의 모든 내부14,592관측과 바깥29,184창에서 기존 라벨과 완전히 일치하는지 검사한다. 생략/호출 창 수를 집계하고 각 stage/fold에서 하나라도 라벨이 달라지면 이 최적화를 채택하지 않는다. 확률 범위·행합과 경계 및 tie를 합성 반례로 검사한다. 원래384시험은 읽어 평가하지 않는다.

최종 모델 파일 해시와 frozen beta를 보존한다. 호출 생략은 모델 저장크기를 줄이지 않으며, 바깥 대표 모델 약120MB는 그대로일 수 있다. 비용은 동일256개 개발창에서 전체 결합과 라벨 전용 생략을 비교한다. 각20회 예열·200회 batch1,CPU6 라이브러리스레드/단일 libsvm,특징+각scaler+실제실행분기 포함,취득200ms·모델로딩 제외다. 호출 여부에 따라 지연 분포가 섞이므로 중앙값·평균·p95와 호출률을 모두 보고한다. 높은 p95가 남으면 숨기지 않는다. 호출 비율을 모르므로 시간 개선치를 미리 보장하지 않는다.

확률 또는 라벨이 달라지는 신호변환을 추가하지 않으며 현재64기록의 의존성·반복CV노출·원필터·마커·논문정보 부족은 그대로다. 공개 push·업로드는 하지 않고 v19의승인대기652파일도수정하지않는다.
