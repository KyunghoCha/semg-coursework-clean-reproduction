# 현재 창 특징에 학습 주성분을 덧붙이는 대조

2026-10-22 UTC, 새 학습 전 고정. 기준은 v25 로컬 커밋 062a307f9ee12b985fe991e3087f8963cbf6e602의 91.9819%다. 외부 게시·업로드는 금지 상태를 유지한다.

## 내부 근거와 다른 후보

최신 내부 세 부분의 오류는 458/375/429개, 합계 1,262개다. 이 중 정답이 상위 2개 안에 있는 오류는 875개이고 어느 한 구성 모델은 맞힌 오류도 682개다. 가장 큰 방향별 클래스 혼동은 72개(오류의 5.7%)로 특정 쌍만의 오류가 아니다. 바깥 오류를 목표로 후보를 설계하지 않았고 이번 진단에서 바깥 예측 파일을 읽지 않았다.

각 내부 학습 14,592창의 표준화 특징에는 절대 상관이 0.9를 넘는 열 쌍이 367/393/387개 있다. 상위 64개 주성분이 설명하는 학습 분산은 65.67/65.77/65.66%다. PCA만 쓰면 나머지 분산의 유용한 정보까지 버릴 수 있으므로 기존 410열을 그대로 보존하고 64주성분을 추가한다. 가설은 여러 특징이 함께 변하는 방향의 분할을 얕은 트리가 활용할 수 있다는 것이다. 학습 공분산과 잔여 오류가 이 가설의 검증 근거일 뿐 효과나 생리학적 의미를 입증하지 않는다.

작은 클래스 쌍 보정은 오류가 넓게 분산돼 후순위다. seed 평균은 기존 정보에 모델 저장·추론 비용을 추가하고, 기존 905특징 숲은 내부 성능이 낮았으므로 이번에 함께 실행하지 않는다. 410특징에 PCA를 추가해 동일 XGB와 비교한 기록은 기존 PLAN·run 검색에서 없었다. PCA 뒤 SVM은 이전에 보류한 다른 방법이다. 추가 PCA 성분 수·규제·비중 탐색을 하지 않는다.

[scikit-learn 1.7.2 PCA 공식 문서](https://scikit-learn.org/1.7/modules/generated/sklearn.decomposition.PCA.html)를 읽었다. PCA는 입력을 중심화하되 열별 크기를 맞추지는 않으므로 먼저 학습 전용 StandardScaler를 사용한다. full SVD와 whiten=False를 명시하고, 백색화·저분산 특징 제거는 하지 않는다. 이 자료에서의 성능 개선은 검증할 가설이다.

## 고정 구현과 선택

현재 200 ms×5채널·100 ms 이동·모든 19창, 같은 64개 개발 기록·1,536시행 및 v10 시행 분할을 유지한다. 원래 384시험은 다시 사용하지 않는다. 과거·미래 창, 시행 투표·경계 힌트·창 위치·기록 ID는 추론 입력이 아니다. 학습 64목표와 기록 64개의 일대일 한계는 그대로다.

각 실제 학습 부분에만 StandardScaler를 fit하고 그 출력에 PCA(n_components=64,svd_solver='full',whiten=False,copy=True)를 fit한다. 현재 표준화 410열 뒤에 투영 64열을 붙여 474열을 만든다. 64라는 수는 추가 특징의 고정 예산이며 클래스 또는 기록 ID를 64열로 입력하는 것이 아니다. 바깥 재학습 때 scaler와 PCA도 바깥 학습 부분만 사용해 다시 fit한다.

XGB는 shallow800의 depth4·800회·learning_rate .05·min_child_weight1·lambda1·reg_alpha0·gamma0·subsample.9·colsample.8·seed42·hist CUDA·n_jobs6이다. 조기 종료·새 학습 표본 축소는 없다. v25의 분할별 beta .4/.2/.3 및 XGB:LDA 4:1은 고정한다. 기존 LDA/SVM은 같은 분할의 저장 모델을 재사용하고 새 XGB 부분만 교체한다. 모든 개발 학습 창을 사용한다.

내부 3fit를 완료한 뒤 각 fold에서 기존 v25보다 정답 창 수가 엄격하게 많고 새 XGB+scaler+PCA 파일 크기가 기존 XGB+scaler의 1.5배 이하일 때만 선택한다. 동률 또는 비용 초과는 기존 유지다. 선택 파일과 해시를 바깥 점수 계산 전에 고정한다. 선택된 fold만 바깥에서 새로 학습하므로 새 학습은 3–6회다. 예상 학습 8–20분, PCA는 수초 이내, GPU 메모리 기존 수준을 예상하되 실제 비용을 기록한다. 바깥 결과가 나빠도 후보를 다시 고르지 않는다.

## 검증과 보고

원래 분할과 전체 개발 1회 평가, 학습 전용 scaler·PCA 통계, PCA 축의 직교성과 변환 식, 원래 410열 보존, 창 행 순서/배치 불변성, 실제 CUDA 설정·라운드 수·클래스 지원, CPU 모델 복원, 확률 합과 지표를 검사한다. 원본 모델·예측 해시를 보존한다. 상관된 19창으로 독립 표본 신뢰구간을 만들지 않는다.

학습 시간은 scaler/PCA 준비와 XGB fit를 구분한다. 대표는 처음 선택된 바깥 fold이며 모두 탈락하면 내부 fold0이다. 해당 평가의 첫 20시행×19창=380창, 예열19창, CPU 라이브러리6스레드·SVM 단일 스레드에서 기존/새 XGB 단독과 고정 세 모델 전체 확률 경로를 측정한다. 현재 창 특징·scaler·PCA·모델·결합 포함, CSV·모델 로딩·신호 취득 제외다. v22 라벨 생략과 혼동하지 않는다. 단독 점수는 결합 선택의 보조 결과다. 실패해도 README에 기록하고 새 테스트 집합 평가와 공개 전송은 하지 않는다.

v24 XGB 선택→v25 비중 선택→이번 PCA 선택이 같은 내부 자료를 재사용한다. 바깥 점수를 보고 이번 선택 규칙을 바꾸지 않아도 반복 개발 노출은 남는다. 독립 미관측 시험·논문 정확재현·기록 일반화 해결로 표현하지 않는다. v23 최대 600 ms 결과는 별도 보존한다.
