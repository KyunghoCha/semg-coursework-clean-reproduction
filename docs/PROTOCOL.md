# 강의 기준 재현 명세

실험 조건을 고정한 시각은 2026-10-20 UTC이며 모델 점수를 보기 전이다. 이 공개본은 이후 파일별 정보와 결과 해석 설명을 정리한 문서로, 실험 설정은 동일하다. 이 문서는 사용자 제공 PPTX 네 개와 CSV를 새로 읽어 작성했다. 논문 DOI 10.1007/s13534-026-00607-7의 전문은 확보하지 못했다. 아래의 ‘통합’은 57쪽 통합 강의이며, 강의가 인용한 논문 설명과 직접 확인한 논문 전문을 구분한다.

## 입력과 과제

| 항목 | 확정한 강의 내용 | 출처 |
|---|---|---|
| 문제 | 네 손동작 × 30°/60°의 8클래스 단일 분류 | 1주차 3–7, 13쪽; 통합 3, 12쪽 |
| 채널 | Ch1 ECR, Ch2 ED, Ch3 FDS, Ch4 상완이두근, Ch5 상완삼두근 | 1주차 5쪽; 통합 19–20쪽 및 전극 그림 |
| 시행 | 휴식2초–동작1초–휴식2초, 30회/조건, 1kHz | 1주차 7쪽; 통합 23–24쪽 |
| 규모 | 8명 × 8조건 × 30회 = 1,920시행 | 통합 18, 24쪽 |
| 입력 예제 | 시행당 한 파일, 5000×5 또는 분석된 2000×5 | 1주차 11–12쪽 |
| 실제 입력 | 64 CSV, 파일당 30시행, 5신호열 + time/onset/mark | 전체 CSV 직접 조사 |

파일명은 `{피험자코드}_{각도} {동작코드}.csv` 형식이다. 한 글자 코드를 피험자 ID, 30/60을 각도, fist/open/pro/extor를 동작 코드로 읽는다. `pro→pronation`, `extor→supination`은 강의의 4동작과 원본 코드의 대응을 위한 **재현 가정**이다. CSV에는 extor의 사전이 없어 해부학적 명칭을 확정할 수 없다. 계산상의 클래스는 원본 코드 그대로 유지한다. 클래스 순서는 `30_extor,30_fist,30_open,30_pro,60_extor,60_fist,60_open,60_pro`로 고정한다.

원본 CSV 64개는 9,711,953행, 977,394,580바이트이다. 모든 time 차이는 0.001초이고 결측/무한값은 없다. 파일마다 mark=1이 30개, onset=1이 1개이며 onset은 첫 mark와 일치한다. 마커 간격은 4999(6개)/5000(1827개)/5001(23개) 표본이다. 파일 첫 행이 아닌 각 mark의 실제 인덱스를 사용한다. 앞뒤 잔여 표본은 분석 구간 밖으로 기록하며 삭제하지 않는다.

## 구간과 전처리

| 항목 | 값 | 근거와 적용 |
|---|---|---|
| 강의 필터 | 60Hz notch Q30 → Butterworth 4차 20–450Hz, filtfilt axis=0 | 2주차 4, 9쪽; 통합 25쪽. Q와 양방향 적용은 수업 선택 |
| 실제 기본 전처리 | 추가 필터 없음 | CSV 열이 bandpass1..5. 원필터의 대역/차수/노치는 미확인. 이중 필터를 피함 |
| 시행 기준점 | 각 mark=1 인덱스 | 마커의 생리적 의미는 설명 자료가 없어 **시행 시작으로 해석하는 가정** |
| 분석 구간 | mark+1500부터 2000표본, 끝 제외 | 2주차 10쪽: 1.5초는 실습 가정이며 논문 명시값이 아님 |
| 창/이동 | 200/100표본, 19창/시행 | 2주차 5, 11쪽; 통합 26쪽 |
| 경계 | 창은 분석 구간과 다음 마커 이전에 완전히 포함 | 모든 시행에서 자동 검증, 짧은 입력은 에러 |

입력의 채널별 RMS 시간 프로파일에서 큰 반응은 마커 뒤 약 1.5–1.8초에 나타났다. 강의의 2–3초 동작 도식과의 정렬은 확정되지 않았다. 고정 구간을 유지한 기준 결과로 보고하며, 데이터나 구현의 오류 원인으로 단정하지 않는다. 원신호(필터 이전)가 없어 실제 데이터에서 필터 전후 비교는 만들 수 없다. 필터 함수 자체는 합성 신호로 검증한다.

## 특징

각 창의 N개 신호값을 x_i, 인접 차이를 d_i=x_(i+1)−x_i로 둔다. 채널별로 다음을 계산한다(2주차 6,12쪽; 통합 27–28쪽).

- RMS = sqrt(sum(x_i²)/N)
- MAV = sum(abs(x_i))/N
- WL = sum(abs(d_i))
- ZC = sum(1[x_i*x_(i+1)<0 and abs(d_i)>=0.01]); 정확히 0인 표본은 교차로 세지 않는다.
- SSC = sum(1[d_i*d_(i+1)<0]); 임계값을 추가하지 않는다.

특징 순서는 `[RMS Ch1..5, MAV Ch1..5, WL Ch1..5, ZC Ch1..5, SSC Ch1..5]`이다. float64로 계산하고 NaN을 대체하지 않는다. 입력 전압 단위는 CSV만으로 확인하지 못했으므로 0.01을 임의 환산하지 않는다.

## 분할과 평가

시행 ID는 파일명+1부터 시작하는 시행 번호다. 정렬된 파일과 시간순 시행에서 1920개 목록을 만든다. 먼저 이 ID 목록을 나눈 다음 각 집합의 창을 펼친다. 특징을 사전 계산하더라도 통계 학습 없이 시행 내부에서만 수행하고 분할은 시행 축에 적용한다.

- Hold-out: `train_test_split(test_size=.2, stratify=trial_labels, random_state=42)`. 학습1536/시험384시행, 창29184/7296개(2주차13쪽).
- 기준 CV: 전체1920시행에서 `StratifiedKFold(5,shuffle=True,random_state=42)`. 각 fold 학습1536/평가384시행. 5개 평가 fold 합집합은 전체 시행과 일치하고 교집합은 비어야 한다(3주차12쪽).
- StandardScaler: 각 학습 집합의 **창**으로 fit, 평가창은 transform. 평균/분산은 학습 집합만으로 검증(2주차14쪽; 3주차12쪽).
- 주평가: **8클래스 창 정확도**. macro precision/recall/F1, confusion matrix, fold 평균·모집단 표준편차(ddof=0)도 보고(3주차10–12쪽).
- 시행 다수결은 보조표에만 기록한다. 동률은 가장 작은 클래스 ID를 선택한다. 강의가 인용한 논문 점수와 대체하지 않는다.
- 동작/각도 정확도와 오류는 8클래스 예측을 두 축으로 분해해 계산한다. 클래스 인접 위치로 오류 종류를 판단하지 않는다.
- 세 쌍의 대응표본 t-test는 같은 5개 fold 정확도를 사용한다(3주차13쪽). 5개 fold의 학습 집합이 중첩되고 표본이 작으므로 탐색적 결과로 해석한다. p≥.05는 동등성 증거가 아니다.
- 같은 피험자와 기록의 서로 다른 시행이 양쪽에 들어간다. 기록 독립/피험자 독립 성능을 의미하지 않는다.

## 모델 설정

| 모델 | 고정 설정 | 출처 |
|---|---|---|
| SVM | SVC(kernel=rbf,C=1,gamma=scale,decision_function_shape=ovr); 나머지 설치 버전 기본값 | 3주차9쪽; 통합32쪽 |
| RF | n_estimators=100,random_state=42,n_jobs=-1; criterion=gini,max_depth=None,max_features=sqrt,bootstrap=True 등 설치 버전 기본값 | 3주차9쪽; 통합33쪽 |
| XGB | objective=multi:softprob,n_estimators=400,max_depth=6,learning_rate=.05,subsample=.9,colsample_bytree=.8,reg_lambda=1,tree_method=hist,random_state=42 | 3주차9쪽; 통합34쪽 |

XGB는 사용자 지시에 따라 `device=cuda`를 추가한다. CUDA histogram은 CPU 실행과 부동소수점·샘플링 결과가 같다고 보장하지 않는다. 조기종료나 학습 규모 축소는 사용하지 않는다. 실제 booster config와 sklearn get_params는 비공개 실행 기록에 남긴다. RF/SVM은 CPU에서 실행한다. 2-tree GPU smoke test는 합성 입력 전용으로 본실험에 포함하지 않는다.

학습 시간은 scaler+model fit, 추론 시간은 표준화된 첫 평가창에 predict 100회 평균으로 측정한다. 모델 크기는 로컬 직렬화 바이트이며 데이터 취득 지연은 포함하지 않는다. 측정 장치는 TITAN Xp 사용자 PC이다.

## 개선실험의 사전 경계

기준의 단위검증과 전체 hold-out/5-fold 실행 후 아래 후보만 비교한다. 별도 기록 분리 목표나 90% 목표를 추가하지 않는다. 한 후보는 기준에서 한 조건만 바꾼다.

1. SVM C=10: 비선형 경계의 규제 강도만 변경.
2. XGB depth=4: 깊이만 줄여 과적합 민감도를 관찰(400회 유지).
3. XGB + MNF/MDF: 창마다 각 채널의 평균·중앙 주파수 10D 추가.
4. XGB 300ms 창: 이동100ms 유지, 시행당18창. 창 길이만 변경하며 결과는 창 수 차이를 표시.
5. XGB 전완3채널: 채널 어블레이션; 사용자 이두근·삼두근 가설 관련 진단이며 개선 후보 선정에서는 제외.

후보 선택은 hold-out 학습1536시행 안의 동일한 층화5-fold(42) 평균 창정확도를 사용한다. 기준 SVM/RF/XGB도 같은 개발 folds에서 평가한다. 시험 결과를 보고 후보를 추가하거나 구간을 옮기지 않는다. 후보 중 최고와 개발 기준 최고를 비교하고, 개선이 없으면 기준을 선택한다. 동률은 사전 순서(SVM,RF,XGB,C10,depth4,spectral,win300)를 따른다. 선택된 모델만 기존 hold-out 시험에 한 번 평가한다. 이 시험 집합은 기준모델 비교에도 쓰였으므로 프로젝트 전체에 완전히 미열람된 외부 시험이라는 주장은 하지 않는다.

MNF/MDF는 1kHz, Hann 창, 창 평균 제거, nfft=창 길이의 단측 periodogram 밀도(0–500Hz 전체)를 사용한다. MNF=sum(f*P)/sum(P), MDF=누적 P가 전체의 절반 이상인 첫 주파수이다. 전력이 0이면 둘 다0으로 정의한다. 주파수 특징의 순서는 MNF Ch1..5 다음 MDF Ch1..5다. 이는 수업 확장에 대한 구현 선택이며 원논문 설정이 아니다. 테스트셋에 맞춘 반복 최적화와 대규모 탐색은 수행하지 않는다.

프로토콜 간 데이터 사용: 기준 전체 5-fold에서 hold-out 시험 384시행 전부가 모델별 학습에 각각 4번, 검증에 1번 들어간다. 각 fold 학습과의 교집합은 291/317/316/306/306시행이다. 개발5-fold의 학습·검증은 hold-out 학습1536시행만 사용하고 시험384시행과 교집합이0이다. 모든 시행 ID는 `private/split_manifest.csv`, 교집합 숫자는 `results/split_checks.csv`에 기록한다. 같은 원천 데이터가 과거 프로젝트에서 사용되었다는 이력도 유지하며 새 외부 독립 데이터라고 표현하지 않는다.

## 상충·미확인 사항

- 통합25쪽 필터 예제는 axis 생략으로 2D 입력에서 채널축을 필터링할 수 있다. 2주차9쪽의 명시적 axis=0을 따른다.
- 통합24쪽은 1920 세그먼트와 19창을 설명하지만 논문의 최종 표본 구성은 불명확하다고 밝힌다. 수업 예제대로 36480창을 주표본으로 사용한다.
- 통합38,45–47쪽은 Table2와 Fig5의 정확도가 불일치한다고 명시한다. 직접 읽은 그림 대각합은 RF371/384, SVM366/384, XGB373/384. 수치 통합이나 원논문 정확재현 주장은 하지 않는다.
- CSV의 사전 필터, 단위, 마커 의미, extor 의미, 원 논문 분할 ID·패키지 버전은 미확인이다. 이 상태에서 얻는 결과의 이름은 **제공 CSV에 적용한 강의 설정 기준실험**이다.

## 검증 조건

라벨 정규식/조건의 완전한 Cartesian product, 비공개 manifest의 64개 파일 해시, 1920시행, 36480창, 수동 특징표, ZC 임계 경계, SSC 무임계값, 창 경계, 마커 변동, 누락 실패, scaler 학습범위, 시행 집계와 정확도 수동 계산, GPU device와 400 rounds를 모두 확인한다. 원본과 학습모델·예측 캐시는 `private/`에만 둔다. 공개 후보는 독립 코드, 환경 설정, 집계표, 설명과 집계그림이다.
