## 확인한 실행 근거

- hold-out3회+전체5-fold15회=18회 fit 완료. RF는 모든 fit에서100트리, XGB는400 boosting rounds와 CUDA device를 확인했다. 조기종료 없음.
- 합성/수동 단위검사12개 통과. 실제15창×25특징을 독립 Python 합으로 대조했고 최대 절대차이는1.78e-15였다.
- 18개 실행의 저장 예측으로 혼동행렬과 네 지표를 새로 계산하여 결과표와 일치함을 확인했다.
- 각 split의 시행 교집합0. 실제 분석구간 사이 최소2999표본. 36480개의25D 벡터 중 완전히 같은 벡터0개.
- 각 학습 부분에서만 scaler fit하고 학습 평균을 재계산해 대조했다.
- 결과 파일: baseline.csv, baseline_cv_summary.csv, paired_tests.csv, verification.json, split_checks.csv.

## 해석과 다음 실험

RF가 창 단위 기준에서 가장 높았다. 강의가 인용한 논문의96%대와 수치가 일치하지 않았다. 원논문 표본 구성/구간 정렬/원필터가 미확인인 상태에서 원인을 데이터 탓으로 단정할 수 없다.
고정구간 안에서도 창 위치별 성능이 다르다. 이 관찰은 오류분석이며 이후 시험점수를 높이기 위한 구간 변경에 사용하지 않는다.
다음 단계는 사전 명세의 C10, XGB depth4, 주파수 특징,300ms 창과3채널 진단이다. 선택은 hold-out 학습1536시행 안의5-fold에서만 한다. 전체 baseline CV와 hold-out은 같은 원천 시행을 다른 방식으로 재사용하며 그 교집합을 공개 집계했다.

공개본 해석 보완: 고정 시험 384시행 전부는 전체 CV에서 모델별 학습에 각각 4번, 검증에 1번 사용됐다. 따라서 뒤의 선택 모델 시험을 완전 미관측 외부 평가로 해석할 수 없다. 개별 fold 내부의 학습·검증 교집합은 0이고, 개선 후보의 개발 분할은 고정 시험을 제외했다.
