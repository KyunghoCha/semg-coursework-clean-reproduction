# 초기창·필터·정규화의 참조 범위

## 현재 구현에서 확인한 사실

v8의 905특징과 v9의 열 선택은 제공 CSV에서 자른 현재 200표본×5채널만 사용한다. RMS·평균·표준편차·분위수·부분 RMS·포락선 정규화는 해당 창 안에서 계산한다. 채널 간 비율·상관도 같은 창 안의 5채널만 참조한다. periodic Hann, 평균 제거, periodogram 및 교차 스펙트럼의 입력도 같은 200표본이다. 전체 시행의 평균·분산·최댓값을 특징 정규화에 사용하지 않는다.

합성 2초 신호에서 첫·중간·마지막 창을 고정한 채 그 밖의 모든 표본을 크게 바꿔도 905특징과 고정 scaler 출력이 정확히 같았다. 배치에서 추출한 창과 단독 추출도 일치했다. [범위 검사](../results/reference_phase_probe/window_scope.json)에 결과를 남겼다. 이는 현재 코드가 **제공 CSV의 창 이후 표본을 새로 참조하지 않는다**는 검사다.

StandardScaler는 각 모델의 학습 시행에서 만든 창에만 fit한다. 초기창 진단은 저장된 OOF scaler와 모델을 그대로 사용한다. 각 모델의 scaler 표본 수는 1,024시행×19창=19,456개이며, 초기창을 평가하기 위해 다시 fit하지 않았다. 평가 시행의 신호나 통계는 scaler 추정에 들어가지 않는다. 다만 이 작업은 오프라인 학습 모델의 평가이며 실제 시간 순서로 이전 기록만 학습하는 온라인 배치 실험은 아니다.

`lecture_filter`는 강의의 원시 입력 예제를 구현한 함수로 `filtfilt`를 사용한다. 현재 제공된 bandpass CSV의 준비·특징·학습 경로에서는 이 함수를 호출하지 않는다. 실제 호출은 합성 필터 단위 검사뿐이다. 따라서 새 파이프라인에서 이중 필터를 적용하지 않았다. 완료한 v11 정현파 투영은 별도 변경으로 기록했으며, 각 현재 창 안에서만 수행한다.

## 확인하지 못한 사전 처리

제공자는 60Hz 노치와 20–450Hz 4차 Butterworth 처리를 설명하지만 실제 계수·차수 적용 방식·순서·초기 상태·전후 처리·위상 구현을 확보하지 못했다. 원시 비필터 신호도 없다. 제공 CSV가 `filtfilt` 같은 비인과적 처리를 거쳤는지, 원신호의 미래 표본이 이미 현재 CSV 값에 반영됐는지 검증할 수 없다. 현재 코드의 창 독립성 검사를 사전 처리까지 포함한 인과성 증명으로 확대하지 않는다.

mark는 반복 시행을 구분하는 표식으로 사용했으며 동작 시작·이완·생리적 휴식의 정확한 시점은 확인하지 못했다. 따라서 mark+0.0–0.2초를 ‘초기 기준창’이라고 부른다. 실제 휴식창 또는 미래 영향이 없는 원신호라고 단정하지 않는다.

## 초기창 점수와 데이터 노출

초기창 90.43%는 각각의 시행을 제외한 3개 OOF 모델의 예측이다. 학습·평가 시행 교집합은 0이지만 세 분할 모두 기록 64개가 공유됐다. [OOF 범위 확인](../results/reference_phase_probe/oof_scope.json)에 학습·평가 수량과 교집합을 명시했다. 전체 개발 자료로 재학습한 모델의 학습 점수는 아니다. 반면 특징과 후보 설계는 이 개발 자료를 반복 사용했으므로 전체 분석 절차가 미관측 자료에서 평가됐다는 뜻도 아니다.

원래 384시행 시험도 최초 전체 5-fold에서 이미 사용됐다. 현재 자료 안에 완전히 미관측인 독립 시험이 남아 있다고 쓰지 않는다. 새로운 seed나 바깥 fold는 해당 선택 절차의 분리를 돕지만 과거 노출과 동일 기록 공유를 없애지 못한다. 기록 분리 대조는 이 혼입 가능성을 진단하는 별도 질문이며 강의 기준이나 논문 성능 목표를 대체하지 않는다.

이 저장소에서 직접 계산한 `평균±SD`의 SD는 fold 정확도의 표준편차(ddof=0)다. 신뢰구간이 아니다. 본문의 논문 인용 `96.72±0.58%`는 공개 초록 표기를 그대로 옮겼으며, 그 ±의 계산 정의는 전문에서 확인하지 못했다.


기록 공유를 분리한 초기창 대조 8회를 추가했다. 같은 초기 입력과 직접 8클래스 모델에서 시행 분리의 전체 합산 정확도는 81.3151%, 기록 분리는 2.6042%였다. 초기 90.43%와는 학습 구간·모델이 다르므로 직접적인 성능 대조가 아니다. [대조 결과](../experiments/record_reference_control/LOG.md)에 학습 수 차이와 기록·사람·조건 효과의 한계를 함께 기록했다.

공통 RMS 대조도 현재200×5표본의 제곱평균 제곱근 하나만 사용한다. DC를 제거하지 않고 양의 분모는 그대로 나누며0이면 영신호를 만든다. 다른 창·시행·기록 통계와 학습할 정규화 파라미터는 없다. 창 밖 변형 불변성과 배율 불변성 검사를 통과했다. 이는 해당 코드의 범위 검사이고 원래 CSV의 필터 인과성에 대한 새 증거는 아니다.
