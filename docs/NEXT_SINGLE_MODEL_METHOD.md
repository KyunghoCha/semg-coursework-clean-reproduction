# 다음 단독 모델 방법의 검토 — v34 사전 검토 이력

2026-10-22 후속 실행 요청에 따라 이 검토를 v34로 구체화했다. 실행 결과는 개선 실패였다(바깥 정답 −1창); 기존 v33을 유지하며 [결과](../results/local_spectrum_v34/summary.json)에 부정적 결과까지 보존했다. [고정 계획](../experiments/local_spectrum_v34/PLAN.md)과 [진단 후 실행 판단](../experiments/local_spectrum_v34/DIAGNOSTIC_DECISION.md)을 참조한다. 아래는 실행 전 검토 기록이며, 최신 진행은 STATUS.md와 v34 결과에 기록한다.

v33은 34창(+0.1165%p)을 더 맞혔지만 대표 모델 크기가 55.44→92.47 MB로 커졌다. 사용자가 긴 탐색과 작은 증가에 불만을 표했으므로, 트리 수·비중·SVM C를 조금씩 더 바꾸는 학습을 자동으로 시작하지 않는다. 아래는 실행된 결과나 사전 등록된 새 학습이 아니라, 다음에 검토할 한 가지 표현 가설이다.

## 현재창 안의 시간별 주파수 변화

현재 410개 특징은 200ms 전체의 주파수 파워·채널 관계와 40ms×5의 광대역 RMS를 포함한다. `features_v2.py`와 `features_fast.py`를 확인하면, 특정 주파수 성분이 창의 앞·뒤 어디에서 변했는지를 직접 표현하는 시간×주파수 특징은 없다. 같은 전체 파워와 비슷한 RMS를 가진 창도 주파수 성분의 시간 순서가 다를 수 있다는 가설이다.

같은 단독 XGB800의 **내부** 저장 예측을 집계했을 때 첫 위치는 83.59%, 뒤쪽 위치 하나는 95.31%였다(각 위치 분모 768개 내부 관측; 세 내부 분할은 완전 OOF가 아님). 이 차이는 더 세밀한 현재창 표현을 검토할 근거이지만, 원인이 창 내부의 주파수 변화라는 증거는 아니다. 기록 특성·신호 정렬·활동도 차이도 설명이 될 수 있다. 바깥 오답을 골라 새 특징을 정하지 않는다.

후보 예시는 현재 200ms를 네 개의 50ms 구간으로 나눠, 구간별 5채널의 고정 4대역 상대 파워를 구하는 80개 특징이다. 전체 200ms와 19개 평가창은 그대로이며 다른 창이나 시행 경계 정보는 쓰지 않는다. 한 XGB의 입력에만 추가하므로 여러 학습 모델의 출력 결합도 없다. 실제 실행 전에 창 함수·DC 제거·대역 경계·분모·작은 값 처리·특징 순서를 수식으로 고정해야 한다.

먼저 내부 자료에서 시간별 대역 변화가 기존 특징과 거의 중복되는지, 기록·클래스·RMS 수준을 고려한 뒤에도 오답과 관계가 남는지 작은 진단으로 확인하는 편이 타당하다. 관계가 불안정하거나 기존 특징의 재표현에 그치면 새 학습을 하지 않는다. 관계가 남아도 인과 효과나 일반화 개선을 보장하지 않는다.

검증할 근거가 생기면 기존 단독 XGB800의 같은 내부 분할과 전체 개발 시행을 유지한 한 후보만 비교한다. 같은 200ms·100ms 이동·전 19창과 기존 시험 제외를 유지하고, 선택은 내부에서만 한다. 내부 3fit와 통과한 바깥 최대 3fit가 필요하다. 현재 실제 fit 시간을 근거로 대략 10–25분 규모지만 새 특징의 비용은 아직 측정하지 않았다. 초기 진단과 특징 계산 시간도 먼저 확인해야 한다. 채택 기준과 크기 상한은 실행 전에 고정해야 하며, 아직 결과에 맞춰 정한 새 기준은 없다.

## 중복 방지와 우선순위

- 단순 50ms×4 RMS는 기존 40ms×5 RMS와 겹쳐 v15에서 이미 보류했다. 위 가설은 시간별 **대역 분포**에 관한 것이며 같은 제안으로 바꾸지 않는다.
- AR은 이미 TD25뿐 아니라 기존 410특징에 계수를 더한 440차원, 계수·잔차를 더한 445차원까지 v15에서 검증했다. 이를 새 방법으로 다시 제안하지 않는다.
- RF 용량 확대, SVM C·gamma·상관 보정, XGB 깊이·학습 횟수 대조의 낮은 결과도 보존했다. 이 설정들만으로 모든 전통 ML 방법을 소진했다고 주장하지 않는다.

가장 큰 논문 비교 장애는 여전히 원논문의 최종 표본 정의·정확한 분석 구간·분할 ID·필터 및 제공 데이터와의 대응이 없다는 점이다. 기존 RF 예측도 창별 64.54%와 시행 투표 95.78%로 크게 달라진다. 이 차이를 먼저 구분해야 하며, 높은 숫자를 맞추려고 평가 단위를 변경해서는 안 된다. 새 자료나 정확한 방법 정보 없이 논문 수준의 수치를 약속하지 않는다.


## v34 완료 후 판단

내부 세 분할 전체에서 새 표현의 정답은 고정 XGB800보다1개 적었고, 내부 규칙으로 선택된 한 fold의 바깥 결과도 기존보다1개 적었다. v34는 유의미한 향상의 근거를 만들지 못했다. 새 모델4개의 복원과83개 검사를 완료했으며 현재 추가 fit는 실행하지 않는다. 과거77개 검사 기준인 c1107da와 기존 최고 단독 v33을 보존했다.

현재 확인한 내부 잔차만으로 **우선 실행할 만큼 큰 개선을 뒷받침하는 새 후보는 없다**. AR·짧은 RMS·현재창 대역 표현을 이름만 바꾸거나, 바깥에서 틀린 창에 맞춰 대역·블록 수를 고르는 후속 탐색을 하지 않는다. 이는 모든 전통 ML 알고리즘·표현·설정이 소진됐다는 주장이 아니다. 실제로 단일 CatBoost나 다중 taper 추정은 현 저장소의 실행 기록에서 찾지 못했지만, 미실행이라는 사실만으로 고효과 후보가 되지는 않는다. 그러한 후보도 현재창 내부 오차와 연결되는 구체적 근거, 고정된 내부 선택·비용 예산이 먼저 필요하다.

논문과의 정확한 차이를 판정하려면 원논문의 표본/평가 단위, 분석구간 시작, 필터·단위·특징 정의, 분할 ID와 제공 데이터 대응이 필요하다. 강의의 mark+1.5–3.5초는 실습 가정이며 그 생리적 정렬을 확인할 근거가 부족하다. 이를 바꿔 점수를 높이는 것은 현재 고정된19창과 별도 조건이므로 조용히 변경하지 않는다. 이 방법 정보의 부족은 **정확한 논문 비교**의 장애이지, 현재200ms 실험 실행 자체가 불가능하다는 뜻은 아니다. 이번 실험은 실제 실행했고 개선을 확인하지 못했다.
