# 공개 이력

사용자 승인 후 https://github.com/KyunghoCha/semg-coursework-clean-reproduction 를 새 공개 저장소로 만들었다. 이전 실패 저장소와 비공개 실험 Git 이력을 합치지 않았다. 검증 export의 파일만 별도 공개 Git으로 관리한다.

최초 공개 commit은 `c19f72bb4f07e6dde828d57f0b665023f9a34637`이다. 원격 main 및529개 Git blob을 로컬 공개 후보의 바이트와 대조했다. 같은 v14 ZIP은3,184,898바이트이며 SHA256은 `10ec7c237d3acf692892a4a1a7151f78ca2deb4788c10462a600b148f9566274`다. 사용자 대화에 같은 ZIP을 전달했다.

원신호·모델·개별예측·개인별 결과·강의 원본·인증정보·대화는 게시하지 않는다. v15 공개 commit은 `465b9ae384c4d793eead015965e3b8a2ef188076`이며559개 Git blob이 검증 ZIP과 일치했다. v16은 `678fc35642ee81b0d1a8e93cbaf2bb5ead911cb4`의585개파일이검증ZIP과일치했다. ZIP은3,367,080바이트,SHA256 `b41455a7ad0e4c43ac2683e8b1ae2672dd2c2e9af194b504f0e0aad7932c91f4`다. 이후완료한실험도코드와집계만검증해반영한다. 기존 ZIP은 그대로 보존하며 중복 업로드하지 않는다.


## 이번 로컬 제출 후보

원본 커밋 `e6ddc74f30536abd4c446dc12ccd352733968cb8`의 완료 상태를 공개 규칙으로 정리했다. 공개 main의 HEAD는 읽기 전용 조회에서 `678fc35642ee81b0d1a8e93cbaf2bb5ead911cb4`로 확인됐다. 이번 v34 후보는 로컬에만 준비했으며 원격 커밋 생성·push·Library 업로드·release 생성은 수행하지 않았다. 이전 v19 승인 대기 ZIP은 변경하지 않았다.
