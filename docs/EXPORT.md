# 공개 후보의 범위

현재 clean 프로젝트의 새 로컬 export다. 원래 로컬 상세 결과와 이전 ZIP은 보존했다. 원신호, 모델, 개별 예측, 피험자별 성능·RMS 점, 기록별 프로파일, 파일명·마커 상세, 호스트명, 인증정보, 강의 원본과 대화 원문을 포함하지 않는다. 코드·전체 집계·그림·재현 환경만 포함한다. 학습 데이터가 없으므로 공개 묶음만으로 원자료 없이 학습할 수는 없다. 파서 검사에 쓰는 `a_30 fist.csv`와 `h_60 extor.csv`는 형식 검사용 합성 문자열이며, 실제 CSV 내용이나 개인별 결과가 아니다. 테스트는 이 이름의 파일을 열지 않는다. 공개 생성·전송·push는 수행하지 않았다.
