# 논문·강의·현재 구현 대조

2026-10-22 UTC. 최신 요청은 단독 RF/XGBoost/SVM 평가이며, 과거91.9819% 앙상블은 별도 조건으로 보존한다. 현재 단독 비교는 v33에 기록한다. 25개 시간 영역 특징 기준선의 차이를 먼저 확인했다. 현재 점수를 논문 수치와 같은 평가로 간주하지 않는다. 아래의 ‘논문 확인’은 공개 초록 또는 그림에서 직접 확인한 범위다. 강의가 논문에 관해 설명한 내용은 별도 출처로 표시했다.

## 먼저 확인된 결론

1. **강의 RF 기준선 64.54±0.35%는 RF를 작게 줄여서 얻은 값이 아니다.** RF100·깊이 제한 없음·기본 sqrt 특징 선택을 그대로 실행했다. RMS/MAV/WL/ZC/SSC의 25개 특징도 강의 코드와 일치한다. 초기15창의 독립 수식 검증에 이어, 개발1536시행의 전29184창을 독립 식으로 재계산했다. 최대 절대차이는4.27e−14였고 ZC·SSC 정수는 모두 정확히 일치했다. 저장 예측·분할·scaler 검증도 통과했다. 이는 논문 전체 방법과 동일하다는 뜻은 아니다.
2. **가장 큰 비교 불확실성은 표본·평가 단위다.** 공개 Fig.5의 각 행은 48개, 총 384개다. 현재 기준선은 384시행의 19창을 각각 평가하므로 7,296개다. 384라는 수가 우리 시험 시행 수와 같다는 사실만으로 논문이 시행 투표를 했다고 결론 내릴 수 없다. 한 창 선택·특징 집계·예측 집계 중 어느 방식인지 확인되지 않았다.
3. **분석 시작 1.5초는 강의의 실습 가정이다.** 강의 2주차 10쪽은 논문의 2초 구간 시작점을 명시하지 않았다고 쓰며, 코드에도 실습 가정이라고 표시한다. 현재 마커+1.5–3.5초에는 신호가 약한 창과 전이 창이 함께 있다. 정확도에 영향을 줄 수 있지만, 시험 점수에 맞춰 구간을 이동하거나 창을 제외하지 않는다.
4. 원본 64개 CSV는 제공자 저장소의 특정 버전과 일치한다. **논문 원자료와의 동일성은 미확인**이다. 논문의 요청 기반 데이터 제공 정책만으로 두 자료가 다르다고 판단할 수 없다.

## 기존 보조지표가 보여 주는 평가 단위의 영향

새 시험 예측이나 재학습 없이, 처음 기준실험에 이미 저장된 `results/baseline.csv`의 `trial_vote_accuracy`를 읽었다. 같은 모델·같은 예측을 창마다 세는지, 한 시행의19창 다수결로 세는지에 따라 다음처럼 달라졌다.

|기존 전체5-fold|개별창 정확도|기존 시행 다수결 정확도 평균±SD|
|---|---:|---:|
|RF100/25TD|64.54%|95.78±1.11%|
|SVM C1/25TD|48.56%|79.95±1.34%|
|XGB400/25TD|62.97%|94.17±1.18%|

기존 RF hold-out 보조지표는372/384=96.875%이고 창 정확도는64.3777%다. 이는 **평가 단위 차이만으로 큰 수치 격차가 생길 수 있음**을 보여 주는 직접적인 예다. 그러나 SVM의 시행 점수도 논문과 차이가 크므로, 투표 하나가 모든 차이를 설명한다고 볼 수 없다. 논문이 투표를 사용했는지 확인되지 않았고, 수치가 비슷하다는 이유로 방법이나 데이터가 같다고 판단하지 않는다.

이 보조값은2초 구간 전체19창의 정보와 시행 경계를 사용한다. 현재200ms 한 창 조건과 다르며 주평가로 채택하거나 새 정확도 개선으로 기록하지 않는다. 기존 시험 예측을 새로 생성하지 않았고, 이 값을 RF v32 설정·선택에 사용하지 않는다.

## 25TD의 낮은 값에 대한 기각 범위

원본 전체 64기록·1,920시행·36,480창을 사용했다. 기준 hold-out 3fit와 전체 5-fold 15fit에서 RF100트리 및 XGB400라운드를 확인했다. 결과는 SVM48.56±0.45%, RF64.54±0.35%, XGB62.97±0.39%다. 코드의 수식·정답 정렬·fold 교집합·scaler·지표 재계산 범위에서는 결함을 찾지 못했다. 이는 마커의 생리적 의미와 원필터까지 입증한 검증은 아니다.

ZC 임계값이 작동하지 않는 창이 채널에 따라 26–60%라는 관찰은 있지만, v2에서 ZC 임계값만 0으로 바꾼 XGB 내부 평균은 58.3215%, 원래 58.4360%였다. 시간 영역 특징을 늘린 값도 58.3644%였다. 이 대조는 ‘0.01을 없애면 격차가 해결된다’는 가설을 지지하지 않는다. 물리 단위 불확실성 자체를 없애는 결과는 아니다. 전압의 공통 양의 배율은 RF의 RMS/MAV/WL 분할 순서를 바꾸지 않으므로, 단위 차이가 RF의 전체 격차를 자동 설명하지도 않는다. 반면 고정 임계값 ZC에는 영향을 줄 수 있다.

위치별 결과도 ‘활동 구간만 맞추면 해결된다’는 단순한 설명을 지지하지 않는다. 기존 전체 기준선 RF의 창 정확도는 시작1.7초에서75.21%, 2.3초에서54.84%였다(`results/window_position_cv.csv`). 개발 자료에서3.3초 창의 전완 RMS/휴식 RMS 비율 중앙값은0.83이고 낮은 활동 비율은87.57%였다. 반면 최신 v25의 사후 기술 집계에서 최고 위치는3.1초의95.57%, 첫1.5초는86.52%였다. 서로 다른 모델·평가이므로 수치를 직접 뺄 수 없으며, 이 바깥 위치 점수로 v32를 선택하지 않았다. 활동이 낮아도 같은 기록을 식별하는 정보가 남을 수 있다는 기존 기록 분리 대조와 함께 해석해야 한다. 이는 동작 관련 정보가 전혀 없다는 증명은 아니다.

자료를 강제로 재필터링하거나 1초 활동창만 골라 96%대에 맞추는 것은 오류 수정이 아니다. 논문의 표본 구성·정확한 분석 구간·원자료 대응을 확보해야 그 차이를 판정할 수 있다. 그 전에는 384개 혼동행렬을 맞추기 위해 창 투표를 주지표로 바꾸지 않는다. 전체 5-fold를 다시 실행해도 이 미확인은 해결되지 않는다.

## 현재 입력 조건에서 다음으로 검증할 것

RF100·905특징·직접8목표(v13)는 내부 74.7464%였고, 최근 v28은 **RF가 아니라** 잎을 384개로 제한한 ExtraTrees128·410특징·64목표였다. 후자는 학습 정확도도 약92%로 제한되었다. 이를 현재 410특징에서 충분한 분할 용량을 가진 RF까지 검증했다고 간주할 수 없다.

따라서 별도 v32에서는 같은 200ms·19창·개발 1,536시행·기존 분할을 유지해 **제한 없는 잎의 RF200, max_features=.5** 한 설정을 직접8목표와64목표에서 비교한다. 두 목표를 비교하는 이유는 표현 효과와 기록에 대응하는64목표 효과를 구분하기 위해서다. 새 모델을 기존 결합에 10%만 섞는 규칙을 미리 고정한다. 내부에서 정답이 적어도10창 늘고 전체 크기가 기존의3배 이내일 때만 해당 fold를 바깥 평가로 진행한다. 시험384시행은 열지 않는다. 열세 후보의 긴 지연 측정은 생략하고 학습시간·크기·정확도·복원만 확인한다. 이는 논문 RF 복원이 아니라 같은 입력 조건의 새 RF 대조다. 세부 사전 명세는 `experiments/rf_capacity_v32/PLAN.md`다.

## 정확재현을 판정하는 데 필요한 최소 자료

- 최종 특징 행렬의 행 수와 한 행의 정의: 200ms 창 하나인지, 여러 창의 특징 또는 예측을 합쳤는지, Fig.5의 384개와 어떤 관계인지.
- 실제 분할 ID 또는 분할 생성 코드와 분할 단위: 시행·기록·피험자 공유 여부, 5-fold와 Fig.4/5가 같은 평가인지.
- 취득 원자료와 제공 CSV의 대응, 전압 단위·필터 실행 코드, 마커의 의미 및 분석 2초의 시작 인덱스.

이 정보가 확보되면 동일한 25TD·RF100을 논문에서 확인된 표본 구성에 적용하는 **별도 사전 고정 프로토콜**을 만들 수 있다. 기존 200ms 창 정확도는 계속 함께 제시하고, 분모를 바꾼 결과를 같은 조건의 정확도 개선으로 세지 않는다. 별도의 새 기록·세션 자료는 반복 개발 선택과 기록 의존성을 벗어난 일반화를 확인하는 데 필요하다. 이번 작업에서 저자에게 연락하거나 접근 제한을 우회하지 않았다.
